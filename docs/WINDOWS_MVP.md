# Windows 基础版

## 范围

Windows 优先，其他平台保留为后续目标。仓库使用单一根 Cargo workspace，只包含 GPUI 应用、共享核心和 Windows 平台实现。

首批功能：文本采集、历史持久化、精确去重、搜索、复制、删除、置顶、暂停/恢复。后续已增加全局唤出快捷键、HTML/RTF、PNG 图片和普通文件路径的采集、历史、预览与复制，以及经全局快捷键唤出后返回原窗口的受控粘贴；虚拟文件保真仍待开发。

## 当前实现

- `crates/clipboard-core`：包含数据库 schema、迁移、仓储和去重源码，提供 UI 无关的文本、HTML/RTF、图片与文件路径历史用例。
- `crates/clipboard-platform`：Windows 原生剪贴板事件监听及全局快捷键；独立 worker 串行处理历史操作；请求代次、实例锁、重复启动唤出、有界队列和关闭清理。
- `crates/clipboard-gpui`：Windows 原生主窗口、搜索、虚拟历史列表、复制/删除/置顶、暂停确认、加载更多、文本/富文本/图片预览与文件详情、收藏与收藏筛选、导入分组浏览、组内拖拽排序、系统托盘和错误反馈。

数据库与去重源码已经物理迁入 `clipboard-core`；核心不依赖桌面 UI 框架或 Windows API。

源码模块与维护边界见[工程文档](README.md)。所有 Rust 源码、示例和测试文件上限为 500 物理行，`scripts/check-source-size.ps1` 在 `just check` 与 GPUI CI 中强制检查；拆分按职责而不是编号或文本包含进行。

默认目录由 `ProjectDirs::from("com", "ASLant", "ElegantClipboard-GPUI")` 生成，位于 Windows 用户 LocalAppData。不自动读取旧版安装目录中的数据库；可通过显式导入命令复制旧库到空 GPUI 数据目录。自动测试使用临时目录、合成文本和仓库内 PNG 样本。

限制：单条文本最多 1 MiB，富文本的 HTML、RTF 原始字节与纯文本合计最多 1 MiB；图片最多 2500 万像素、编码 PNG 最多 50 MiB；文件路径列表最多 256 项或 1 MiB，仅保存原路径，不备份文件内容。普通未固定历史按原仓储规则保留一万条；空白文本不保存。重复的完全相同文本移动到顶部，文字和换行原样保存。队列满时报告采集失败，不把不同复制事件主动合并成最后一条。

## 启动与操作

```powershell
# 正常使用：启动原生窗口并记录后续复制的受支持内容
cargo run -p elegant-clipboard-gpui --locked

# 隔离检查：禁用采集，只浏览指定目录中的历史
cargo run -p elegant-clipboard-gpui --locked -- --no-monitor --data-dir .\target\gpui-check

# 窗口冒烟：禁用采集，约 3 秒后自动退出
cargo run -p elegant-clipboard-gpui --locked -- --smoke-test --data-dir .\target\gpui-smoke

# 从旧版数据库导入到尚无 clipboard.db 的 GPUI 数据目录；命令完成后退出
cargo run -p elegant-clipboard-gpui --locked -- --import-db "C:\旧版目录\clipboard.db"
```

- 搜索支持中文与字面 `%`/`_`，等待 150ms 后查询；回车复制当前选中结果。卡片摘要中出现的搜索词会高亮显示；若词只存在于文本正文较深的位置，卡片改为显示第一处命中附近的片段并高亮。匹配按 Unicode 字符逐个比较且不区分大小写；文件路径等没有正文的记录继续使用原摘要。
- 列表支持 ↑/↓ 逐条选择、PageUp/PageDown 翻页选择、Home/End 跳到首尾、←/→ 按“全部/收藏/文本/其他”顺序切换分类、Ctrl+←/→ 切换默认及自定义分组并滚动到选中分组、Enter 按卡片点击规则复制或粘贴、Ctrl+Enter 明确粘贴到原窗口、Delete 删除；Ctrl+F 聚焦搜索。
- 搜索框按 ↓ 会聚焦列表首条已加载记录；列表首条按 ↑ 会返回搜索框。搜索框中的其他方向键继续用于编辑文本，空结果或查询进行中不会转移焦点。
- 当前已加载历史超过 8 条时，列表上方的固定信息栏提供“返回顶部”，点击后严格滚动到首条；该入口不会覆盖卡片操作区。
- 点击卡片非按钮区域时，若通过全局快捷键保留了有效的原窗口目标，就使用现有受控复制后粘贴流程；否则复制该记录供手动粘贴。进入批量选择模式后，卡片点击改为选择或取消选择，Shift 点击可在当前已加载顺序中连选；拖拽和单条记录操作按钮在该模式中关闭。普通模式下悬停或选中卡片时，预览、收藏、置顶、分组及复制等按钮显示在底部信息行，保持各自独立动作；未悬停时显示时间、大小及来源应用。
- 普通模式下仅卡片左右两侧的 18 px 区域可启动拖动排序，卡片中间保留点击动作。显示设置中的“显示卡片拖动区域”默认开启，握柄仅在悬停卡片时出现；关闭后只隐藏提示，拖动仍有效。批量模式不显示拖动区域，也不能拖动排序。
- 普通模式下双击文本、网址或富文本卡片可直接进入编辑；第一次单击会等待系统双击间隔结束后才复制或粘贴，以免双击先执行粘贴。批量模式、键盘操作及图片/文件卡片仍立即响应。搜索、筛选、拖动、打开预览或隐藏窗口会取消尚未执行的单击。
- 非批量模式下右键卡片会显示按记录类型变化的菜单：复制、返回原窗口粘贴、纯文本或路径操作、查看详情、文本编辑、收藏、置顶、移动分组和删除；图片及文件还可在资源管理器中定位或另存为。编辑会先读取该记录完整内容，再进入已有编辑界面；目标窗口失效、记录不再可见等情况仍由执行时检查处理。
- Esc 优先取消拖动或关闭当前确认、分组编辑与移动面板，再退出批量选择模式；没有待处理界面时隐藏历史窗口到托盘。托盘不可用时按关闭窗口流程退出；复制后粘贴正在处理时不会用 Esc 隐藏窗口。全文预览中的 Esc 先取消编辑或返回列表。
- 列表按 Shift+Enter 会使用选中记录已保存的纯文本表示；从有效目标窗口唤出时写入纯文本后尝试返回原窗口粘贴，否则只复制供手动粘贴。富文本卡片和预览中的纯文本按钮沿用相同规则；图片和文件记录、没有纯文本表示的富文本记录会明确报错。
- 置顶、删除与复制按钮直接调用后台服务；文本复制使用完整正文，HTML/RTF 在同一次剪贴板操作中逐项写入纯文本及可用的富格式，任一格式写入或读回校验失败会明确报错，卡片“纯文本”与预览“复制纯文本”只写入其已保存的纯文本表示。没有纯文本表示时明确报错，不复制预览占位文案；图片从保存的文件解码写回剪贴板，文件路径在源文件仍存在时写回剪贴板。文件卡片与文件/图片预览可将有效路径复制为换行分隔的纯文本，也可在资源管理器中定位第一项；从有效目标窗口唤出时“复制路径”变为受控“粘贴路径”。
- “暂停记录 / 恢复记录”状态保存在 GPUI 数据库，重启后先恢复状态再启动监听；保存成功后界面才切换。暂停时已有历史仍可搜索和复制。
- 空数据目录首次打开时显示四步原生引导，依次说明采集、搜索、置顶收藏和键盘快捷键；使用 GPUI Kit Stepper 显示当前进度，点击任一步可查看其说明，“下一步”“开始使用”“跳过”及 Esc 可操作。完成状态写入 SQLite 后才关闭引导，重启不再出现；保存期间禁止切换步骤和重复提交。已有历史的 GPUI 数据目录会自动标记为已完成，避免升级后遮挡历史；窗口冒烟模式不显示引导。引导中有关自动粘贴的说明以从目标应用用全局快捷键唤出为前提。
- 设置窗口按常规、显示、外观、数据、应用过滤、音效、快捷键和关于分页导航；现有设置卡片归入相应页面，切换页面时结束未完成的快捷键录制。导航标签随界面语言切换。
- 音效页可分别启停历史复制和受控粘贴的短音，并选择“立即”或“成功后”播放；试听不受开关限制。复制音效覆盖普通、纯文本、路径和批量合并复制；粘贴音效在向原窗口发送快捷键时触发，“成功后”仅表示 Windows 接受按键注入，无法证明目标应用已完成粘贴。设置保存在 SQLite 并随 GPUI 备份恢复；音频设备不可用时不会阻止复制或粘贴。
- 关于页显示应用版本、作者，并提供作者主页、项目仓库和问题反馈入口；使用 Windows 默认浏览器打开固定的 HTTPS 链接，打开失败时在设置页显示错误。
- 设置窗口的“监听内容类型”可分别切换文本、网址、HTML、RTF、图片和文件的自动采集，至少保留一种。富文本含多个格式时保留已启用的格式；富格式均停用而纯文本表示已启用时回退为文本。设置保存在 SQLite 并随 GPUI ZIP 备份恢复。手动复制历史记录及导入不受此设置限制。
- 设置窗口的“来源应用过滤”支持启停、黑名单/白名单、手工添加或删除规则，并可从当前可见窗口的运行中应用列表选择进程。规则按来源应用名、进程名及完整路径匹配，普通规则不区分大小写地匹配子串，`*` 与 `?` 通配符按整个名称或路径匹配。来源识别失败或规则列表为空时仍记录；过滤仅作用于后续自动采集，不删除已有历史。规则保存在 SQLite 并随 GPUI ZIP 备份恢复。
- 点击“查看”或在列表按 Space 打开完整文本、HTML/RTF 的纯文本表示、图片或文件详情；文本可滚动、选取，图片按原比例显示。图片预览可用缩放按钮或 Ctrl+滚轮按 10% 调整，范围为 50% 至 400%；点击百分比可恢复 100%，放大后可滚动查看，切换预览时重置缩放。文件详情按原顺序显示名称、原始路径、文件/文件夹、普通文件大小与失效状态；旧备份恢复的源文件丢失但受管暂存副本可用时，同时显示备份路径。元数据在后台读取，详情列表独立滚动。富文本预览同时提供“复制纯文本”和“复制富文本”，窄窗口中按钮可换行。图片和普通文件可从预览打开 Windows 原生保存对话框并另存第一项，默认沿用源文件名；后台在复制前重新解析记录，只接受现存普通文件，拒绝文件夹、失效源、相对目标和原地覆盖。文本、网址与富文本可从预览进入编辑，保存后保留记录 ID、分组与收藏状态并刷新搜索结果；修改富文本会转为纯文本，空内容保存会报错，请使用独立“删除”按钮。Esc 在编辑时取消修改，在只读预览时返回列表。预览按需从后台读取，关闭后的旧响应不会重新打开预览。
- 单张图片文件在历史卡片、完整文件详情及文件悬浮浮窗中显示图片，保留文件名、原始路径和大小信息；多文件及不支持预览的记录继续显示文件详情或路径。卡片缩略图的外部文件元数据检查在独立后台线程执行，不阻塞列表绘制；同一批已加载记录不会在每次列表刷新时重复检查。仅预览确认存在、元数据可读且大小已知的 PNG/JPEG/GIF/WebP/BMP 文件；本地路径上限 50 MiB，UNC 路径上限 10 MiB，超限或图片解码失败时显示回退内容。受管备份副本仍只在完整文件详情和悬浮浮窗中预览，历史卡片继续显示原始路径。
- 文件卡片还会在后台检查所有原始路径。任一原始路径不存在时，列表标题显示红色“源文件已失效”；无法读取元数据或路径无效时显示“文件无法读取”。文件名也使用警示色，图片缩略图仅在单文件可读且大小合规时显示。该提示只描述原始来源；旧备份中的受管副本是否可用于复制，仍以完整文件详情和执行时的校验为准。检查结果按记录 ID 和路径内容缓存，记录离开当前列表或路径变化后重新检查；本地路径先完成，网络路径随后返回，避免网络检查拖延本地提示。
- 文件卡片使用警告、普通文件和文件夹图标区分失效、单文件、文件夹与多文件；图片文件符合预览限制时优先显示缩略图。超过图片预览上限的文件显示“图片过大”，保留普通文件图标和文件名。多文件卡片显示前 3 个文件名，更多项以省略号结尾；显示大小时使用后台读取的真实文件字节数，只有全部路径都是可读普通文件时才显示总量，文件夹或失效来源不再显示路径字符串的字节数。
- 点击条目“收藏 / 取消收藏”保存常用记录；分类栏可切换“全部 / 收藏 / 文本 / 其他”，其中“文本”包含 text、HTML、RTF，“其他”包含图片、文件和 URL。分类与自定义分组互斥，搜索、数量与加载更多均由后台按当前分类查询，不会只筛选已加载记录；取消收藏不会删除记录。收藏状态持久化，启动默认显示全部。
- 分类标签与 GPUI Kit `Select` 分组下拉位于同一行，默认分组固定首位；选择自定义分组会切换其历史，搜索、数量和分页限定在当前分组，并取消分类高亮。Select 的“+ 新建分组”和“重命名”使用 GPUI Kit `Dialog` 填写分组名称，确认保存后关闭并刷新分组，失败时在对话框内保留输入和显示错误，保存期间禁止取消与重复提交；选中自定义分组时下拉还提供删除及可用的上移/下移操作。顺序保存到 SQLite，删除前显示名称和记录数，确认后将组内记录移到默认分组，保留收藏与原始内容。每张卡片的“分组”按钮仍可将记录移到其他组，保存后列表与数量刷新；新采集内容仍进入默认分组。隐藏分类栏时分组 Select 仍可使用。
- 文本、网址、富文本、图片和文件记录均可从卡片左右两侧拖动区域拖动；拖动浮层显示类型和摘要，目标上/下半区的主题色插入线表示可放置，红色插入线表示当前列表状态已失效。按钮区保留各自点击操作；指针停在列表边缘时会持续滚动已加载记录，并随可变高度虚拟列表推进更新落点。历史顺序写入 SQLite，收藏列表维护独立顺序。拖到置顶卡片前后会自动置顶，拖到普通卡片前后会自动取消置顶，状态与目标区顺序在同一事务中保存和回滚。Esc 可取消拖动。图片卡片高于默认两行文本卡片；插入线及排序反馈共用动效时长并遵从系统减少动态效果设置。排序已写入但列表刷新失败时返回明确错误并解除操作锁定，重启后可重新查看顺序。
- 默认加载 100 条，点击“加载更多”继续；GPUI Kit `VirtualList` 按记录实际高度只渲染可见行，并保留滚动、键盘定位和边缘拖动的原有行为。
- 设置窗口中的“外观”提供跟随系统、浅色和深色；保存成功后生效，重启恢复选择。设置存于同一 SQLite 数据库，手动主题不随系统通知改变；未知设置值回退为跟随系统。
- “外观”页的窗口效果可选关闭、亚克力、云母或云母 Alt；“背景遮罩强度”提供 40%/55%/72%/85% 四档，仅控制窗口外壳的一层主题染色，不改变控件透明度或系统模糊半径。开启效果时，设置标题栏与侧栏容器局部透明；分组保持描边，卡片、输入框、选中项、通知、菜单和对话框保留 GPUI Kit 原有表面与阴影。材质切换不再修改全局主题 token，也不重新加载主题；三个窗口沿用已有 DWM、边缘缩放与客户区尺寸同步逻辑。原有 `gpui_window_effect` 设置格式及已保存的材质、强度值保持不变。
- 材质能力由平台层用 `RtlGetVersion` 获取并缓存，版本未知时保守关闭。build 22621 及以上提供全部材质；17763–22620 提供关闭和兼容亚克力，已保存的云母/云母 Alt 降级为兼容亚克力；更早版本或探测失败时降级为不透明。设置页保留已保存但不支持的选中项，将其禁用并显示持续降级说明，不因本机能力改变存储值；实际不透明时禁用遮罩调节。原生 DWM 背板仅在支持的系统调用，兼容亚克力使用 GPUI 的 WCA 路径。
- 保存材质设置后，先比较请求值解析出的新旧原生后端。只有后端不同才给每个已打开窗口应用一次原生效果；仅修改遮罩强度或从已保存云母降级状态改选相同的兼容亚克力，只更新背景状态并重绘，不触发原生材质、边框、客户区尺寸重配，也不关闭已有悬停预览。首次创建窗口仍初始化原生效果，悬停浮窗保留创建后的客户区修正。
- 主窗口使用 GPUI 透明标题栏窗口选项，但不绘制顶部标题栏或系统标题栏按钮；搜索框上方有 30 px 高的握柄区域，可按住居中的浅色短横或其左右空白处拖动窗口。顶部边缘由 Windows 优先处理缩放，不能当作拖动点；分类栏下方的记录数量区域仍可拖动，“返回顶部”按钮保持可点击。占一行的快捷键说明已移除；Esc 或托盘控制显隐。独立设置窗口继续使用 gpui-kit `TitleBar`。
- 独立设置窗口初始内容区为 1280×720（16:9），居中打开；最小内容区仍为 700×420。Windows 外框会使实际窗口矩形略大于内容区尺寸。
- 设置窗口的“记住窗口大小”默认开启：主窗口停止缩放 300 ms 后保存最后一次普通窗口的内容区逻辑尺寸，重启时恢复；关闭后清除已保存尺寸并停止写入，重新开启后保存当前普通窗口尺寸。最大化和全屏状态不会覆盖普通尺寸；保存值缺失、损坏或超出 420×520 至 4096×2160 时回退到 560×760。设置窗口可选择唤出位置：默认跟随光标，优先出现在光标右下方，水平空间不足时翻转到左侧；也可在光标所在显示器工作区居中，或在当前会话保持上次位置。前两种模式在启动及托盘、快捷键唤出时将窗口限制在光标所在显示器的工作区内，最大化或全屏时不移动。模式保存在 SQLite；窗口坐标不跨重启持久化，避免显示器变化后落到屏幕外。窗口尺寸记忆开关、已保存尺寸和定位模式随 GPUI ZIP 备份导出和恢复。
- 设置窗口的“隐藏时重置搜索、筛选和滚动”默认关闭。开启后，主窗口从关闭、Esc、快捷键、托盘、外部点击或历史列表空白点击隐藏时，会清空搜索、回到全部记录和默认分组，并将列表滚动到顶部。无论开关状态，隐藏时都会退出未提交的批量选择；批量操作或粘贴请求正在处理时暂不隐藏窗口。预览文本正在编辑或保存时保留预览，避免丢失未保存内容。该设置随 GPUI ZIP 备份导出和恢复。
- 设置窗口的“唤出时清空搜索”默认开启，主窗口从托盘、快捷键或重复启动唤回时清空已有搜索并刷新当前分类/分组结果；“唤出时聚焦搜索”默认关闭，开启后启动显示及每次唤出时将键盘焦点放到搜索框。两项设置保存在 SQLite，并随 GPUI ZIP 备份导出和恢复。
- 主窗口搜索框独占一行，不再提供旁侧多选按钮，左右内容边距各 8 px；下方分类标签与 GPUI Kit 分组 Select 同行，二者与搜索框统一为 32 px 高。清理当前组历史、置顶窗口和设置固定显示在托盘菜单，置顶项显示勾选状态；旧版保存的操作入口显隐和顺序配置不再生效。
- 设置窗口的“列表显示”可隐藏分类筛选栏（当前使用分类或收藏筛选时回到全部记录；浏览自定义分组时保留当前分组，并停止分类左右键切换），或在紧凑、标准、宽松三档卡片密度间切换；卡片预览行数默认为 2 行，可设置为 1 至 10 行，已有保存值保持不变；时间、字符数、大小和来源应用信息可分别显示或隐藏；显示时间可选绝对或相对格式。剪贴板变化时优先按剪贴板所有者识别来源进程，失败时回退到前台窗口；无法读取进程信息时不显示来源。识别到的可执行文件图标在后台提取并缓存为 PNG，卡片可按名称、图标或两者显示，提取失败时回退为名称；被记录引用的图标随 GPUI 备份导出和恢复。文本卡片高度随密度和预览行数变化，图片卡片使用单独行高及居中大缩略图；虚拟列表按实际行高布局，拖拽反馈距离同步更新；显示设置持久化并随备份恢复。
- 托盘置顶项使用 Windows topmost 窗口层级；开启后受控粘贴时窗口保持可见但键盘焦点仍交回目标应用。未置顶时可在“窗口行为”中选择粘贴后是否隐藏，默认隐藏；选择保持可见时仍将键盘焦点交给目标窗口。还可控制粘贴后是否将该条普通记录移到所在列表首位，默认开启；已置顶记录不改变顺序，合并粘贴不触发单条排序。仅在向原窗口成功发送粘贴快捷键后调整顺序。窗口可见且未置顶时，点击应用外的窗口或桌面会隐藏历史窗口到托盘；应用自己的悬停浮窗及设置窗口不触发隐藏，设置窗口打开或粘贴请求处理中也不自动隐藏。监听通过 Windows 鼠标钩子发送有界的点击事件，仅在主窗口可见时转发；不保存点击位置。置顶仅作用于当前运行会话，关闭应用后不保留。
- 历史列表容器中的空白处点击与窗口外点击一样可隐藏未置顶的主窗口；卡片点击继续选择或执行卡片操作，不冒泡成空白点击。置顶时两种自动隐藏均不触发，但全局唤出快捷键仍可主动切换主窗口显隐。设置窗口关闭后，托盘、全局快捷键与窗口外点击继续监听主窗口。
- 关闭窗口后隐藏到系统托盘，左键托盘图标和全局快捷键可切换窗口显隐，最小化时会恢复；右键菜单“打开”始终显示并聚焦窗口，粘贴请求处理中暂不隐藏。右键菜单“退出”结束后台监听。在设置窗口中，“唤出”可选 `Ctrl+Shift+V`（默认）、`Alt+C`、`Ctrl+Alt+V` 或关闭，选择保存在 GPUI 设置中。组合键被占用时提示并恢复原快捷键，托盘入口仍可用；托盘初始化失败时关闭窗口正常退出。用全局快捷键从目标应用唤出后，卡片与预览上的“粘贴”按钮可先复制，再隐藏历史窗口并尝试向原窗口发送设置中选择的 Ctrl+V 或 Shift+Insert；离开历史窗口会清除原目标和未完成的粘贴请求，再直接点回时需从目标应用重新按热键唤出。托盘唤出或目标窗口失效时仅能手动复制。焦点不匹配、修饰键未松开、复制后剪贴板序列号变化或按键注入失败会显示错误并保留已复制的内容。Windows 无法从按键注入返回值确认目标应用已经完成粘贴，因此成功提示仅表示已发送快捷键。粘贴按键可选 Ctrl+V（默认）或 Shift+Insert，配置保存在 SQLite 并随 GPUI 备份恢复；当前不支持任意按键组合录制。
- 选择 `Alt+C` 唤出时，可以按住 Alt 不放，反复按下并松开 C，依次唤出和隐藏主窗口；C 持续按住不会自动连发。Windows 上主窗口唤出且 Alt 仍被按住时直接聚焦窗口，避免 GPUI 默认激活过程注入 Alt 松开事件；未按住 Alt 时继续使用原有窗口激活路径。
- 设置窗口中的“开机启动”默认关闭；用户开启后在当前用户 Run 键写入与该数据目录对应的独立项，关闭后删除。启动命令使用当前可执行文件、该数据目录和 `--start-hidden`；开机启动时窗口不弹出，可由托盘或快捷键唤回，托盘初始化失败则显示窗口。移动可执行文件后需要在新位置重新开启，才能更新启动命令。
- Windows MSVC 版的 GPUI 主线程预留 8 MiB 栈空间；设置窗口元素树在系统默认 1 MiB 预留量下会触发栈溢出。该数值是虚拟地址预留，物理内存随实际使用提交；构建脚本仅对本应用的 Windows MSVC 可执行文件设置链接参数。隔离窗口打开设置和编辑快捷键的过程见 [快捷键界面验收](evidence/windows-quick-paste-shortcuts-2026-09-25.md)。
- 设置窗口中的“快速粘贴快捷键”默认关闭（旧数据若未明确保存该开关也按关闭处理）；仅手动开启时注册全局组合键，已明确保存的启停状态保持不变。应用正常监听剪贴板时，Alt+1～Alt+0（数字行或数字小键盘）对应当前分组前十条记录，Ctrl+Alt+1～3 对应当前分组前三条收藏记录；快捷键在外部应用触发后，后台解析槽位、复制记录并沿用受控粘贴的目标窗口、剪贴板序号及修饰键检查。槽位为空会报告错误；组合键注册失败时仅显示失败数量、一条示例及“设置 → 快捷键”的处理入口，不将所有失败逐条铺满历史窗口；`--no-monitor` 和窗口冒烟模式不注册这些全局快捷键。设置窗口可展开普通与收藏两组各 10 个槽位，逐项录制或输入 Ctrl/Alt/Shift 与数字、字母、F1～F24 或常用导航键的组合，也可逐项停用或恢复默认，或按组一次停用全部及恢复全部默认；至少需要 Ctrl 或 Alt，不接受 Win、重复组合或与唤出快捷键冲突的组合。新组合注册失败时回退到旧配置；设置保存在 SQLite 并随 GPUI ZIP 备份恢复。按键录制在设置窗口焦点区域完成，Esc 可取消；文本输入可作为录制受键盘布局或系统拦截影响时的备用方式。实际跨应用按键注入和快捷键冲突仍需真实桌面验收。
- 打开设置窗口会在后台统计当前 GPUI 数据占用，分别显示 SQLite 主文件/WAL/SHM、受管图片和暂存载荷的文件数与大小；“刷新”重新读取磁盘，“打开目录”用系统资源管理器打开当前实例实际使用的数据目录。统计跳过符号链接和目录外无关文件，读取失败会显示错误而不返回低估结果。“整理数据库”在后台执行 SQLite optimize、VACUUM 和 WAL 截断，回收已删除记录留下的空闲页，完成后刷新占用统计；整理不删除仍存在的历史或设置。
- 同一数据目录下再次启动程序会唤回已有窗口并退出第二个进程；指定另一数据目录可并行运行隔离实例。不同实例之间全局快捷键仍只能由一个实例注册，冲突会在另一个窗口提示。
- 导入只读访问旧库，使用 SQLite 在线备份获取含 WAL 的一致快照，在新目录升级副本并校验；如果 GPUI 目录已有 `clipboard.db` 就拒绝覆盖。旧版默认数据库位于旧程序可执行文件旁；如旧版 `config.json` 配置了 `data_path`，应指定该目录中的 `clipboard.db`。可用 `--data-dir` 为导入选择另一个空目录。当前界面可浏览默认分组及自定义分组的文本、网址、HTML/RTF、图片和普通文件路径；导入的外部图片与文件保留原路径，导入不会复制原文件。文件记录若仅含旧版虚拟文件载荷而没有可用原路径，不能在新版本复制。不要把开发版的 `--data-dir` 指向旧版数据目录。
- 主窗口“导出备份”保存 v2 GPUI ZIP：在线 SQLite 快照、引用的可读取图片、图标及暂存文件。默认排除非 GPUI 设置（包括旧库潜在的密码或 token）；源资产缺失时显示数量，记录保留原路径。备份不包含普通文件记录指向的原文件，但包含可读取的暂存副本。恢复使用 `elegant-clipboard-gpui --import-backup <备份.zip> --data-dir <空目录>`，兼容 v1/v2；恢复时同样筛除归档中的非 GPUI 设置。在创建暂存文件前拒绝重复归档路径、超过 10 万项或展开后超过 50 GiB 的备份，随后验证格式、数据库与资产引用，并在安装或打包暂存数据库前完成 WAL checkpoint；检查失败则不安装。不覆盖已有数据库或资产目录。恢复期间目标目录不能由其他实例使用。
- 新建库与 GPUI 备份保留内部 URL 和语义哈希迁移完成标记，恢复后不会把已编辑为纯文本的有效链接再次归入网址；旧版备份缺少标记时仍按旧库迁移规则回填。排序、字符数及收藏顺序的新增列与回填在同一事务内完成，失败后回滚并可重试；图片尺寸和来源应用字段逐列补齐，兼容旧版本迁移中断留下的缺列。已有排序值不会在每次启动时无条件重写。
- 旧版 Tauri ZIP 可用 `elegant-clipboard-gpui --import-legacy-backup <旧版备份.zip> --data-dir <空目录>` 导入；它会升级数据库，恢复并重建 `images/`、`icons/`、`staged/` 路径。归档中未包含的外部图片保留原引用并计入报告。原文件丢失时，普通文件记录可使用恢复到 GPUI 目录中的暂存副本进行复制；删除或自动淘汰记录后会清理无引用的暂存副本。旧版虚拟文件的额外剪贴板格式仍不支持写回。单独的旧 `clipboard.db` 仍用 `--import-db`，该方式不会复制外部媒体。两种旧数据导入都只将 GPUI 使用的外观、快捷键和暂停采集设置写入新数据库，旧版专属设置及凭据保留在原来源中。
- 托盘菜单“清理历史”使用 GPUI Kit `Dialog` 明确确认后删除当前分组中未置顶且未收藏的记录；搜索、收藏或类型筛选不缩小清理范围。其他分组及受保护记录保留，本地受管理图片在无引用时删除。操作无法撤销，可先使用“导出备份”。
- 设置窗口的“删除全部历史”另有强确认，删除所有分组中的全部记录，包括置顶和收藏，同时清理无引用的受管图片及暂存副本；主题、快捷键、暂停状态等设置和自定义分组保留。完成后关闭已删除记录的预览并清空批量选择。此操作无法撤销，可先导出备份。
- 单条删除、批量删除和历史清理先提交数据库，再回收无引用的受管文件。文件被占用、权限不足或引用查询失败时，已提交的删除不会撤销，列表仍刷新，通知明确说明记录已删除但部分附件未回收；仍被引用及目录外文件不删除，缺失文件视为已回收。自动淘汰和编辑后的回收失败记录警告，不将已保存记录误报为保存失败。目前没有附件回收重试队列，“整理数据库”也不负责删除残留附件。
- 卡片底部悬停操作区的“选择”或列表中的 Ctrl+A 可进入批量模式。模式内点击整张卡片可切换选择，按住 Shift 点击可按当前已加载顺序连选两者之间的记录，并保留此前选择；取消最后一条选择后仍保持批量模式。批量操作栏“退出多选”清空所选记录并退出模式，Esc 也可退出。批量模式下单条记录的 Enter、Shift+Enter、Ctrl+Enter、Space 和 Delete 快捷键不执行，避免误操作焦点记录。选择至少两条后可按当前列表顺序“合并复制”；文本表示以换行连接，文件和受管图片同时作为去重后的文件路径列表写入，并逐项读回校验。由有效目标窗口热键唤出时按钮变为“合并粘贴”，沿用单条受控粘贴的焦点、修饰键和剪贴板序号检查；目标失效或用户离开窗口后仅保留已复制内容。“删除选中”需再次确认，并会删除所选的置顶和收藏记录。选择仅作用于当前已加载列表，切换搜索、分组或收藏视图会退出批量模式；后台校验列表代次和分组，在同一事务内删除，失败不部分删除，提交后按引用清理受管图片及暂存副本。

- 鼠标停留在历史卡片上达到设置的延时后，会单独请求完整内容并在鼠标所在屏幕内打开悬停预览。图片、文本、网址及 HTML/RTF 默认开启；文件路径默认关闭，设置可分别开关，已保存的开关选择保持不变。设置还可选择 250/500/750/1000ms 延时、自动/左侧/右侧位置、5%/10%/20%/50% 的图片缩放步进，以及默认关闭的“大图使用更大浮窗”；开启后读取历史中保存的图片尺寸，将图片浮窗扩大但限制在当前显示器内，尺寸缺失或无效时保持默认 460×300。设置保存后重启与备份恢复均保留。文本和文件路径可在只读浮窗中滚动查看；图片浮窗支持 Ctrl+滚轮在 50% 至 400% 间缩放。鼠标离开卡片和浮窗后延时关闭；搜索、筛选、批量模式、拖动、点击完整预览和隐藏主窗口会关闭悬停预览。悬停请求与点击预览使用独立响应，过期响应不会重新打开浮窗。图片浮窗大小以及文本、文件悬浮内容与离开后的关闭行为已用隔离数据在桌面窗口验收；跨显示器边界仍需验收。

- 图片和单张图片文件的悬停浮窗提供缩小、百分比重置及放大按钮；缩放范围为 50% 至 400%，按钮使用设置的缩放步进，Ctrl+滚轮仍可使用。隔离窗口已验证图片文件浮窗中 100%→110%→100%→90% 的控件交互，普通图片浮窗也显示同一组控件。

- 常规设置可启用“清理历史免确认”，默认关闭；开启后托盘菜单“清理历史”直接请求清理当前分组未置顶且未收藏的记录。搜索和筛选仍不缩小清理范围。“清空所有记录”和批量删除继续要求确认。设置持久化并随 GPUI 备份保留。
