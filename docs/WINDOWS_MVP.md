# 跨平台 GPUI 应用状态

## 范围

Windows 是主要验收平台，macOS 与 Linux 实现同仓构建（能力差异与验证边界见根 README）。仓库使用单一根 Cargo workspace，包含 GPUI 应用、共享核心和各平台原生实现。

首批功能为文本采集、历史持久化、精确去重、搜索、复制、删除、置顶、暂停/恢复。现已扩展至全局唤出快捷键、HTML/RTF、PNG 图片与普通文件路径的采集、历史、预览与复制，以及经全局快捷键唤出后返回原窗口的受控粘贴。

## 当前实现

- `crates/clipboard-core`：数据库 schema、迁移、仓储和去重源码，提供 UI 无关的文本、HTML/RTF、图片与文件路径历史用例；额外原生格式与内容寻址 blob 存储也属此层。
- `crates/clipboard-platform`：三平台剪贴板事件监听、全局快捷键、托盘与原生格式写回；独立 worker 串行处理历史操作；请求代次、实例锁、重复启动唤出、有界队列和关闭清理。
- `crates/clipboard-gpui`：原生主窗口、搜索、虚拟历史列表、复制/删除/置顶、暂停确认、文本/富文本/图片预览与文件详情、收藏与收藏筛选、分组浏览、拖拽排序、系统托盘和错误反馈。

数据库与去重源码位于 `clipboard-core`；核心不依赖桌面 UI 框架或任何 OS API。

源码模块与维护边界见[工程文档](README.md)。所有 Rust 源码、示例和测试文件上限为 640 物理行，`scripts/check-source-size.ps1` 在 `just check` 与 GPUI CI 中强制检查；拆分按职责而不是编号或文本包含进行。

默认数据目录为 `%LOCALAPPDATA%\ElegantClipboard`。不自动搬迁 2.0 beta 或 1.2.10 以外版本的数据目录和开机启动项；1.2.10 的数据库和 ZIP 可导入到空的数据目录。自动测试使用临时目录、合成文本和仓库内 PNG 样本。

### 内容限制与保留策略

- 单条文本最多 1 MiB；富文本的 HTML、RTF 原始字节与纯文本合计最多 1 MiB。
- 图片最多 2500 万像素、编码 PNG 最多 50 MiB。
- 文件路径列表最多 256 项或 1 MiB，仅保存原始路径，不复制文件实体；启动时移除旧的受管 `staged` 副本及引用，原件移动或删除后明确提示失效。
- 保留策略默认数量 10000、天数 0；显式保存后按各分组限制未置顶且非收藏记录，0 表示关闭相应限制，首次启用或收紧限制需要确认，旧配置不自动扩大清理范围。
- 空白文本不保存。重复的完全相同文本移动到顶部，文字和换行原样保存。队列满时报告采集失败，不把不同复制事件主动合并成最后一条。

### 采集与原生格式

监听线程在五类主格式之外用 `EnumClipboardFormats` 枚举全部原生格式（内置常量黑名单过滤 OLE/Shell/Chromium 内部格式、隐私标记与已由主采集表示的格式），逐条存入 `native_formats` 表（主键 item_id+format_name）。超过 64 KiB 的格式数据以内容寻址方式落盘 `blobs/<hash>`（zstd 压缩、pending→commit 两阶段），单格式 8 MiB、单次采集 32 MiB 上限，超限跳过并提示。

复制历史记录时（Original 模式）额外格式随主格式写回剪贴板：富文本在单 guard 会话内按 text→html→rtf→extras 顺序写入；纯文本路径以独立 NoClear 会话追加；图片 Original 复制在打开剪贴板前生成 24 位 CF_DIB，单 guard 写 CF_DIB + PNG + CF_HDROP（内容寻址 `image_tmp/<hash>.png`），拖拽同样携带这份现成位图，image_tmp 在 worker 启动时清扫（超过 24 小时或 64 个）。

监听采集（deferred=true）先进 300ms 瞬时确认窗口：到期时序列号未变或被自身写回取代则入库，重读为空或内容不同则丢弃，重读失败顺延 250ms 最多 3 轮；测试与 smoke 注入 deferred=false 绕过窗口；开关 `gpui_transient_filter` 默认开启，在数据设置页切换。

相同纯文本（text/url/html/rtf，默认分组）再次复制时合并进既有条目：补缺 html/rtf 列、仅 text 目标升级类型、byte_size 重算、置顶，并在 `content_hash_aliases` 记录别名；`touch_by_hash` 在默认分组作用域内解析别名。

五个删除路径（单删/批删/清空当前组/清空全部/保留策略）在提交数据库行删除前收集 blob 引用与别名，提交后由 cleanup_media 回收无引用 blob 并用 purge_stale_aliases 兜底；GPUI 备份 v2 增加 blobs 资产类别与 missing_blobs 计数，恢复原样重放（文件名即内容哈希无需重映射）。

### HTML 悬停预览

HTML 条目的 `PreviewContent::Html`（优先 StartFragment 片段）经 `htmd` 转换为 Markdown 后，由 GPUI Kit `TextView::markdown` 在悬停浮窗渲染，避免旧 `TextView::html` 的行内代码段落共享元素状态导致文字丢失。正文不设固定宽度上限：复用纯文本字形测量估算 Markdown 源文本的首选宽度，在每个预览实例内缓存，再按主窗口旁的可用空间收缩；显示与隐藏测量使用相同确定宽度，避免不定宽容器逐字换行。长文通过来源卡片上的 Ctrl＋滚轮滚动。数据库与复制/粘贴仍使用原始 HTML；复杂 CSS、HTML 专属布局不保真，转换失败明确显示错误。列表卡片与搜索仍用纯文本；RTF 与缺 html_content 的旧数据回退纯文本。

## 依赖策略

当前使用 [GPUI Kit 稳定版 0.9.1](https://crates.io/crates/gpui-kit/0.9.1)，配套 `gpui-base`、`gpui-component`、`gpui-component-macros` 及 `gpui-kit-assets` 均为 0.9.1，默认 `gpui-pre-*` 后端为 0.3.12。通过 `cargo update -p gpui-kit --precise 0.9.1` 定向更新锁文件，配套分词依赖解析为 ICU 2.4；不切换可选后端，不升级无关直接依赖。

## 功能与交互

### 列表与搜索

- 历史列表一次取回当前筛选的全部记录，不按页截断；GPUI Kit `VirtualList` 按记录实际高度只渲染可见行，保留滚动、键盘定位和边缘拖动。
- 搜索等待 150ms 后查询，支持中文与字面 `%`/`_`；回车复制当前选中结果。卡片摘要高亮命中词；若词只存在于文本正文较深位置，卡片改显示第一处命中附近的片段并高亮。匹配按 Unicode 字符逐个比较且不区分大小写。搜索片段在后台生成，列表快照不携带全文；悬停预览、编辑和复制仍按 ID 读取原文。
- ↑/↓ 逐条选择，PageUp/PageDown 翻页，Home/End 跳首尾，←/→ 切换分类，Ctrl+←/→ 切换分组，Enter 复制或粘贴，Ctrl+Enter 明确粘贴到原窗口，Delete 删除，Ctrl+F 聚焦搜索。搜索框按 ↓ 聚焦列表首条；首条按 ↑ 返回搜索框。
- 离开首屏且还能再滚过一屏时，右下角显示"返回顶部"按钮，点击 300ms ease-out 回顶；滚轮、键盘或滚动条操作可打断。
- 静态列表图片按卡片尺寸×DPI 在后台生成缩略图，最多两个在途任务，缓存随可见行及前后四行回收；GIF/WebP/APNG 沿用原显示路径，悬停预览、复制和导出仍使用原图。外部文件每约 5 秒后台核对大小/修改时间，无变化不重解码；隐藏 30 秒释放列表缓存。单次静态解码预算 128 MiB，缩略图单边上限 2048 像素。

### 卡片操作

- 单击卡片非按钮区域：有有效原窗口目标时执行受控复制后粘贴，否则复制供手动粘贴。批量选择模式下点击切换选择，Shift 点击连选；拖拽和单条操作按钮在该模式关闭。
- 悬停卡片时，选择、收藏、置顶、移动分组和删除按钮以独立操作栏淡入右上角；底部信息行始终显示时间、大小及来源应用。
- 右键菜单按记录类型变化：复制、返回原窗口粘贴、纯文本或路径操作、文本与备注编辑、收藏、置顶、移动分组和删除；图片及文件还可在资源管理器中定位或另存为。
- Esc 依次关闭卡片菜单、取消拖动或确认、退出批量选择、隐藏窗口到托盘；复制后粘贴处理中不隐藏。
- Shift+Enter 使用已保存纯文本表示；HTML 缺少纯文本时转换实体、段落和表格分隔；图片、文件及没有可转换文本的 RTF 明确报错。

### 分组与分类

- 分类栏提供"全部/收藏/文本/图片/链接/其他"，新配置默认只显示全部、收藏、其他；分类归属在写入时计算并保存，一条记录可同时属于多个分类。分类与分组独立组合，搜索与数量均由后台按分组、分类和关键词交集查询。
- 分类栏在"收藏"后提供"待办"：添加和编辑打开独立文本编辑窗口，Markdown 预览只在编辑窗口内；点击勾选完成，已完成项排在未完成项之后。待办保存在本机数据库，不进入剪贴板历史，也不受分组、采集和保留策略影响。
- 分组下拉与分类标签同行，默认分组固定首位；新建和编辑分组通过 GPUI Kit `Dialog` 填写名称，删除入口在编辑弹窗内，确认后组内记录移到默认分组。每张卡片的"分组"按钮可将记录移到其他组；新采集内容仍进入默认分组。
- 拖动排序：同一置顶分区内可排序，跨分区不改变置顶状态；其他卡片 300ms ease-in-out 让位，列表边缘自动滚动，Esc 取消。持续按住左键拖出主窗口转为 Windows OLE 复制拖放，透明置顶浮窗保持原尺寸与抓取点；不写系统剪贴板，不提供移动或链接效果。

### 批量选择与序列粘贴

- 卡片"选择"或 Ctrl+A 进入批量模式；至少两条后可"合并复制"（文本换行连接，文件和受管图片作为去重路径列表写入并逐项读回校验）。由有效目标唤出时按钮变为"合并粘贴"。
- "删除选中"需再次确认，会删除所选的置顶和收藏记录；切换搜索、分组或收藏视图退出批量模式。
- 序列粘贴（决策 0004）：多选后逐条粘贴到原窗口，首条立即受控粘贴，其后按全局推进键（默认 `Ctrl+Shift+G`，可录制/停用）逐条送出，队列耗尽自动结束。离开面板、复制、合并或删除操作取消队列。

### 受控粘贴与快捷键

- 从目标应用按全局快捷键唤出后，卡片"粘贴"先复制、隐藏历史窗口，再向原窗口发送 Ctrl+V 或 Shift+Insert（可选）。离开历史窗口清除原目标；托盘唤出或目标失效时仅能手动复制。
- 修饰键按住时异步等待最多 2 秒，每 20ms 核对目标身份、前台和剪贴板序列，松开后才发送；超时、目标变化、序列变化或按键注入失败明确提示手动粘贴。新复制请求或重新唤出窗口取消旧投递任务。
- 普通文本、图片、文件及富文本均读回校验后才确认写入；Windows 无法从按键注入返回值确认目标已完成粘贴，成功提示仅表示已发送快捷键。
- `Alt+C` 唤出时按住 Alt 反复按 C 可依次唤出/隐藏；Alt 仍按住时直接聚焦窗口，不注入 Alt 松开事件。
- 快速粘贴快捷键默认关闭：Alt+1～Alt+0 对应当前分组前十条记录，Ctrl+Alt+1～3 对应前三条收藏记录；可逐项录制/停用或按组恢复默认。投递节奏分**受控**（默认，等待修饰键松开）与**连贴**（修饰键按住时可连按槽位）。

### 窗口与托盘

- 主窗口隐藏原生和 Kit 标题栏；搜索框上方 30 px 握柄区域可拖动窗口，顶部边缘由 Windows 处理缩放。底部 28 px 记录数量栏也可拖动。
- 关闭窗口隐藏到系统托盘；左键托盘图标和全局快捷键切换显隐，最小化时恢复。右键菜单固定提供清理历史、窗口置顶（勾选态）和设置。
- 未置顶时点击应用外隐藏到托盘；悬停浮窗及设置窗口不触发隐藏，设置窗口打开或粘贴处理中不自动隐藏。
- 托盘置顶项使用 Windows topmost 窗口层级；开启后受控粘贴时窗口保持可见但键盘焦点交回目标应用。
- 独立设置窗口初始内容区 800×560，最小 700×420；主窗口"记住窗口大小"默认开启，保存最后一次普通窗口内容区尺寸。唤出位置可选跟随光标、屏幕居中或保持上次位置。
- Windows 主窗口隐藏创建，第一次唤出先应用尺寸、再定位、显示和激活，所有原生变更在 GPUI 借用之外执行，避免旧位置先可见或 `RefCell already borrowed` panic。

### 设置窗口

按常规、显示、待办、外观、数据、应用过滤、音效、快捷键和关于分页导航；使用 GPUI Kit `Settings`/`SettingPage`/`SettingGroup`/`SettingItem` 与全宽 GroupBox。

- **常规**：清理历史免确认（默认关闭）；暂停记录/恢复记录持久化，重启后先恢复状态再启动监听。
- **显示**：隐藏分类筛选栏；紧凑/标准/宽松三档卡片密度；卡片预览行数 1–10；时间、字符数、大小和来源应用分别显隐；时间可选绝对或相对格式。来源图标在后台提取并缓存为 PNG，随备份导出恢复。
- **外观**：跟随系统/浅色/深色主题；内部组件圆角可选跟随系统（新用户默认）、关闭、4px、16px，不修改原生窗口圆角；卡片圆角独立偏好 `gpui_card_corner`（half/global/off）。背景材质按 Windows build 提供无/毛玻璃/云母（22621 起全部，17763–22620 兼容亚克力，更早或未知仅不透明）；背景浓度 0–100，默认 72，只控制外壳底色。macOS 毛玻璃使用 NativeBlur 后端；Linux 仅不透明。
- **数据**：数据占用统计（SQLite 主文件/WAL/SHM、受管图片和暂存载荷的文件数与大小）、刷新、打开目录、整理数据库（optimize + VACUUM + WAL 截断）、导出备份；旧数据库、旧 ZIP、GPUI 备份导入恢复，必须选择独立空目标目录。
- **应用过滤**：黑名单/白名单规则，按来源应用名、进程名及完整路径匹配，`*` 与 `?` 通配；可手工添加或从当前可见窗口的运行中应用列表选择。过滤仅作用于后续自动采集。
- **音效**：历史复制和受控粘贴的短音分别启停，可选"立即"或"成功后"播放；复制音效覆盖普通、纯文本、路径和批量合并复制。音频设备不可用时不阻止复制或粘贴。
- **快捷键**：唤出热键（新用户默认 `Alt+C`）可输入或录制 Ctrl/Alt/Shift/Win 组合，冲突拒绝并恢复，保存失败回滚；自动粘贴按键可选 Ctrl+V 或 Shift+Insert；快速粘贴槽位与序列粘贴推进键逐项录制或停用。
- **关于**：应用版本、作者、作者主页、项目仓库和问题反馈入口；使用 Windows 默认浏览器打开固定 HTTPS 链接。

### 采集与隐私控制

- "监听内容类型"分别切换文本、网址、HTML、RTF、图片和文件的自动采集，至少保留一种；富文本含多个格式时保留已启用格式。
- "采集格式"默认只读取名单中的剪贴板格式名；"读取全部格式"打开后忽略名单。名称必须是剪贴板实际格式名，隐私标记即使在名单中也不会保存。
- 采集前尊重 `ExcludeClipboardContentFromMonitorProcessing` 和 `CanIncludeInClipboardHistory` 的本地历史限制；只禁止云同步的标记不阻止本地记录。
- "隐藏时重置搜索、筛选和滚动"默认关闭：开启后隐藏时清空搜索、回到全部记录和默认分组并滚到顶部；隐藏时总是退出未提交的批量选择。
- "唤出时清空搜索"默认开启；"唤出时聚焦搜索"默认关闭。

### 文件卡片

- 单张图片文件在历史卡片、完整文件详情及悬浮浮窗中显示图片，保留文件名、原始路径和大小；仅预览确认存在、元数据可读且大小已知的 PNG/JPEG/GIF/WebP/BMP，本地路径上限 50 MiB、UNC 路径上限 10 MiB。
- 任一原始路径不存在时列表标题显示红色"源文件已失效"；无法读取元数据或路径无效时显示"文件无法读取"。检查结果按记录 ID 和路径内容缓存，本地路径先完成，网络路径随后返回。
- 文件卡片用警告、普通文件和文件夹图标区分失效、单文件、文件夹与多文件；多文件卡片显示前 3 个文件名，仅全部路径可读时显示真实总字节数。

### 悬停预览

- 鼠标停留达到设置延时后请求完整内容并在鼠标所在屏幕内打开透明穿透绘制层：文本、网址及 HTML/RTF 与图片默认开启，文件路径默认关闭。延时可设 100–2000ms，位置自动/左/右，图片缩放步进 5–50，"大图使用更大浮窗"默认关闭。
- 图片初始适配 480×480，Ctrl＋滚轮在 50%–400% 间缩放；文本和文件路径可滚动查看。鼠标离开卡片和浮窗后按 600ms 宽限关闭；搜索、筛选、批量模式、拖动、打开编辑和隐藏主窗口会关闭预览。
- 预览覆盖来源显示器工作区，窗口隐藏创建、明确选择显示器、在 GPUI 借用之外完成定位和无框/不激活/穿透配置；图片、文本/HTML、文件内容、备注、连接线和信息标签绘制在同一层。类型、大小、分辨率/缩放比例、来源及操作提示以外部信息标签呈现；"存储格式"表示历史文件编码，"数据格式"读取采集时记录的原生格式名称（Windows 保留 CF_* 和注册格式名，macOS/Linux 保留 UTI/MIME 名）。

### 文本编辑

- 文本类记录从右键"编辑"打开独立编辑窗口，使用带行号、字体跟随界面的编辑器；保存后保留记录 ID、分组与收藏状态并刷新搜索结果。修改富文本转为纯文本（保存前提示），空内容保存报错；Esc 取消且不写入，保存中禁止关闭；Ctrl+S（macOS ⌘S）保存。
- 备注使用主窗口内短对话框编辑，2000 字符上限，参与 LIKE 搜索。

### 粘贴后选项

- "粘贴后隐藏"默认开启；选择保持可见时仍将键盘焦点交给目标窗口。
- "粘贴后移到首位"默认开启；已置顶记录不改变顺序，合并粘贴不触发单条排序，仅在成功发送粘贴快捷键后调整。
- "粘贴后恢复原剪贴板"默认关闭（`gpui_restore_clipboard`）：受控粘贴的 Original 写回前由 worker 暂存快照，粘贴送达后写回并抑制自捕获。
- 去重策略切换（`gpui_dedup_strategy`）：move_to_top 默认 / always_new 跳过哈希触碰与同文合并。
- 文本转换复制/粘贴（CopyMode::Transform）：去首尾空白、去换行、大小写；富文本可按单一格式复制/粘贴（CopyAsFormat：纯文本/HTML/RTF，缺少所选格式报错不降级）。

### 首次引导

空数据目录首次打开时，在主窗口显示三步原生引导：设置唤出快捷键（真实配置与注册状态，可编辑/录制/保存）、体验搜索与粘贴（独立内存演示数据，不读写系统剪贴板或真实历史）、选择使用偏好（主题、圆角、开机启动与搜索聚焦）。无跳过入口，引导不响应 Esc；完成状态写入 SQLite 后才关闭，失败可重试。已有历史自动标记已完成；设置→关于可在同一主窗口重看。

### 数据导入与备份

- 导入只读访问旧库，使用 SQLite 在线备份获取含 WAL 的一致快照，在新目录升级副本并校验；GPUI 目录已有 `clipboard.db` 则拒绝覆盖。导入的外部图片与文件保留原路径。
- 打开数据库只接受当前结构和 1.2.10：1.2.10 已有当前列且没有 2.0 表时只补 `note`，再由 schema 创建新表；更早的 1.x 及其他 2.0 beta 拒绝打开，不改原文件。
- `--import-db` 导入单独的 1.2.10 `clipboard.db`（不复制外部媒体）；`--import-legacy-backup` 导入 1.2.10 Tauri ZIP（补备注列并创建 2.0 新表，重建 `images/`、`icons/`；旧 `staged/` 跳过且引用移除）。
- "导出备份"保存 v2 GPUI ZIP：在线 SQLite 快照、引用的可读取图片、图标和原生格式 blob；默认排除非 GPUI 设置（包括旧库潜在的密码或 token），源资产缺失时显示数量。恢复用 `--import-backup <备份.zip> --data-dir <空目录>`，兼容 v1/v2；创建暂存文件前拒绝重复归档路径、超过 10 万项或展开后超过 50 GiB 的备份，随后验证格式、数据库与资产引用并完成 WAL checkpoint，检查失败不安装。
- 同一数据目录下再次启动唤回已有窗口并退出第二个进程；指定另一数据目录可并行运行隔离实例，不同实例间全局快捷键只能由一个注册。

### 删除与清理

- 托盘菜单"清理历史"经 Dialog 确认后删除当前分组中未置顶且未收藏的记录；搜索、收藏或类型筛选不缩小清理范围。
- 设置窗口"删除全部历史"另有强确认，删除所有分组中的全部记录（含置顶和收藏），同时清理无引用的受管图片及暂存副本；设置和自定义分组保留。
- 单条删除、批量删除和历史清理先提交数据库，再回收无引用的受管文件；回收失败明确说明记录已删除但部分附件未回收，仍被引用及目录外文件不删除，缺失文件视为已回收。

### 诊断日志

默认启用数据目录下 `logs` 中的会话日志：`application.log` 同步写入、4 MiB 轮转、最多三份备份，仅清理符合生成规则且未被进程持锁的旧会话，保留最近五个非活动会话。Rust panic 绕过普通日志互斥锁，独立写入并同步 `panic.log`，包含时间、线程、代码位置及强制堆栈；普通事件与 panic 文件各有 1 MiB 上限和截断标记，panic 消息另限 64 KiB。原始剪贴板正文、搜索词、图片像素和分组名不主动记录；异常字符串可能带本机路径。Windows fail-fast、进程强杀和断电不保证触发 panic hook。

## 验证命令

在仓库根目录运行：

```powershell
.\scripts\check-source-size.ps1
cargo fmt --all -- --check
cargo check --workspace --all-targets --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
cargo build -p elegant-clipboard-gpui --release --locked
cargo run -p clipboard-platform --example isolated_clipboard_smoke --locked
.\scripts\package-gpui-windows.ps1
```

日常使用与调试：

```powershell
# 正常使用：启动原生窗口并记录后续复制的受支持内容
cargo run -p elegant-clipboard-gpui --locked

# 隔离检查：禁用采集，只浏览指定目录中的历史
cargo run -p elegant-clipboard-gpui --locked -- --no-monitor --data-dir .\target\gpui-check

# 窗口冒烟：禁用采集，约 3 秒后自动退出
cargo run -p elegant-clipboard-gpui --locked -- --smoke-test --data-dir .\target\gpui-smoke

# 从旧版数据库导入到尚无 clipboard.db 的 GPUI 数据目录；命令完成后退出
cargo run -p elegant-clipboard-gpui --locked -- --import-db "C:\旧版目录\clipboard.db"
```

打包脚本仅接受 Windows x64 MSVC 构建，使用锁定依赖生成 `target/packages/ElegantClipboard-v<版本>-windows-x64.zip` 与同名的 NSIS `*-setup.exe` 及各自 `.sha256`。压缩包含 exe、许可证和运行说明；安装包为当前用户安装，目录是 `%LOCALAPPDATA%\Programs\ElegantClipboard`，与数据目录分开，卸载不删除历史数据。两者均未经签名，不包含自动更新。

Windows CI 包含源码行数限制、fmt、all-targets check、Clippy、locked 测试、独立窗口站剪贴板往返 smoke 和应用 Release 构建。剪贴板 smoke 在写入前拒绝交互窗口站 `WinSta0`，使用临时数据库；CI 步骤设置 5 分钟超时。

Windows 常驻资源可用 `scripts/measure-gpui-idle.ps1 -ProcessId <GPUI 进程 ID> -OutputPath <CSV 路径>` 采样，默认持续 8 小时、每分钟记录私有内存、工作集、句柄、线程和累计 CPU 时间；脚本只观察进程，执行前应使用独立数据目录并关闭采集与全局快捷键。

历史验收记录见 `evidence/` 目录；界面间距与动画规则见 [UI 规范](UI_GUIDELINES.md)；各阶段实现决策见 `decisions/`。
