主窗口回到原来的操作顺序

顶部
搜索框 + 清理历史 / 多选 / 固定窗口 / 设置。搜索中的 × 只清文字；清理历史是独立操作。空白可拖窗。
批量栏
仅多选时出现：选择数、合并、删除、取消。Shift 连选，Ctrl+A 选已加载记录，明确范围。
历史列表
单列虚拟卡片，记录置顶优先。中部即时单击粘贴，左右拖动。悬停右上角显示置顶、收藏、复制、删除。
底部
全部 / 收藏 / 文本 / 其他 + 分组下拉固定显示。分组、分类、搜索可组合，默认分组不是所有分组汇总。

文本类编辑统一从右键进入独立窗口；移除默认双击编辑及其单击等待。新目录默认 Alt+C、文本三行预览、128 ms 悬停；既有保存偏好不被覆盖。

默认策略与明确例外

新目录沿用原版基础默认

  • 每组 10,000 条普通历史、30 天清理。
  • 文本类 1,024 KiB，图片 51,200 KiB。
  • 重复移顶、文本语义匹配；置顶与收藏受保护。
  • 数量 0 为用户数量不限，天数 0 为不按天清理；资源保护边界仍有效。

升级不自动删旧数据

  • 已有 GPUI 缺少清理天数设置时，保持按天清理关闭。
  • 已有热键、预览与显示设置保留。
  • 删组仍把记录移回默认组，不恢复级联删除。
  • 较丰富富格式不得被较少格式覆盖；暂存状态与支持格式明确报告。

按可验收结果推进

M1

恢复原版主窗操作

顶部四入口、底栏、即时单击、右键与多选、分组 × 分类 × 搜索、窗口固定、自由主热键、活动组采集上下文。

验收：中文/英文与最小窗口无重叠；组合查询正确；单击无等待；固定后保留窗口并交回焦点；记事本/浏览器文本往返。

M2

补齐内容和数据规则

去重三策略、语义/严格匹配、数量/天数/大小限制；文件暂存和格式；图片类型判定；统一资源状态与执行预检；独立编辑窗。

验收：跨格式/跨组/保护记录隔离测试，原件删除后的暂存回退，超限和失效反馈，Office/浏览器、图像应用与 Explorer 往返。

M3

完成迁移与设置闭环

GUI 导入恢复、基础旧设置转换报告、目录迁移、明确清理范围和八页设置持久化。

验收：旧 DB、旧 ZIP、GPUI ZIP；中文路径、缺媒体、已有目标、损坏归档和失败回退。先临时目录校验，再切换实例；不覆盖来源。

M4

验收当前版本并发布

自动门禁、当前 HEAD 隔离剪贴板、真实应用矩阵、IME/高 DPI/多屏、8 小时常驻与负载、休眠唤醒、万条混合历史、具体 ZIP 和 CI 记录。

验收：关联提交与制品校验和；基础能力有证据；列明环境未覆盖项。先出预览版，完成门槛后发布 2.0.0。

基础完成后再扩展

WebDAV、网络互传、翻译、插件、脚本、Win+V 接管、内置提权、ARM64、安装器、自动更新、瀑布流、繁中和高级外观均后置。已有音效、应用过滤和统计继续保留。

不承诺任意自定义格式或通用虚拟文件恢复；复制文件路径、保存描述符与保存实际文件内容是不同能力。

实现与验证的边界

当前基线通过 fmt、全目标 check、Clippy、229 项测试（另 2 项忽略）及 release 构建。这些结果不代表新计划完成；历史验收也不自动代表当前 UI 通过。

原窗口无效时明确退回复制。Windows 接受模拟按键，只证明按键已发送，不证明目标应用完成粘贴。数据恢复在临时目录校验，目录迁移失败可回退；有未保存编辑时确认放弃。
