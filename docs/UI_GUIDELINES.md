# GPUI 基础界面规则

全应用参考 Chakra 的语义颜色、组件层级与动效时序，以 `crates/clipboard-gpui/src/design_system.rs` 配置官方 GPUI Kit 主题；`visual.rs` 管理公共间距、入场与拖动。页面读取主题语义色，不维护局部明暗色表。主窗口与设置窗口复用 `ui/presentation.rs` 的窗口外壳，悬停预览使用共享透明绘制层。内部组件圆角新用户默认跟随系统，可选跟随系统、关闭、4px、16px；已有明确保存的值保留，所有选项均不得修改原生窗口圆角。

## 组件选用约束

界面使用 GPUI Kit。开发或修改 UI 控件时，先查阅 [GPUI Kit 官方组件目录](https://gpui-kit.com/zh-CN/component)；目录提供的组件必须使用官方实现，不得另造同类控件或引入另一套组件库。目录未提供的应用专属内容和布局可使用 GPUI 原语实现；该规则不要求把业务界面强行套入无对应功能的组件。

已使用的目录控件包括 [`VirtualList`](https://gpui-kit.com/zh-CN/component/virtual-list)、[`Dialog`](https://gpui-kit.com/zh-CN/component/dialog)、[`Scrollable`](https://gpui-kit.com/zh-CN/component/scrollable)、[`Accordion`](https://gpui-kit.com/zh-CN/component/accordion)、[`Alert`](https://gpui-kit.com/zh-CN/component/alert)，以及 Kit 的按钮、输入、勾选、选择、分类标签、图标、图片、快捷键、状态栏、设置页与图表。历史卡片点击/拖放区、窗口拖动热区、缩放画布、状态文字和布局不是独立的通用控件；使用 GPUI 原语承载业务内容，图片缩放容器的底层 GPUI 滚动配合 Kit 滚动条。

| 部位 | 规则 |
|---|---|
| 内容左右边距 | 12 px；搜索、筛选、列表和状态栏对齐；控件默认使用当前主题圆角，面板不另设固定圆角 |
| 控件焦点 | 全局关闭额外的粗焦点外环（`Theme::focus_ring = false`）；保留官方控件的细边框变色和无边框控件的 1 px 焦点线，保持键盘焦点可辨识，不逐个控件禁用焦点样式 |
| 历史行高度 | 使用 GPUI Kit `VirtualList` 渲染可变高度记录，并保留像素滚动位置及可见范围导航；标准密度默认两行文本为 96 px、图片为 124 px，预览行数超过两行每行增加 20 px；紧凑/标准/宽松密度的卡片四边内边距分别统一为 8/10/12 px。文本正文、媒体预览和标题从同一左上内边距起排，元信息沿底边排列；图片和文件卡片使用左侧缩略图或图标、右侧标题与元信息的横向层级 |
| 行内按钮高度 | 24 px；右上角管理操作栏仅保留选择、收藏、置顶、移动分组和删除，采用 28 px 高的独立 popover 底色、细描边和轻阴影；顶部与右侧使用卡片内边距。仅鼠标悬停卡片时淡入，离开后淡出；选中不触发显示，拖动期间隐藏，完全透明后不参与命中。选中态跟随鼠标悬停与键盘导航同一目标，拖拽与批量模式下不因悬停变化。底部时间、大小及来源始终保留；复制、粘贴、路径和纯文本操作通过卡片点击、快捷键或右键菜单提供 |
| 删除与返回顶部 | 卡片及右键菜单删除使用官方 Lucide `Trash`；返回顶部使用 36 px 的 Kit 中性 outline 图标按钮、`ArrowUpToLine`、主题圆角及轻阴影。按实际滚动偏移显示：向下超过 32 px 才出现，回顶后隐藏，不再根据记录条数常驻；点击使用 300ms ease-out 平滑回顶，滚轮、键盘导航或滚动条改动可打断，减少动态效果时立即回顶 |
| 主窗口边框 | 主窗口隐藏原生和 Kit 标题栏与系统标题栏按钮；搜索框上方 30 px 区域有居中浅色短横握柄，按住握柄或其左右空白处拖动窗口，紧邻窗口上边缘的缩放热区仍由 Windows 处理。记录数量固定显示在列表下方的 28 px 底栏，不随列表滚动，该区域也可拖动窗口，“返回顶部”按钮不作为拖动区。Esc 与托盘菜单控制窗口显隐；独立设置窗口仍使用 GPUI Kit TitleBar |
| 窗口骨架 | 主窗口与独立设置窗口通过 Kit `open_window` 创建，由 Base Root 承载 Dialog 等浮层；悬停预览使用原生 GPUI 窗口，避免 Root 边框阴影。悬停预览统一无标题栏与白色外框：文本/HTML 按内容测量尺寸并支持滚动，图片按原图比例布局，不显示文件路径页脚；类型、大小、分辨率/缩放比例、来源及操作提示以外部信息标签呈现。图片内部圆角跟随主题 radius_lg；外围透明区域承载轻阴影，不绘制底色 |
| 窗口材质 | 原生背板只配置在主窗口和设置窗口，外壳绘制一次主题染色；侧栏、分组、列表与引导容器共享该层，不重复涂染。design_system统一投影材质模式的中性控件、分段底槽、悬停/按下/选中、列表/表格行及状态色底面。控件色板只接收明暗主题和材质类型，不接收外壳浓度；不得用“1−浓度”衰减控件底色，否则85%时底槽、输入框及交互状态会消失。Kit输入框（含设置内部搜索）通过background颜色及深色input颜色获取材质底色；background token的可绘制背景另供带固定阴影的分段选中面使用实底，避免阴影透出变灰。主按钮、危险操作、文字、图标与焦点保持语义色和对比度。popover保留不透明表面，所有应用Dialog显式使用popover；菜单、Notification、悬停阅读面、信息标签及浮动操作栏不透出自身阴影。关闭材质恢复原不透明配色与token。浓度只控制外壳底色，不代表系统模糊半径，不改变用户系统透明效果设置 |
| 材质能力与更新 | 根据真实 Windows build 筛选可用材质：22621 起提供所有材质，17763–22620 仅提供关闭与兼容亚克力，更早或版本未知时仅提供关闭。已保存但不支持的选项仍保留为选中、禁用的标签，持久 `Alert` 明确保存值和降级结果，不高亮另一选项或覆写 SQLite。遮罩强度按实际生效效果决定是否可用；只有有效原生后端变化才重新配置窗口，单纯强度变化只广播背景状态并重绘，不关闭悬停预览 |
| 隐藏与唤回 | 未置顶时点击应用外会隐藏到托盘；卡片和操作按钮的点击不冒泡成空白点击。设置窗口打开、粘贴或批量操作处理中不自动隐藏；置顶时保留窗口，但快捷键仍可主动切换显隐。设置窗口关闭后，托盘和全局快捷键须继续响应 |
| 窗口设置 | 默认收起外观、唤出、开机启动与数据维护选项，最小窗口可完整显示首张卡片；“本地数据”的占用摘要和刷新、整理数据库、打开目录、导出备份按钮在宽窗口同一行，空间不足时才换行，摘要文本不截断。普通窗口内容区尺寸自动记忆，最大化和全屏不覆盖该值 |
| 设置界面 | 八页统一使用 GPUI Kit `Settings`、`SettingPage`、`SettingGroup`、`SettingItem` 与全宽官方GroupBox；保留原有保存和禁用逻辑。布局集中在settings_common：settings_stack组织纵向内容，settings_columns及settings_column/settings_column_field按360px首选字段宽度自动分列或回流，settings_inline排列自然宽度的选项与操作；字段和分段标签填满所属列，不再各自限制640px或音效360px。外观的语言/主题、圆角/材质两列成组；显示、去重/恢复剪贴板、保留策略、应用过滤、音效、快捷键沿用同一字段规则。关于页简介与功能说明并列，项目链接横向分组。14px标签、12px说明、16px主要间距、8px字段内间距；常规输入和主操作36px，次要操作32px，数值输入保留合理固有宽度。展开的应用列表与快捷键槽位使用页面滚动，不嵌套固定高度截断；长说明及操作自动换行。每日历史无记录时使用紧凑空态，有记录才显示图表。700×420最小窗口保留正文及侧栏滚动。侧栏初始200px、可调184–224px，分组导航使用简短中英文标题；搜索按页面、分组标题及说明过滤。不以缩小字号、撑高空卡片或隐藏控件消除留白 |
| 设置中的选择项与预览行数 | 多选及其余布尔项使用 GPUI Kit `Checkbox`；开机自启与复制、粘贴音效的启用项使用 Kit `Switch`。窗口位置、外观、悬停预览、列表显示、音效时机及应用过滤等互斥选择使用 Kit `TabBar` 的 Filling Space 等宽标签。唤出快捷键使用 Kit `Input` 编辑或录制，以 `Kbd` 展示，并提供保存、取消和关闭；注册或持久化失败恢复原快捷键。选项保存期间禁用并在后台确认后更新选中态；复制与粘贴音效的播放时机、“试听”按钮和“启用”开关同排，开关位于最右侧，执行操作继续使用 Kit `Button`。卡片预览行数使用 Kit `NumberInput`，编辑提交和加减步进限制在 1–10 行，后台确认后同步显示，保存失败时恢复已确认的值；可展开的快捷键与运行中应用区域使用 Kit `Accordion` |
| 快捷键展示 | 设置中的唤出热键、自动粘贴按键、快速粘贴槽位和录制提示，以及首次引导中的操作键提示，均使用 GPUI Kit `Kbd` 展示按键；置于 Kit `TabBar` 标签内时关闭 `Kbd` 自带底色与边框，沿用标签的选中态文字样式，避免标签中再嵌套灰色徽标。可编辑的快捷键仍使用 Kit `Input` 录入，未设置状态使用普通文本 |
| 首次引导 | 在现有剪贴板面板中提供“设置唤出快捷键”“体验搜索与粘贴”“选择使用偏好”三步，不另开引导窗口，不显示“快速上手”标题行；中英文切换只放第一步正文。使用官方 Kbd、Input、Textarea、Button、TabBar、Switch、Scrollable；不使用步骤指示器，进度由“上一步/下一步”与每步标题传达。标题统一22px半粗、30px行高，说明与标题间距8px；标题和底部导航固定，中间正文独立滚动，右侧为官方覆盖式滚动条保留16px槽位，避免遮挡输入框、按钮及焦点边框，适配400×520。第一步显示真实快捷键配置与注册状态，支持就地编辑/录制/保存；录制按键在应用绑定之前拦截，Esc只取消录制。第二步使用独立内存演示数据，提供真实搜索高亮、共享侧边图片预览、来源卡片Ctrl＋滚轮缩放及文本/富文本转纯文本插入；不读取或改写系统剪贴板，不写入历史，练习框禁用系统复制粘贴。离开步骤、隐藏窗口或关闭引导必须结束录制与预览，延迟悬停不得重开已卸载步骤的浮层。第三步保存主题、开机启动与搜索聚焦并解释本地存储和回贴条件；平台限制及暂停记录按真实状态提示。保存期间禁止导航，只有最后一步“开始使用”可结束；完成持久化失败留在当前页并允许重试。无跳过按钮，Esc不得结束或隐藏引导；真实唤出快捷键仍可切换显隐并保留步骤。设置→关于在同一主窗口重新查看，不清空真实历史；步骤入场遵循统一动效与减少动态效果设置 |
| 状态反馈 | 设置窗口打开时使用官方 [`Notification`](https://gpui-kit.com/zh-CN/component/notification)，由 Root 在右上角显示并自动消失；设置未打开或窗口已失效时，反馈在后台调用各系统通知 API：Windows WinRT Toast、macOS UNUserNotificationCenter、Linux 桌面通知 D-Bus。通知以 ElegantClipboard 自身应用身份发送，实际展示服从系统权限与免打扰设置；发送失败仅记录错误，不递归通知或回退到应用内浮层。剪贴板主窗口及首次引导不显示应用内 toast，不积压旧消息等待设置打开。`StatusBar` 仅显示正在保存排序等持续状态。后台历史、占用、每日统计和运行应用查询成功保持静默；局部校验与持续可操作条件仍使用行内 `Alert` |
| 文本悬停预览 | 文本、网址及 HTML/RTF 与图片默认在悬停 500 ms 后请求完整内容，文件默认关闭。预览纵向对齐当前来源卡片的可见位置，计入虚拟列表滚动偏移，超出屏幕时才夹回可见范围。鼠标停留来源卡片或浮窗时保持打开，包括静止及 Ctrl + 滚轮操作；移除固定 5 秒关闭任务，只有离开两者后才按 600ms 宽限关闭，批量模式不展示 |
| 文本编辑 | 双击文本类记录或从右键“编辑”进入官方 Dialog，保持原卡片 ID 与分组；保存前提示富文本会转为纯文本，空内容需使用独立删除操作；Esc 取消不写入，保存中禁止关闭。备注使用独立编辑入口，主窗口不切换到整页预览 |
| 预览与文件操作 | 悬停预览为透明、鼠标穿透、不抢焦点的桌面绘制层，优先放在主窗口侧边：按自动/左/右设置在两侧空间中选边，放不下时改为中心叠放并整体收缩。图片初始等比适配 480×480，大图模式放开到显示区域的 70%，小图不强行放大；文本/HTML 使用 460×300 基线按内容收缩。来源卡片上 Ctrl + 滚轮缩放图片浮层（上限 2400px 及工作区边界），缩放比例与分辨率显示在外部信息标签，阴影间距与内部圆角不随缩放倍增；无标题栏与文件路径页脚。文本及普通文件预览保留滚动布局；右键菜单入口不变 |
| 动效 | 采用 Chakra 时序：不透明卡片悬停/选中背景与边框通过visual::transition_color在预乘RGBA空间过渡150ms，不沿HSL色相绕行，避免白/灰到蓝色出现绿色中间帧；Windows、macOS、Linux共用该实现。快速反向与重新进入由官方transition从当前插值继续，透明端点的隐藏RGB不参与染色。材质卡片保持即时换色以避免合成边缘，操作栏透明度仍平滑过渡150ms且不移动、不改变行高；明暗主题使用独立动画通道。面板/步骤/预览入场200ms ease-out，拖动让位与排序完成300ms ease-in-out，反向移动从当前显示位置继续。官方TabBar/Switch/Dialog等读取全局动效策略；尊重GPUI reduce_motion，静态模式不挂持续帧；系统背板能力仍依平台处理，不承诺不同系统像素完全相同 |
| 拖放 | 普通模式下整卡正文、图片与信息行可开始拖动，操作按钮保留独立点击；两侧 18 px 握柄仅为可配置提示，批量模式禁用拖动。GPUI Kit `VirtualList` 按实际行高让位，动画使用 prepaint 位移而不改行布局，命中与反向续接使用上一实际绘制帧的共享进度，同一目标内持续悬停不反复换位。浮层保留原尺寸正文、图片与信息栏，Kit 主题背景完全不透明，不显示操作按钮、额外阴影或插入线；源卡片为同尺寸空白占位。松手后保存，同一置顶分区内排序，保存期间保持临时位置。列表上下 32 px 自动滚动区采用 60 ms 节拍；自定义分组顺序由 Select 的上移/下移菜单项保存 |
| 窗口外拖放 | 同一透明、不激活、鼠标穿透的预览浮窗保持抓取点，Windows OLE 使用复制反馈；支持完整 Unicode、已存 HTML/RTF、文件路径和图片文件/DIB，不写系统剪贴板。持续按住返回源窗口可继续排序，回源同时松手由应用会话提交内部排序，Esc 取消。应用会话统一负责松手收尾；预览窗口复用，普通跟随由帧回调驱动，最小化无帧时有低频清理兜底。拖动期间延后同代次历史快照，避免后台刷新挤走源卡片 |
| 富文本复制 | 默认“复制”保留可用富格式；记录菜单中的“纯文本”优先使用已保存文本；缺失时从 HTML 提取可读文本、解码实体并保留段落/表格分隔，无法转换的记录明确报错。图片右键提供“作为文件复制/粘贴”，复用受管图片文件 |
| 批量选择 | 卡片右上角悬停操作栏提供“选择/已选”，列表 Ctrl+A 也可进入多选；整卡点击切换选择。多选操作栏提供“全选已加载 / 退出多选 / 删除选中”，退出时清空选择，删除使用 Kit `Dialog` 二次确认。搜索、分组及收藏视图切换会退出多选；受管媒体在事务提交后按引用清理 |
| 隐私清理 | 当前分组“清理历史”保留置顶和收藏；主窗口使用 Kit `Dialog` 确认当前分组清理；窗口设置中的“删除全部历史”使用 danger 按钮和独立 Kit `Dialog` 强确认，明确覆盖所有分组、置顶与收藏，并说明设置和自定义分组保留 |
| 主界面操作 | 搜索框独占一行，不提供旁侧多选按钮；左右内容边距各 12 px。托盘菜单固定提供清理历史、窗口置顶（勾选态）和设置；清理历史沿用当前分组范围与确认。既有操作入口显隐和顺序配置不再生效 |
| 历史分类栏 | 使用 GPUI Kit `TabBar` 的 Filling Space 分段标签，默认 32 px 高，与分组 Select 一致；分段选中块四周各4px、四项等宽，最小窗口文字完整；搜索 Input 使用官方 Medium（实际 32 px）与 14 px 字号，容器不参与纵向压缩，不使用会退回 24 px 的自定义 Size；全部、收藏、文本、其他四项等宽占用分组 Select 左侧剩余宽度；切换分类保留搜索和左右方向键行为，分组独立于分类，选择自定义组后保留当前分类标签并与搜索取交集；最小窗口不换行 |
| 分组 Select | GPUI Kit `Select` 与分类标签同行，默认分组固定首位；下拉列表依次显示自定义分组和新建入口，选中自定义分组后追加重命名、删除、可用的上移/下移操作。新建和重命名通过窗口中央的 Kit `Dialog` 填写分组名称，背后内容保留 Kit 遮罩；保存成功后关闭，失败时保留输入并在对话框内显示原因；保存期间禁止取消或重复提交。动作不会覆盖选中的组名；分组顺序保存至 SQLite。Kit `Dialog` 在删除前确认名称和记录数，记录移至默认分组。分类栏隐藏时 Select 仍显示 |
| 移动记录 | 每张卡片共用“分组”入口；目标选择栏同样固定 42 px 并横向滚动，后台确认后才从当前列表移除记录 |
| 数据管理 | 导入/恢复使用原生路径选择器，要求独立空目录；成功展示记录和附件报告并提供打开操作，不覆盖活库。保留策略使用 Kit NumberInput，首次保存及收紧限制通过 Kit Dialog 确认。普通文件仅记录原始路径，不提供文件副本设置 |

动效只传达操作状态，最终顺序以数据库确认后的快照为准，保存失败按既有错误流程恢复。拖动不改变置顶状态，也不绘制插入线。分组下拉使用 Kit 标准选中态，重排以后台确认后的列表顺序为准。滚动列表保留虚拟渲染，完整正文在悬停、文本编辑或准备外拖载荷时读取。

列表搜索片段在后台生成，界面只保存显示摘要并计算摘要高亮；复制、编辑和完整预览仍按 ID 读取原文。上下键采用最近可见滚动，目标已在视口内时不移动列表；Home/End 与翻页保留各自定位策略。静态列表图片按卡片尺寸与 DPI 在后台生成缩略图，最多两个任务并发，缓存保留可见行及前后四行；拖动快照持有图片，离屏后也不会提前释放。GIF、WebP 和 APNG 沿用原图显示路径以保留动画，完整预览、复制和导出始终使用原图。外部文件在后台核对大小与修改时间，过期结果不会回填；隐藏 30 秒释放策略不变。

最小窗口客户区目标为 400 × 520 px，保持搜索、首条记录和状态栏可见；较长列表使用滚动。
