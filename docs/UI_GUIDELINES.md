# GPUI 基础界面规则

全应用参考 Chakra 的语义颜色、组件层级与动效时序，以 `crates/clipboard-gpui/src/design_system.rs` 配置官方 GPUI Kit 主题；`visual.rs` 管理公共间距、入场与拖动。页面读取主题语义色，不维护局部明暗色表。主窗口与设置窗口复用 `ui/presentation.rs` 的窗口外壳，悬停预览使用共享透明绘制层。内部组件圆角新用户默认跟随系统，可选跟随系统、关闭、4px、16px；已有明确保存的值保留，所有选项均不得修改原生窗口圆角。

## 组件选用约束

界面使用 GPUI Kit。开发或修改 UI 控件时，先查阅 [GPUI Kit 官方组件目录](https://gpui-kit.com/zh-CN/component)；目录提供的组件必须使用官方实现，不得另造同类控件或引入另一套组件库。目录未提供的应用专属内容和布局可使用 GPUI 原语实现；该规则不要求把业务界面强行套入无对应功能的组件。

设置复选框和开关统一走 `settings_toggle`：高度 `CONTROL_HEIGHT`，垂直内边距 `TOGGLE_PADDING_Y`，字号 `TEXT_BODY`。与 36px 主操作并排时，调用点把高度覆写成 `CONTROL_HEIGHT_LARGE`。确认对话框统一走 `dialog_shell`、`dialog_title`、`dialog_footer` 和 `dialog_copy`；默认宽度 `DIALOG_WIDTH`，短表单用 `DIALOG_WIDTH_COMPACT`。正文编辑使用独立窗口，不嵌在历史面板对话框里。紧凑按钮、关于页操作和分组菜单行使用 `CONTROL_HEIGHT_COMPACT`。悬停正文行高是 `HOVER_LINE_HEIGHT`，备注行高沿用 `PREVIEW_LINE_HEIGHT`。

已使用的目录控件包括 [`VirtualList`](https://gpui-kit.com/zh-CN/component/virtual-list)、[`Dialog`](https://gpui-kit.com/zh-CN/component/dialog)、[`Scrollable`](https://gpui-kit.com/zh-CN/component/scrollable)、[`Accordion`](https://gpui-kit.com/zh-CN/component/accordion)、[`Alert`](https://gpui-kit.com/zh-CN/component/alert)，以及 Kit 的按钮、输入、勾选、选择、分类标签、图标、图片、快捷键、设置页与图表。历史卡片点击/拖放区、窗口拖动热区、缩放画布、状态文字和布局不是独立的通用控件；使用 GPUI 原语承载业务内容，图片缩放容器的底层 GPUI 滚动配合 Kit 滚动条。

| 部位 | 规则 |
|---|---|
| 内容左右边距 | 12 px；搜索、筛选和列表对齐；控件默认使用当前主题圆角，面板不另设固定圆角 |
| 控件焦点 | 全局关闭额外的粗焦点外环（`Theme::focus_ring = false`）；保留官方控件的细边框变色和无边框控件的 1 px 焦点线，保持键盘焦点可辨识，不逐个控件禁用焦点样式 |
| 历史行高度 | 使用 GPUI Kit `VirtualList` 渲染可变高度记录，并保留像素滚动位置及可见范围导航；标准密度默认两行文本为 96 px、图片为 124 px，预览行数超过两行每行增加 20 px；紧凑/标准/宽松密度的卡片四边内边距分别统一为 8/10/12 px。文本正文、媒体预览和标题从同一左上内边距起排，元信息沿底边排列；图片和文件卡片使用左侧缩略图或图标、右侧标题与元信息的横向层级 |
| 历史置顶标识 | 置顶记录在卡片右上角显示 GPUI Kit 纯文字 `Tag`，使用低对比度主题色底、细描边，以及高对比度的「置顶 / Pinned」文字；标识不使用主按钮的实色填充。普通模式下，悬停操作栏出现时临时让出该角落，标题宽度不跳动；多选和拖拽预览始终显示标识。未置顶记录不留空位；底部信息行不受影响 |
| 行内按钮高度 | 24 px；右上角管理操作栏仅保留选择、收藏、置顶、复制和删除，采用 28 px 高的独立 popover 底色、细描边和轻阴影；顶部与右侧使用卡片内边距。仅鼠标悬停卡片时淡入，离开后淡出；选中不触发显示，拖动期间隐藏，完全透明后不参与命中。悬停只影响预览、高亮和操作栏，不改变键盘当前项；单击仍直接操作被点中的卡片。底部时间、大小及来源始终保留。复制可从操作栏直接写入剪贴板且不粘贴；粘贴、路径和纯文本仍通过卡片点击、快捷键或右键菜单提供。单条复制成功时卡片覆盖淡主色遮罩并弹出较细的勾，500ms 后消失；粘贴、合并和失败不播放。把未收藏的记录标为收藏时播放同样的遮罩和较细的心形，取消收藏不播放。系统减少动效时不显示遮罩|
| 待办卡片操作 | 右上角编辑和移除仅在鼠标位于该卡片上时显示，离开后隐藏；选中（含键盘导航留下的选中）不显示按钮，拖动期间隐藏。进度与时间留在元信息行。Enter、Delete 和 Backspace 只作用于仍在当前筛选结果中的选中项；原选中项消失时清空焦点项，不选中其他记录 |
| 删除与返回顶部 | 卡片及右键菜单删除使用官方 Lucide `Trash`；返回顶部使用 36 px 的 Kit 中性 outline 图标按钮、`ArrowUpToLine`、主题圆角及轻阴影。按实际滚动偏移显示：列表还能再滚过一屏，且当前已经离开首屏时才出现；短列表或滚轮轻拨不弹出。回顶后隐藏，不再根据记录条数常驻；点击使用 300ms ease-out 平滑回顶，滚轮、键盘导航或滚动条改动可打断，减少动态效果时立即回顶 |
| 滚动条 | 继续使用官方Scrollbar/ScrollableElement，共享主题在Kit投影后细化Base滚动条：12px交互轨道，常态/悬停/拖动滑块宽3/6/8px，边缘内缩2px，胶囊圆角，最小长度24px；长度与位置仍由真实滚动范围计算，不人为缩短近一屏内容的滑块。继承系统显示模式，Scrolling模式闲置900ms后用200ms淡出、150ms淡入、180ms宽度过渡；Always模式保持常显，减少动态效果由官方组件处理。主列表轨道位于卡片外侧留白，内容可滚动时阻断鼠标穿透但保留滚轮，进入轨道关闭悬停预览；不足一屏时不显示、不拦截 |
| 主窗口边框 | 主窗口始终隐藏原生和 Kit 标题栏与系统标题栏按钮（不透明/毛玻璃/云母均不绘制）；搜索框上方 30 px 区域有居中浅色短横握柄，按住握柄或其左右空白处拖动窗口，紧邻窗口上边缘的缩放热区仍由 Windows 处理。不显示底部状态栏，“返回顶部”按钮不作为拖动区。Esc 与托盘菜单控制窗口显隐；独立设置窗口仍使用 GPUI Kit TitleBar |
| 窗口骨架 | 主窗口与独立设置窗口通过 Kit `open_window` 创建，由 Base Root 承载 Dialog 等浮层；悬停预览使用原生 GPUI 窗口，避免 Root 边框阴影。悬停预览统一无标题栏与白色外框：文本/HTML 按内容测量尺寸并支持滚动，图片按原图比例布局，不显示文件路径页脚；类型、大小、分辨率/缩放比例、来源及操作提示以外部信息标签呈现。图片内部圆角跟随主题 radius_lg；外围透明区域承载轻阴影，不绘制底色 |
| 窗口材质 | 原生背板只配置在主窗口和设置窗口，外壳绘制一次主题染色；侧栏、分组、列表与引导容器共享该层，不重复涂染。design_system统一投影材质模式的中性控件、分段底槽、悬停/按下/选中、列表/表格行及状态色底面。控件色板只接收明暗主题和材质类型，不接收外壳浓度；不得用“1−浓度”衰减控件底色，否则85%时底槽、输入框及交互状态会消失。Kit输入框（含设置内部搜索）通过background颜色及深色input颜色获取材质底色；background token的可绘制背景另供带固定阴影的分段选中面使用实底，避免阴影透出变灰。主按钮、危险操作、文字、图标与焦点保持语义色和对比度。popover保留不透明表面，所有应用Dialog显式使用popover；菜单、Notification、悬停阅读面、信息标签及浮动操作栏不透出自身阴影。关闭材质恢复原不透明配色与token。浓度只控制外壳底色，不代表系统模糊半径，不改变用户系统透明效果设置 |
| 材质能力与更新 | 根据真实 Windows build 筛选可用材质：22621 起提供所有材质，17763–22620 仅提供关闭与兼容亚克力，更早或版本未知时仅提供关闭。已保存但不支持的选项仍保留为选中、禁用的标签，持久 `Alert` 明确保存值和降级结果，不高亮另一选项或覆写 SQLite。遮罩强度按实际生效效果决定是否可用；只有有效原生后端变化才重新配置窗口，单纯强度变化只广播背景状态并重绘，不关闭悬停预览 |
| 隐藏与唤回 | 未置顶时点击应用外会隐藏到托盘；卡片和操作按钮的点击不冒泡成空白点击。设置窗口打开、粘贴或批量操作处理中不自动隐藏；置顶时保留窗口，但快捷键仍可主动切换显隐。设置窗口关闭后，托盘和全局快捷键须继续响应。Windows主窗口须先在隐藏状态初始化并定位，再显示、激活；不能先显示旧位置或让框架初始placement覆盖新位置。隐藏必须取消待执行的唤出任务 |
| 窗口设置 | 默认收起外观、唤出、开机启动与数据维护选项，最小窗口可完整显示首张卡片；“本地数据”的占用摘要和刷新、整理数据库、打开目录、导出备份按钮在宽窗口同一行，空间不足时才换行，摘要文本不截断。普通窗口内容区尺寸自动记忆，最大化和全屏不覆盖该值 |
| 设置界面 | 八页统一使用 GPUI Kit `Settings`、`SettingPage`、`SettingGroup`、`SettingItem` 与全宽官方GroupBox；保留原有保存和禁用逻辑。布局集中在settings_common：settings_stack组织纵向内容，settings_columns及settings_column/settings_column_field按360px首选字段宽度自动分列或回流，settings_inline排列自然宽度的选项与操作；字段和分段标签填满所属列，不再各自限制640px或音效360px。外观的语言/主题、圆角/材质两列成组；显示、去重/恢复剪贴板、保留策略、应用过滤、音效、快捷键沿用同一字段规则。关于页简介与功能说明并列，项目链接横向分组。14px标签、12px说明、16px主要间距、8px字段内间距；常规输入和主操作36px，次要操作32px，数值输入保留合理固有宽度。展开的应用列表与快捷键槽位使用页面滚动，不嵌套固定高度截断；长说明及操作自动换行。每日历史无记录时使用紧凑空态，有记录才显示图表。700×420最小窗口保留正文及侧栏滚动。侧栏初始200px、可调184–224px，分组导航使用简短中英文标题；搜索按页面、分组标题及说明过滤。不以缩小字号、撑高空卡片或隐藏控件消除留白 |
| 设置中的选择项与预览行数 | 多选及其余布尔项使用 GPUI Kit `Checkbox`；开机自启与复制、粘贴音效的启用项使用 Kit `Switch`。窗口位置、外观、悬停预览、列表显示、音效时机及应用过滤等互斥选择使用 Kit `TabBar` 的 Filling Space 等宽标签。唤出快捷键使用 Kit `Input` 编辑或录制，以 `Kbd` 展示，并提供保存、取消和关闭；注册或持久化失败恢复原快捷键。选项保存期间禁用并在后台确认后更新选中态；复制与粘贴音效卡片按「启用开关、播放时机、试听按钮」纵向排列，时机与试听在音效关闭时禁用，执行操作继续使用 Kit `Button`。界面/卡片/预览字体族使用可搜索的 Kit `Select`，字号步进器用 `NumberInput` 内嵌 `px` 后缀。卡片预览行数使用 Kit `NumberInput`，编辑提交和加减步进限制在 1–10 行，后台确认后同步显示，保存失败时恢复已确认的值；可展开的快捷键与运行中应用区域使用 Kit `Accordion` |
| 快捷键展示 | 设置中的唤出热键、自动粘贴按键、快速粘贴槽位和录制提示，以及首次引导中的操作键提示，均使用 GPUI Kit `Kbd` 展示按键；置于 Kit `TabBar` 标签内时关闭 `Kbd` 自带底色与边框，沿用标签的选中态文字样式，避免标签中再嵌套灰色徽标。可编辑的快捷键仍使用 Kit `Input` 录入，未设置状态使用普通文本 |
| 首次引导 | 在现有剪贴板面板中按“设置唤出快捷键 → 体验搜索与粘贴 → 练习拖拽收藏 → 选择使用偏好”四步展开。标题固定，正文用 GPUI Kit `Scrollable` 独立滚动，底部固定显示当前步数与上一步/下一步；中英文切换只在第一步。支持 320×480；步骤入场沿用统一动效并尊重减少动态效果。第一步支持查看、编辑、录制真实快捷键；第二步使用独立样例练习搜索高亮、图片悬停和缩放、文本及富文本转纯文本插入，禁用系统复制粘贴。第三步在「全部」拖到虚线落点收藏，切到「收藏」重复手势取消；与主列表共用落点样式和松手提示，预览不变淡、不跳位。也可用按钮操作，练习可直接点下一步，不写真实历史、收藏或系统剪贴板。离开步骤或隐藏窗口结束未完成的手势、录制和预览；Esc 只取消练习拖动，不退出引导。第四步配置外观、开机启动与搜索聚焦并说明本地存储；主题色显示当前色样，与设置共用四款预设，宽度不足时用 Kit 下拉菜单显示全名。保存期间禁止导航，最后一步「开始使用」保存成功后进入历史，失败留在当前页可重试 |
| 重看引导 | 从「设置 → 关于 → 重新打开引导」在现有剪贴板面板重新开始；首次引导若尚未结束，则回到当前步骤。重看时最后一步使用底部「退出引导」返回历史，也可按 Esc 提前退出（拖动中先取消手势）。进入、退出或完成重看均不重置已有设置、不修改真实历史，也不重写首次引导的完成状态 |
| 状态反馈 | 搜索框右侧始终保留回贴目标或「仅复制」及条目数（多选时显示已选数，保存顺序时在计数位置显示进度）；目标名过长时省略，可悬停查看全文。短暂反馈使用官方 [`Notification`](https://gpui-kit.com/zh-CN/component/notification)，由 Root 自动隐藏：优先在已打开的设置窗口右上角显示，否则在可见历史主窗底部居中显示，不覆盖回贴状态。两处均不可用时（例如主窗隐藏、最小化或处于首次引导）发送系统通知（WinRT / UNUserNotificationCenter / D-Bus）；发送失败仅记日志。界面已经能看到结果的成功不通知，包括普通设置保存、分组与历史变更、编辑、暂停或恢复记录、打开目录和定位文件，以及进行中的复制与合并。失败、只完成一部分，以及窗口隐藏后仍要用户处理的复制和粘贴结果仍通知。管理员启动要到下次才生效，以及关闭全局快捷键后改从托盘唤出，这两句成功通知保留。后台历史、占用、每日统计和运行应用查询成功保持静默；局部校验与持续可操作条件仍使用行内 `Alert` |
| 文本悬停预览 | 文本、网址及 HTML/RTF 与图片默认在悬停 300 ms 后请求完整内容，文件默认关闭。预览纵向对齐当前来源卡片的可见位置，计入虚拟列表滚动偏移，超出屏幕时才夹回可见范围。鼠标停留来源卡片或浮窗时保持打开，包括静止及 Ctrl + 滚轮操作；移除固定 5 秒关闭任务，只有离开两者后才按 600ms 宽限关闭，批量模式不展示 |
| 文本编辑 | 文本类记录从右键“编辑”打开独立编辑窗口，而不是历史面板内的对话框；卡片单击直接复制或粘贴，不等待双击。编辑窗口可移动、缩放，正文占满剩余高度。正文使用带行号的编辑器，字体和字号跟随界面设置，无卡片描边，滚动条贴窗口右缘。标题栏在窗口按钮左侧提供置顶和眼睛：置顶让本窗口保持在其他窗口之上，眼睛在源码和 Markdown 预览之间切换，默认源码，预览时不显示编辑器。保存后保持原卡片 ID 与分组；保存前提示富文本会转为纯文本，空内容需使用独立删除操作。Ctrl+S（macOS 为 ⌘S）保存；Esc 先交给编辑器关闭查找和多余光标。正文、备忘录和备注有未保存改动时，主动关闭需确认放弃；保存中禁止关闭。独立编辑器不会因主窗新建分组或请求无关删除而关闭。退出、应用内安装更新或管理员重启前，先保存或放弃未完成的编辑。备注仍使用主窗口内的短对话框。主窗口不切换到整页预览 |
| 预览与文件操作 | 悬停预览为透明、鼠标穿透、不抢焦点的桌面绘制层，优先放在主窗口侧边：按自动/左/右设置在两侧空间中选边，放不下时改为中心叠放并整体收缩。图片初始等比适配 480×480，大图模式放开到显示区域的 70%，小图不强行放大；文本/HTML 使用 460×300 基线按内容收缩。来源卡片上 Ctrl + 滚轮缩放图片浮层（上限 2400px 及工作区边界），缩放比例与分辨率显示在外部信息标签，阴影间距与内部圆角不随缩放倍增；无标题栏与文件路径页脚。文本及普通文件预览保留滚动布局；右键菜单入口不变 |
| 动效 | 采用 Chakra 时序：历史卡片的选中底色和描边即时切换，不等待键盘重复触发之间的过渡；不透明卡片的鼠标悬停底色通过 `visual::transition_color` 在预乘 RGBA 空间过渡 150ms，不沿 HSL 色相绕行。快速反向与重新进入由官方 transition 从当前插值继续，透明端点的隐藏 RGB 不参与染色。材质卡片的悬停底色仍即时换色，以避免合成边缘；操作栏透明度继续平滑过渡 150ms，不移动、不改变行高。明暗主题使用独立动画通道。面板/步骤/预览入场 200ms ease-out，拖动让位与排序完成 300ms ease-in-out，反向移动从当前显示位置继续。官方 TabBar/Switch/Dialog 等读取全局动效策略；尊重 GPUI reduce_motion，静态模式不挂持续帧；系统背板能力依平台处理 |
| 拖放 | 普通模式下整卡正文、图片与信息行可开始拖动，操作按钮保留独立点击；两侧 18 px 握柄仅为可配置提示，批量模式禁用拖动。GPUI Kit `VirtualList` 按实际行高让位，动画使用 prepaint 位移而不改行布局，命中与反向续接使用上一实际绘制帧的共享进度，同一目标内持续悬停不反复换位。浮层保留原尺寸正文、图片与信息栏，Kit 主题背景完全不透明，不显示操作按钮、额外阴影或插入线；源卡片为同尺寸空白占位。松手后保存，同一置顶分区内排序，保存期间保持临时位置。列表上下 32 px 自动滚动区采用 60 ms 节拍；自定义分组顺序由 Select 的上移/下移菜单项保存 |
| 拖放收藏与取消收藏 | 拖动历史卡片时，搜索框下的工具栏原位变为等高的虚线落点：普通列表显示「拖到这里收藏」，收藏页显示「拖到这里取消收藏」。只有鼠标指针进入虚线区才高亮落点并提示「松手收藏」或「松手取消收藏」，卡片预览的信息栏同步显示该提示，避免遮住落点时看不到；移出即恢复原信息。预览始终不透明，跟随原抓取点，不吸附或让位。只有在落点内松手才保存。取消收藏不删除历史记录；拖动结束恢复原工具栏。不增加行高、不切换筛选、不改变分组、置顶或历史顺序。重复提交相同状态不刷新列表。主窗口聚焦时，按一次 Esc 只取消当次拖动，不收起面板 |
| 窗口外拖放 | 同一透明、不激活、鼠标穿透的预览浮窗在窗口外保持抓取点，Windows OLE 使用复制反馈；支持完整 Unicode、已存 HTML/RTF、文件路径和图片文件/DIB，不写系统剪贴板。持续按住返回源窗口可继续排序或使用收藏落点，回源同时松手由应用会话按落点收尾；Esc 取消。Windows 拖动中截图遮罩等操作接管输入时，取消当前手势并清理预览与落点，不提交排序或收藏；下一次按下可直接起拖，不必重新唤出面板。预览窗口复用，普通跟随由帧回调驱动，最小化无帧时有低频清理兜底。拖动期间延后同代次历史快照，避免后台刷新挤走源卡片 |
| 富文本复制 | 默认“复制”保留可用富格式；记录菜单中的“纯文本”优先使用已保存文本；缺失时从 HTML 提取可读文本、解码实体并保留段落/表格分隔，无法转换的记录明确报错。图片右键提供“作为文件复制/粘贴”，复用受管图片文件 |
| 批量选择 | 默认按条点选：卡片悬停「选择」、右键「选择」、或 Shift 连选；列表聚焦时按「多选快捷键」（默认 Ctrl+A，macOS Cmd+A；设置→快捷键可录制或停用，空值禁用）进入多选并勾焦点条（无则空选），再按退出多选并清空勾选。方向键移动当前项，描边立即跟随焦点；列表聚焦时按 Space 勾选或取消当前项，卡片底色表示已勾选，不触发复制或粘贴。多选条与分类栏同为 32 px 高，四边内距为 4 px。左右按钮共用字号、高度、描边、最小宽度和水平内距；窄窗口统一收紧尺寸，保持单行。空间不足时长标签可省略，悬停可见完整说明。「反选」翻转当前列表勾选。多选内整卡点击切换；「退出」离开多选。搜索/分组/收藏切换会退出。「删除」用危险色描边提示，仍需 Kit `Dialog` 确认；受管媒体事务后按引用清理 |
| 本地数据 / 清理 | 当前分组“清理历史”保留置顶和收藏；主窗口用 Kit `Dialog` 确认分组清理；设置「本地数据」中的“删除全部历史”为 danger 按钮 + 独立 Kit `Dialog` 强确认，覆盖所有分组/置顶/收藏，并说明设置与自定义分组保留 |
| 主界面操作 | 搜索框独占一行，外框与分类栏同为 32 px 高；点击搜索框内的图标、文字或状态区，或按搜索快捷键，均聚焦输入内容。搜索输入、工具栏操作和菜单选项统一使用 Kit 小字号（0.875 rem），随界面字号缩放；卡片正文和辅助信息保留各自的字号。左右内容边距各 12 px。托盘菜单固定提供清理历史、窗口置顶（勾选态）和设置；清理历史沿用当前分组范围与确认。既有操作入口显隐和顺序配置不再生效 |
| 历史分类栏 | 空间足够时使用 GPUI Kit `TabBar` 的等宽分段标签；所有可见标签放不下时，改用显示当前分类的 Kit 下拉菜单，菜单与按钮同宽，所有启用的分类仍可选择。分类标签、分类下拉和分组触发器共用 Kit 小字号（0.875 rem），测宽与渲染一致；分类栏与分组按钮同为 32 px 高，最小窗口不换行。切换分类保留搜索和左右方向键行为。搜索框保留搜索图标、可用时显示的清空按钮和右侧状态，不重复显示搜索说明图标。分组独立于分类，查询取两者交集 |
| 分组选择 | GPUI Kit `Popover` 与 `Button` 组成分组弹层，与分类栏同行。触发器按当前分组名称测宽，最多占窗口宽度的 40% 且不超过 160 px；菜单与按钮同宽，较长的组名可悬停查看全文。默认分组固定首位，下拉依次显示自定义分组和新建入口，选中自定义分组后追加「编辑分组」及可用的上移／下移操作。新建和编辑通过窗口中央的 Kit `Dialog` 填写分组名称；保存失败保留输入并在对话框显示原因。删除由独立 Kit `Dialog` 确认，记录移至默认分组。分组顺序保存至 SQLite。隐藏历史分类栏时仍保留分组入口，备忘录页不显示分组入口 |
| 移动记录 | 每张卡片共用“分组”入口；目标选择栏同样固定 42 px 并横向滚动，后台确认后才从当前列表移除记录 |
| 数据管理 | 导入/恢复使用原生路径选择器，要求独立空目录；结果分别报告记录、图片/图标和原生格式附件，缺失项明确标为部分成功。预览恢复目录不监听系统剪贴板，不覆盖或切换活库。保留策略使用 Kit NumberInput，首次保存及收紧限制通过 Kit Dialog 确认。普通文件仅记录原始路径，不提供文件副本设置 |

动效只传达操作状态，最终顺序以数据库确认后的快照为准，保存失败按既有错误流程恢复。拖动不改变置顶状态，也不绘制插入线。分组下拉使用 Kit 标准选中态，重排以后台确认后的列表顺序为准。滚动列表保留虚拟渲染，完整正文在悬停、文本编辑或准备外拖载荷时读取。

列表搜索片段在后台生成，界面只保存显示摘要并计算摘要高亮；复制、编辑和完整预览仍按 ID 读取原文。上下键采用最近可见滚动，目标已在视口内时不移动列表；Home/End 与翻页保留各自定位策略。静态列表图片按卡片尺寸与 DPI 在后台生成缩略图，最多两个任务并发，缓存保留可见行及前后四行；拖动快照持有图片，离屏后也不会提前释放。GIF、WebP 和 APNG 沿用原图显示路径以保留动画，完整预览、复制和导出始终使用原图。外部文件在后台核对大小与修改时间，过期结果不会回填；隐藏 30 秒释放策略不变。

最小窗口客户区目标为 320 × 480 px，保持搜索框（含状态）和首条记录可见；较长列表使用滚动。
