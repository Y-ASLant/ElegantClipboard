# GPUI 基础界面规则

界面间距与动效规则主要定义在 `crates/clipboard-gpui/src/visual.rs`，主窗口、设置窗口和悬停预览的公共窗口骨架定义在 `crates/clipboard-gpui/src/ui.rs`；使用 GPUI Kit 主题色，不单独维护固定明暗色表。

## 组件选用约束

界面使用 GPUI Kit。开发或修改 UI 控件时，先查阅 [GPUI Kit 官方组件目录](https://gpui-kit.com/zh-CN/component)；目录提供的组件必须使用官方实现，不得另造同类控件或引入另一套组件库。目录未提供的应用专属内容和布局可使用 GPUI 原语实现；该规则不要求把业务界面强行套入无对应功能的组件。

已使用的目录控件包括 [`VirtualList`](https://gpui-kit.com/zh-CN/component/virtual-list)、[`Dialog`](https://gpui-kit.com/zh-CN/component/dialog)、[`Scrollable`](https://gpui-kit.com/zh-CN/component/scrollable)、[`Accordion`](https://gpui-kit.com/zh-CN/component/accordion)、[`Alert`](https://gpui-kit.com/zh-CN/component/alert)，以及 Kit 的按钮、输入、勾选、选择、分类标签、图标、图片、快捷键、状态栏、设置页、图表与首次引导步骤。历史卡片点击/拖放区、窗口拖动热区、缩放画布、状态文字和布局不是独立的通用控件；使用 GPUI 原语承载业务内容，图片缩放容器的底层 GPUI 滚动配合 Kit 滚动条。

| 部位 | 规则 |
|---|---|
| 内容左右边距 | 20 px；搜索、筛选、列表和状态栏对齐 |
| 历史行高度 | 使用 GPUI Kit `VirtualList` 渲染可变高度记录，并保留像素滚动位置及可见范围导航；标准密度默认两行文本为 96 px、图片为 124 px，预览行数超过两行每行增加 20 px；紧凑/宽松密度分别缩小/放大卡片和缩略图。正文在上，时间、大小与来源应用在下，图片预览居中 |
| 行内按钮高度 | 24 px；卡片悬停或选中时在底部显示操作按钮，其他时候显示来源应用；辅助操作使用 ghost，复制与受控粘贴使用 outline；粘贴仅在快捷键唤出并保存有效原窗口后启用 |
| 主窗口边框 | 主窗口隐藏原生和 Kit 标题栏与系统标题栏按钮；搜索框上方 30 px 区域有居中浅色短横握柄，按住握柄或其左右空白处拖动窗口，紧邻窗口上边缘的缩放热区仍由 Windows 处理。分类栏下方的记录数量区域也可拖动，“返回顶部”按钮不作为拖动区。Esc 与托盘菜单控制窗口显隐；独立设置窗口仍使用 GPUI Kit TitleBar |
| 窗口骨架 | 主窗口、独立设置窗口与悬停预览共用全尺寸纵向布局及主题背景、前景色；主窗口的拖动握柄、设置窗口的 GPUI Kit TitleBar 和预览浮窗的边框仍分别实现。主窗口内部页面继承窗口主题，不重复设置相同背景和文字样式 |
| 隐藏与唤回 | 未置顶时点击应用外或主窗口历史列表的空白区域会隐藏到托盘；卡片和操作按钮的点击不冒泡成空白点击。设置窗口打开、粘贴或批量操作处理中不自动隐藏；置顶时保留窗口，但快捷键仍可主动切换显隐。设置窗口关闭后，托盘和全局快捷键须继续响应 |
| 窗口设置 | 默认收起外观、唤出、开机启动与数据维护选项，最小窗口可完整显示首张卡片；“本地数据”的占用摘要和刷新、整理数据库、打开目录、导出备份按钮在宽窗口同一行，空间不足时才换行，摘要文本不截断。普通窗口内容区尺寸自动记忆，最大化和全屏不覆盖该值 |
| 设置界面 | 使用 GPUI Kit `Settings`、`SettingPage`、`SettingGroup` 和 `SettingItem` 组织八个设置页及 17 个分组；各分组沿用原有保存行为。内容卡片随侧栏之外的可用宽度伸展，常规设置在宽窗口横向分组或多列排列，在 700×420 最小窗口按可用宽度换行；语言与带文字标签的主题选项同排，快速粘贴槽位的快捷键和操作在宽窗口同排。组件自带搜索与可调整宽度的侧栏（初始 224 px，范围 212–280 px），搜索按页面、分组标题及说明过滤，标题、分组和控件随语言切换更新；最小设置窗口中侧栏和分组内容仍可滚动访问 |
| 设置中的选择项与预览行数 | 多选及其余布尔项使用 GPUI Kit `Checkbox`；开机自启与复制、粘贴音效的启用项使用 Kit `Switch`。窗口位置、快捷键、外观、悬停预览、列表显示、音效时机及应用过滤等互斥选择使用 Kit `TabBar` 的 Filling Space 等宽标签；唤出快捷键采用无阴影的 `outline` 样式，其余使用 `segmented`。选项保存期间禁用并在后台确认后更新选中态；复制与粘贴音效的播放时机、“试听”按钮和“启用”开关同排，开关位于最右侧，执行操作继续使用 Kit `Button`。卡片预览行数使用 Kit `NumberInput`，编辑提交和加减步进限制在 1–10 行，后台确认后同步显示，保存失败时恢复已确认的值；可展开的快捷键与运行中应用区域使用 Kit `Accordion` |
| 快捷键展示 | 设置中的唤出热键、自动粘贴按键、快速粘贴槽位和录制提示，以及首次引导中的操作键提示，均使用 GPUI Kit `Kbd` 展示按键；可编辑的快捷键仍使用 Kit `Input` 录入，未设置状态使用普通文本 |
| 首次引导 | 使用 GPUI Kit 小号 `Stepper` 展示四个可点击的步骤与当前位置，标题、说明和提示随步骤切换；中文和英文标签均须在默认窗口内完整显示；完成状态经后台持久化后再退出引导 |
| 状态反馈 | 列表与全文预览共用一个 GPUI Kit `StatusBar` 底部状态栏；仅在有消息或正在保存顺序时显示，错误使用主题 danger 色；设置页内的操作失败与提示使用 Kit `Alert` |
| 文本悬停预览 | 文本、网址及 HTML/RTF 与图片默认在悬停 500 ms 后请求完整内容，使用已有可滚动只读浮窗；文件默认关闭，已有用户明确保存的开关不变。离开卡片和浮窗后关闭，批量模式不展示 |
| 文本编辑 | 从全文预览进入，保持原卡片 ID 与分组；保存前提示富文本会转为纯文本，空内容需使用独立删除操作；Esc 取消编辑并恢复原内容 |
| 文件详情 | 使用可滚动的统一卡片列表；标题显示文件名，状态标签显示大小、文件夹或失效，正文显示原始路径；受管备份副本另列实际路径，失效项使用主题 danger 边框和文字 |
| 动效 | 预览、卡片拖动浮层、插入线、拖动中的卡片主动让位和历史卡片排序完成共用 180 ms ease-out 动效；尊重 GPUI `reduce_motion` |
| 拖放 | 普通模式下卡片左右各 18 px 可拖动排序，默认悬停时显示握柄，正文与按钮仍保留原点击行为。GPUI Kit `VirtualList` 的可见卡片按各自真实行高实时移动，为被拖卡片让出目标位置；落点始终按虚拟列表原始槽位和滚动偏移计算，不随动画中的卡片跳动。浮层使用 Kit 主题，插入线提示落点；松手后再保存，跨置顶区同步更新状态与顺序。列表上下 32 px 自动滚动区采用 60 ms 节拍；自定义分组顺序由 Select 的上移/下移菜单项保存 |
| 富文本复制 | 默认“复制”保留可用富格式；卡片“纯文本”和预览“复制纯文本”仅复制已保存的文本表示，缺失时提示错误 |
| 批量选择 | 卡片底部悬停操作栏提供“选择/已选”，列表 Ctrl+A 也可进入多选；整卡点击切换选择。多选操作栏提供“全选已加载 / 退出多选 / 删除选中”，退出时清空选择，删除使用 Kit `Dialog` 二次确认。搜索、分组及收藏视图切换会退出多选；受管媒体在事务提交后按引用清理 |
| 隐私清理 | 当前分组“清理历史”保留置顶和收藏；主窗口使用 Kit `Dialog` 确认当前分组清理；窗口设置中的“删除全部历史”使用 danger 按钮和独立 Kit `Dialog` 强确认，明确覆盖所有分组、置顶与收藏，并说明设置和自定义分组保留 |
| 主界面操作 | 搜索框独占一行，不提供旁侧多选按钮；左右内容边距各 20 px。托盘菜单固定提供清理历史、窗口置顶（勾选态）和设置；清理历史沿用当前分组范围与确认。既有操作入口显隐和顺序配置不再生效 |
| 历史分类栏 | 使用 GPUI Kit `TabBar` 的 Filling Space 分段标签，默认 32 px 高，与搜索 Input 和分组 Select 一致；全部、收藏、文本、其他四项等宽占用分组 Select 左侧剩余宽度；切换分类保留搜索和左右方向键行为，选择自定义分组时不高亮分类标签；最小窗口不换行 |
| 分组 Select | GPUI Kit `Select` 与分类标签同行，默认分组固定首位；下拉列表依次显示自定义分组和新建入口，选中自定义分组后追加重命名、删除、可用的上移/下移操作。新建和重命名通过 Kit `Dialog` 填写分组名称，保存成功后关闭，失败时保留输入并在对话框内显示原因；保存期间禁止取消或重复提交。动作不会覆盖选中的组名；分组顺序保存至 SQLite。Kit `Dialog` 在删除前确认名称和记录数，记录移至默认分组。分类栏隐藏时 Select 仍显示 |
| 移动记录 | 每张卡片共用“分组”入口；目标选择栏同样固定 42 px 并横向滚动，后台确认后才从当前列表移除记录 |

动效只传达操作状态，不改变列表的最终顺序；数据库确认后才播放历史卡片排序完成反馈。跨置顶区拖放与同区排序使用相同的主色插入线和换位动画，卡片标签与置顶按钮在后台快照返回后同步更新。分组下拉使用 Kit 标准选中态，重排以后台确认后的列表顺序为准。滚动列表保留虚拟渲染，正文仅在预览时读取。

最小窗口客户区目标为 420 × 520 px，保持搜索、首条记录和状态栏可见；较长列表使用滚动。
