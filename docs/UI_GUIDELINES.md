# GPUI 基础界面规则

界面间距与动效规则主要定义在 `crates/clipboard-gpui/src/visual.rs`，主窗口、设置窗口和悬停预览的公共窗口骨架定义在 `crates/clipboard-gpui/src/ui.rs`；使用 GPUI Kit 主题色，不单独维护固定明暗色表。

## 组件选用约束

界面使用 GPUI Kit。开发或修改 UI 控件时，先查阅 [GPUI Kit 官方组件目录](https://gpui-kit.com/zh-CN/component)；目录提供的组件必须使用官方实现，不得另造同类控件或引入另一套组件库。目录未提供的应用专属内容和布局可使用 GPUI 原语实现；该规则不要求把业务界面强行套入无对应功能的组件。

已使用的目录控件包括 [`VirtualList`](https://gpui-kit.com/zh-CN/component/virtual-list)、[`Dialog`](https://gpui-kit.com/zh-CN/component/dialog)、[`Scrollable`](https://gpui-kit.com/zh-CN/component/scrollable)、[`Accordion`](https://gpui-kit.com/zh-CN/component/accordion)、[`Alert`](https://gpui-kit.com/zh-CN/component/alert)，以及 Kit 的按钮、输入、勾选、选择、分类标签、图标、图片、快捷键、状态栏、设置页、图表与首次引导步骤。历史卡片点击/拖放区、窗口拖动热区、缩放画布、状态文字和布局不是独立的通用控件；使用 GPUI 原语承载业务内容，图片缩放容器的底层 GPUI 滚动配合 Kit 滚动条。

| 部位 | 规则 |
|---|---|
| 内容左右边距 | 8 px；搜索、筛选、列表和状态栏对齐 |
| 历史行高度 | 使用 GPUI Kit `VirtualList` 渲染可变高度记录，并保留像素滚动位置及可见范围导航；标准密度默认两行文本为 96 px、图片为 124 px，预览行数超过两行每行增加 20 px；紧凑/宽松密度分别缩小/放大卡片和缩略图。正文在上，时间、大小与来源应用在下，图片预览居中 |
| 行内按钮高度 | 24 px；卡片悬停或选中时在底部显示操作按钮，其他时候显示来源应用；辅助操作使用 ghost，复制与受控粘贴使用 outline；粘贴仅在快捷键唤出并保存有效原窗口后启用 |
| 主窗口边框 | 主窗口隐藏原生和 Kit 标题栏与系统标题栏按钮；搜索框上方 30 px 区域有居中浅色短横握柄，按住握柄或其左右空白处拖动窗口，紧邻窗口上边缘的缩放热区仍由 Windows 处理。记录数量固定显示在列表下方的 24 px 底栏，不随列表滚动，该区域也可拖动窗口，“返回顶部”按钮不作为拖动区。Esc 与托盘菜单控制窗口显隐；独立设置窗口仍使用 GPUI Kit TitleBar |
| 窗口骨架 | 主窗口与独立设置窗口通过 Kit `open_window` 创建，由 Base Root 自动承载 Dialog 等浮层；悬停预览通过原生 GPUI 窗口创建以避免 Root 窗口边框的内溢阴影。三个窗口复用 `ui/presentation.rs::window_shell` 的全尺寸纵向布局及主题前景色，不手动渲染 Dialog 层；主窗口拖动握柄、设置 TitleBar 和预览浮窗边框分别实现 |
| 窗口材质 | 系统背板与主题分离：只在窗口外壳绘制一层主题染色，不修改 GPUI Kit 的全局背景、输入、选中态或浮层 token。开启效果时，设置 TitleBar 与 Sidebar 容器通过官方样式接口局部透明，露出同一层外壳；分组沿用 Outline，无额外底色。历史卡片、文件详情、引导面板、拖动浮层及行内操作栏保留主题底色；控件、Notification、菜单和 Dialog 保留原有背景与阴影，文字、图标和焦点不随材质变淡。背景遮罩强度仅控制外壳染色，不代表系统模糊半径；关闭效果恢复普通主题表面 |
| 材质能力与更新 | 根据真实 Windows build 筛选可用材质：22621 起提供所有材质，17763–22620 仅提供关闭与兼容亚克力，更早或版本未知时仅提供关闭。已保存但不支持的选项仍保留为选中、禁用的标签，持久 `Alert` 明确保存值和降级结果，不高亮另一选项或覆写 SQLite。遮罩强度按实际生效效果决定是否可用；只有有效原生后端变化才重新配置窗口，单纯强度变化只广播背景状态并重绘，不关闭悬停预览 |
| 隐藏与唤回 | 未置顶时点击应用外或主窗口历史列表的空白区域会隐藏到托盘；卡片和操作按钮的点击不冒泡成空白点击。设置窗口打开、粘贴或批量操作处理中不自动隐藏；置顶时保留窗口，但快捷键仍可主动切换显隐。设置窗口关闭后，托盘和全局快捷键须继续响应 |
| 窗口设置 | 默认收起外观、唤出、开机启动与数据维护选项，最小窗口可完整显示首张卡片；“本地数据”的占用摘要和刷新、整理数据库、打开目录、导出备份按钮在宽窗口同一行，空间不足时才换行，摘要文本不截断。普通窗口内容区尺寸自动记忆，最大化和全屏不覆盖该值 |
| 设置界面 | 使用 GPUI Kit `Settings`、`SettingPage`、`SettingGroup` 和 `SettingItem` 组织八个设置页及按职责划分的设置分组；各分组沿用原有保存行为。内容卡片随侧栏之外的可用宽度伸展，常规设置在宽窗口横向分组或多列排列，在 700×420 最小窗口按可用宽度换行；语言与带文字标签的主题选项同排，快速粘贴槽位的快捷键和操作在宽窗口同排。组件自带搜索与可调整宽度的侧栏（初始 224 px，范围 212–280 px），搜索按页面、分组标题及说明过滤，标题、分组和控件随语言切换更新；最小设置窗口中侧栏和分组内容仍可滚动访问 |
| 设置中的选择项与预览行数 | 多选及其余布尔项使用 GPUI Kit `Checkbox`；开机自启与复制、粘贴音效的启用项使用 Kit `Switch`。窗口位置、外观、悬停预览、列表显示、音效时机及应用过滤等互斥选择使用 Kit `TabBar` 的 Filling Space 等宽标签。唤出快捷键使用 Kit `Input` 编辑或录制，以 `Kbd` 展示，并提供保存、取消和关闭；注册或持久化失败恢复原快捷键。选项保存期间禁用并在后台确认后更新选中态；复制与粘贴音效的播放时机、“试听”按钮和“启用”开关同排，开关位于最右侧，执行操作继续使用 Kit `Button`。卡片预览行数使用 Kit `NumberInput`，编辑提交和加减步进限制在 1–10 行，后台确认后同步显示，保存失败时恢复已确认的值；可展开的快捷键与运行中应用区域使用 Kit `Accordion` |
| 快捷键展示 | 设置中的唤出热键、自动粘贴按键、快速粘贴槽位和录制提示，以及首次引导中的操作键提示，均使用 GPUI Kit `Kbd` 展示按键；置于 Kit `TabBar` 标签内时关闭 `Kbd` 自带底色与边框，沿用标签的选中态文字样式，避免标签中再嵌套灰色徽标。可编辑的快捷键仍使用 Kit `Input` 录入，未设置状态使用普通文本 |
| 首次引导 | 使用 GPUI Kit 小号 `Stepper` 展示四个可点击的步骤与当前位置，标题、说明和提示随步骤切换；中文和英文标签均须在默认窗口内完整显示；完成状态经后台持久化后再退出引导 |
| 状态反馈 | 主窗口和设置窗口的操作结果均使用官方 [`Notification`](https://gpui-kit.com/zh-CN/component/notification)，由 Root 在右上角显示，默认 5 秒后自动消失，也可手动关闭；悬停或键盘焦点位于通知上时，计时按 Kit 规则暂停。主视图统一投递，同一结果只通知一个窗口：主窗口未激活且设置窗口存在时发给设置，否则发给主窗口。`StatusBar` 仅显示正在保存排序等持续状态，不保留已完成操作消息。后台历史、占用、每日统计和运行应用查询成功只更新数据，不弹成功通知或覆盖已有错误；需要持续处理的局部校验或上下文错误仍使用行内 `Alert` |
| 文本悬停预览 | 文本、网址及 HTML/RTF 与图片默认在悬停 500 ms 后请求完整内容，使用已有可滚动只读浮窗；文件默认关闭，已有用户明确保存的开关不变。离开卡片和浮窗后关闭，批量模式不展示 |
| 文本编辑 | 从全文预览进入，保持原卡片 ID 与分组；保存前提示富文本会转为纯文本，空内容需使用独立删除操作；Esc 取消编辑并恢复原内容 |
| 文件详情 | 使用可滚动的统一卡片列表；标题显示文件名，状态标签显示大小、文件夹或失效，正文显示原始路径；受管备份副本另列实际路径，失效项使用主题 danger 边框和文字 |
| 动效 | 卡片拖动让位与排序完成使用 260 ms ease-in-out，反向拖动从当前显示位置继续；其他预览动效保留 180 ms ease-out。尊重 GPUI `reduce_motion` |
| 拖放 | 普通模式下整卡正文、图片与信息行可开始拖动，操作按钮保留独立点击；两侧 18 px 握柄仅为可配置提示，批量模式禁用拖动。GPUI Kit `VirtualList` 按实际行高让位，动画使用 prepaint 位移而不改行布局，命中与反向续接使用上一实际绘制帧的共享进度，同一目标内持续悬停不反复换位。浮层保留原尺寸正文、图片与信息栏，Kit 主题背景完全不透明，不显示操作按钮、额外阴影或插入线；源卡片为同尺寸空白占位。松手后保存，同一置顶分区内排序，保存期间保持临时位置。列表上下 32 px 自动滚动区采用 60 ms 节拍；自定义分组顺序由 Select 的上移/下移菜单项保存 |
| 窗口外拖放 | 同一透明、不激活、鼠标穿透的预览浮窗保持抓取点，Windows OLE 使用复制反馈；支持完整 Unicode、已存 HTML/RTF、文件路径和图片文件/DIB，不写系统剪贴板。持续按住返回源窗口可继续排序，回源同时松手由应用会话提交内部排序，Esc 取消。应用会话统一负责松手收尾；预览窗口复用，普通跟随由帧回调驱动，最小化无帧时有低频清理兜底。拖动期间延后同代次历史快照，避免后台刷新挤走源卡片 |
| 富文本复制 | 默认“复制”保留可用富格式；卡片“纯文本”和预览“复制纯文本”优先使用已保存文本；缺失时从 HTML 提取可读文本、解码实体并保留段落/表格分隔，无法转换的记录明确报错。图片右键提供“作为文件复制/粘贴”，复用受管图片文件 |
| 批量选择 | 卡片底部悬停操作栏提供“选择/已选”，列表 Ctrl+A 也可进入多选；整卡点击切换选择。多选操作栏提供“全选已加载 / 退出多选 / 删除选中”，退出时清空选择，删除使用 Kit `Dialog` 二次确认。搜索、分组及收藏视图切换会退出多选；受管媒体在事务提交后按引用清理 |
| 隐私清理 | 当前分组“清理历史”保留置顶和收藏；主窗口使用 Kit `Dialog` 确认当前分组清理；窗口设置中的“删除全部历史”使用 danger 按钮和独立 Kit `Dialog` 强确认，明确覆盖所有分组、置顶与收藏，并说明设置和自定义分组保留 |
| 主界面操作 | 搜索框独占一行，不提供旁侧多选按钮；左右内容边距各 8 px。托盘菜单固定提供清理历史、窗口置顶（勾选态）和设置；清理历史沿用当前分组范围与确认。既有操作入口显隐和顺序配置不再生效 |
| 历史分类栏 | 使用 GPUI Kit `TabBar` 的 Filling Space 分段标签，默认 32 px 高，与搜索 Input 和分组 Select 一致；全部、收藏、文本、其他四项等宽占用分组 Select 左侧剩余宽度；切换分类保留搜索和左右方向键行为，分组独立于分类，选择自定义组后保留当前分类标签并与搜索取交集；最小窗口不换行 |
| 分组 Select | GPUI Kit `Select` 与分类标签同行，默认分组固定首位；下拉列表依次显示自定义分组和新建入口，选中自定义分组后追加重命名、删除、可用的上移/下移操作。新建和重命名通过窗口中央的 Kit `Dialog` 填写分组名称，背后内容保留 Kit 遮罩；保存成功后关闭，失败时保留输入并在对话框内显示原因；保存期间禁止取消或重复提交。动作不会覆盖选中的组名；分组顺序保存至 SQLite。Kit `Dialog` 在删除前确认名称和记录数，记录移至默认分组。分类栏隐藏时 Select 仍显示 |
| 移动记录 | 每张卡片共用“分组”入口；目标选择栏同样固定 42 px 并横向滚动，后台确认后才从当前列表移除记录 |
| 数据管理 | 导入/恢复使用原生路径选择器，要求独立空目录；成功展示记录和附件报告并提供打开操作，不覆盖活库。保留策略使用 Kit NumberInput，首次保存及收紧限制通过 Kit Dialog 确认；文件副本默认关闭，以 Checkbox 启用并明示容量和目录限制 |

动效只传达操作状态，最终顺序以数据库确认后的快照为准，保存失败按既有错误流程恢复。拖动不改变置顶状态，也不绘制插入线。分组下拉使用 Kit 标准选中态，重排以后台确认后的列表顺序为准。滚动列表保留虚拟渲染，完整正文在预览或准备外拖载荷时读取。

列表搜索片段在后台生成，界面只保存显示摘要并计算摘要高亮；复制、编辑和完整预览仍按 ID 读取原文。上下键采用最近可见滚动，目标已在视口内时不移动列表；Home/End 与翻页保留各自定位策略。静态列表图片按卡片尺寸与 DPI 在后台生成缩略图，最多两个任务并发，缓存保留可见行及前后四行；拖动快照持有图片，离屏后也不会提前释放。GIF、WebP 和 APNG 沿用原图显示路径以保留动画，完整预览、复制和导出始终使用原图。外部文件在后台核对大小与修改时间，过期结果不会回填；隐藏 30 秒释放策略不变。

最小窗口客户区目标为 420 × 520 px，保持搜索、首条记录和状态栏可见；较长列表使用滚动。
