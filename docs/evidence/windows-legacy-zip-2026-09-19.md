# Windows 旧版 ZIP 导入验收（2026-09-19）

- 旧版 Tauri 的 ZIP 布局为 `clipboard.db` 加上平铺的 `images/`、`icons/`、`staged/` 文件，不带 GPUI 清单。新增 `--import-legacy-backup`，要求显式空 `--data-dir`，持有实例锁，先在临时目录提取、升级与校验数据库，再安装资产与数据库。未知、重复和路径穿越条目被拒绝，导入不覆盖现有数据。
- 导入后重建数据库中的图片、图标和暂存文件绝对路径；没有归档资源的图片引用保留原路径并计数。仅保留 GPUI 使用的设置项。恢复的暂存副本可在原文件丢失时作为普通文件复制路径；只接受位于当前数据目录 `staged/` 内的副本。删除、清理和容量淘汰会移除无引用的暂存文件。
- 合成旧格式归档测试覆盖文本、分组、收藏、中文媒体文件名、图片预览、图标、文件暂存回退、设置过滤、重复导入与恶意归档路径；另测试暂存路径不得指向管理目录之外、共享引用的保留与最终清理，以及容量淘汰。GPUI ZIP 升级为 v2，测试图片、图标、暂存副本的往返恢复及旧版 v1 恢复兼容。全 workspace 共 145 项测试通过，严格 Clippy 无告警。
- 真实命令行以 `target/qa/image-ui/` 的数据库在线快照和图片构造旧格式 ZIP，在 `target/qa/legacy-backup-ui/restored/` 隔离目录导入。报告 2 条记录和 1 张图片；SQLite `quick_check=ok`，恢复图片存在且为 10615 字节。再次导入同一目录被拒绝。未使用默认用户数据目录或交互桌面剪贴板。
