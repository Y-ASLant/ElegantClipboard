# Windows 批量合并复制与粘贴（2026-09-19）

- GPUI 批量栏在选择至少两条记录后提供“合并复制”；记录按当前列表顺序处理，而不是 `HashSet` 的非确定顺序。文本、网址和富文本使用已有纯文本表示，缺少纯文本的 HTML 使用剥离标签后的表示；无法可靠转成文本的 RTF 明确报错。文件列表使用旧版备份恢复的受管暂存副本作为安全回退，源文件或受管图片缺失时在改写剪贴板前停止。
- 合并结果以换行连接文本，并将文件与受管图片路径去重后同时写入系统剪贴板。路径总量继续受 256 项或 1 MiB 限制。Windows 后端在写入后精确读回文本和文件列表，并检查写入期间的剪贴板序号；失败或外部并发修改会返回错误，部分自身写入的最终序号仍加入采集抑制，避免生成历史循环。
- 若窗口由有效外部目标的全局快捷键唤出，按钮显示“合并粘贴”：写入确认后复用单条粘贴的窗口有效性、前台焦点、修饰键释放、序号和 `SendInput` 检查。窗口失焦会取消尚未执行的目标绑定，合并内容仍留在剪贴板供手动粘贴。没有目标时只执行“合并复制”。
