# Windows 文件与图片路径操作（2026-09-19）

- 文件卡片增加“复制路径”；文件和图片预览增加“复制路径”与“在资源管理器中显示”。存在由全局快捷键绑定的有效外部目标时，路径按钮显示“粘贴路径”，写入确认后复用现有的焦点、修饰键、剪贴板序号和 `SendInput` 检查；否则只复制路径文本。
- 普通文件继续优先使用仍存在的原始路径；旧版备份恢复的原文件丢失时，仅接受 GPUI 数据目录 `staged/` 内的受管副本。图片使用其受管 PNG。路径操作在改写剪贴板或启动资源管理器之前确认每一项仍存在，文件列表以换行连接，资源管理器定位第一项并在多项时给出数量提示。
- Windows 后端从 `SystemRoot` 选择系统 `explorer.exe`，通过独立参数传递 `/select,` 与路径，不使用 shell 字符串拼接。单元测试覆盖中文和空格路径、参数边界、缺失源文件与非媒体记录拒绝；没有在测试中实际启动用户的资源管理器窗口。
- 私有窗口站 `Service-0x0-acfbc94$` 中，正式后台采集文件记录后执行 `CopyPath`；系统剪贴板精确读回完整路径文本，并确认不再包含文件对象格式。随后原有文件对象复制、合并复制和监听错误隔离仍通过。该测试没有选择交互窗口站。
