# Windows 窗口尺寸恢复验收（2026-09-19）

- 主窗口通过 GPUI 窗口边界观察器跟踪普通窗口内容区逻辑尺寸，变化停止 300 ms 后发送给现有后台服务写入 SQLite。最大化和全屏边界不参与保存，写入失败会进入统一底部错误状态。
- 保存值只接受宽 420–4096、高 520–2160；缺失或损坏时使用 560×760 默认内容区。启动仍在当前显示器居中，不持久化可能因显示器拓扑变化而落到屏幕外的位置。窗口尺寸属于 GPUI 安全设置白名单，备份恢复测试验证该值能够往返且非 GPUI 设置仍被过滤。
- 使用忽略目录 `target/qa/window-size-ui-20260919-v1` 和真实 debug GPUI 窗口验收：默认内容区 560×760 在当前 Windows 环境对应 576×768 外框；把外框调整到 900×700 后保存内容区 884×692，最大化没有覆盖该值；退出并以同一数据目录重启后外框仍为 900×700。把数据库值损坏为 `99999x1` 后重启，窗口回退到默认外框 576×768，并把有效默认内容区重新保存为 `560x760`。
- 验收使用 `--no-monitor`，没有读取或写入系统剪贴板。自动测试覆盖设置持久化、非法值回退、平台事件确认、服务重启加载及 GPUI ZIP 备份恢复；完整测试和制品摘要见本次提交对应的 Windows 基础版与打包记录。
