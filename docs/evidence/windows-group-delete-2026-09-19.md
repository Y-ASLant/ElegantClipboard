# Windows 分组删除与记录保留验收（2026-09-19）

- GPUI 新增两步删除：只能对选中的自定义分组操作，确认栏显示分组名、组内记录数与“移到默认分组”的结果。旧版 Tauri 的分组删除会级联删除记录；GPUI 使用独立的事务方法，先迁移记录再删除分组。
- 核心测试覆盖组内三条记录、与默认分组相同的内容哈希、收藏状态、显示顺序及重启持久化；另用故障触发器验证迁移失败时分组与记录均回滚。Windows 后端测试验证过期列表代次被拒绝，以及成功后分组列表刷新、默认分组可见原记录。
- 使用 `target/qa/groups-ui/clipboard.db` 的隔离备份，以 `--no-monitor` 打开真实 GPUI 窗口，选中“工作”分组并点击“删除分组”。界面显示“3 条记录将移到默认分组”；确认后 SQLite 中该分组消失，原有 3 条记录的 `group_id` 均为 `NULL`，全库记录总数保持 5 条，默认分组界面显示 4 条记录。过程截图位于忽略目录 `target/qa/group-delete/`。
- 未修改旧版删除命令、真实用户数据目录或交互桌面剪贴板。
