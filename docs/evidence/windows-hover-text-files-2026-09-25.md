- 使用 `target/ui-expanded-image-20260925` 隔离数据目录与调试版 `--no-monitor`。向隔离 SQLite 插入 830 字符合成文本和指向已有合成 PNG 的单文件记录；启用文本与文件悬浮预览，延时设为 250 ms。未启用剪贴板监控，未点击复制或粘贴控件。
- 鼠标悬停文本卡片时，打开约 462×301 的独立浮窗（截图含边框），标题为“文本预览”，正文显示卡片摘要以外的完整内容起始段落。文本区有后续内容可滚动；本次未验证滚动到底部。
