# Windows 批量删除验收（2026-09-19）

- 从可见卡片逐条勾选，或选中一条后全选已加载记录；删除前单独确认，明确包括选中的置顶和收藏记录。搜索、分组及收藏视图切换会清空选择。后台拒绝过期列表、跨组 ID、重复或不存在的 ID。
- 核心删除在一笔 SQLite 事务中校验所有 ID 与分组并删除；用触发器强制中途失败后，已尝试删除的记录也回滚。提交后清理不再引用的受管图片与暂存文件，保留未选记录及其他分组。
- 420 × 520 px 隔离窗口下，“选择”按钮可见。真实鼠标选中首项、全选 8 条并打开确认框时，数据库仍为 8 条；取消后保持 8 条，确认后变为 0 条。截图保存在忽略目录 `target/qa/batch-selected.png` 与 `target/qa/batch-delete-confirm.png`，操作只使用隔离数据库且禁用采集。
