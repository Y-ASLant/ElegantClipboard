# Windows 卡片拖拽与视觉统一验收（2026-09-19）

- 六类可见记录（文本、网址、HTML、RTF、图片、文件）共用整卡非按钮区域拖拽逻辑；目标前后位置由卡片上下半区决定，组内与收藏视图按各自顺序持久化。置顶状态不同的记录不能直接互换，红色插入线和卡片边框提前标明不可放置。
- 图片与非图片记录采用相同的行高、预览底板、卡片内距和操作区。图片缩略图保持固定尺寸；文本摘要限制两行。拖动浮层重复使用卡片的类型和摘要层级。浮层、插入线、提示面板与排序反馈共用 `visual::MOTION_DURATION` 和相同缓动，系统要求减少动态效果时不播放动画。
- 420 × 520 px 最小窗口下，“窗口设置”默认收起；缩紧历史标题与搜索间距后，首张卡片的正文和全部操作按钮在状态栏上方完整可见。单击“展开”可看到外观与唤出设置，原有选项仍可访问。截图保存在忽略目录 `target/qa/card-drag/narrow.png`、`settings-expanded.png`。
- 在隔离数据目录中以真实鼠标从首张卡片拖至第二张后半区，SQLite 顺序由 `[7,6,5,…]` 变为 `[6,7,5,…]`；拖动浮层与落点线截图保存在 `target/qa/card-drag/dragging.png`。
- 现有核心测试覆盖图片、富文本、文件与普通文本混排排序，以及收藏顺序、置顶边界、分组隔离、分页外记录和重启持久化。全 workspace 145 项测试通过；严格 Clippy、fmt 与 Windows 隔离窗口冒烟通过。
