# Windows 文件与图片另存为（2026-09-19）

- 图片和文件预览增加“另存为”；多文件记录明确显示“另存第一项”。界面复用 GPUI 已用于备份导出的原生保存路径能力，不增加插件或文件对话框依赖，默认文件名来自记录解析后的第一项。
- 系统对话框只选择目标路径。Windows 后台收到记录 ID 后重新读取数据库，普通文件继续使用有效原路径或当前数据目录中的受管暂存回退，图片使用受管 PNG；复制前再次确认所有解析路径存在，并只允许第一项为普通文件。相对目标、缺失父目录、目录目标、文件夹源和解析后与源文件相同的目标均被拒绝。
- 单元测试使用中文和空格路径，核对普通文件与图片的字节级复制，并覆盖原地覆盖及文件夹拒绝。`cargo test --workspace --locked --quiet` 共 167 项通过（核心 132、Windows 后端 30、应用状态/参数 5）；严格 Clippy、格式检查和 Debug 构建通过。
- 真实 GPUI 窗口使用 `target/qa/save-as-ui-20260919-v2/` 隔离数据目录并关闭采集。UI Automation 打开图片预览，确认 560×760 布局中的“另存为”“在资源管理器中显示”“复制路径”和“复制图片”按钮；点击“另存为”后，gpui-pre 0.3.5 的 Windows `IFileSaveDialog` 打开到文档目录并预填 `sample.png`。截图为忽略目录中的 `image-preview-save-as.png` 与 `after-save-as-click.png`，随后发送 Esc 取消，没有创建目标文件或改写剪贴板。
