# Windows 记录移动分组验收（2026-09-19）

每张历史卡片共用“分组”操作。点击后出现横向滚动的目标栏，可选择默认组或已有自定义组。后台请求携带当前组与查询代次；核心层再核对记录实际来源组和目标组存在性。成功后刷新分组列表和当前历史，失败保持选择栏并显示原因。收藏、置顶及内容数据随同一记录移动。

验证：workspace 共 125 项测试通过，严格 Clippy、release 构建及 release 窗口冒烟无告警。核心测试覆盖默认组→自定义组→另一自定义组→默认组、缺失目标、过期来源，以及收藏/置顶属性保留；后台测试覆盖刷新列表与拒绝过期代次。

在 `target/qa/groups-ui` 隔离数据目录启动 GPUI 并禁用采集，实际点击默认组第一条卡片的“分组”，选择“工作”：SQLite 中该记录的 `group_id` 变为“工作”组 ID，默认组计数从 2 变为 1，界面移除该卡片并显示保存反馈。420×520 最小窗口下，七个行内操作仍在卡片宽度内。没有读写交互桌面剪贴板。
