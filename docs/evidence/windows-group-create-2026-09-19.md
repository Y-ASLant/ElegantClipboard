# Windows 新建分组验收（2026-09-19）

核心层对新分组名称做首尾空白裁剪，拒绝空名称、超过 40 个字符或 160 字节的名称，以及已存在的同名分组。后台保存成功后刷新分组列表、发送明确确认；界面关闭内联输入框并切换到新分组。保存失败时保留输入框和文本，状态栏显示原因。

验证：123 项 workspace 测试、fmt、严格 Clippy、release 构建及 release 窗口冒烟均通过且无编译告警。核心测试覆盖名称校验、重复名称与重启后持久化；后台测试覆盖分组列表刷新、成功确认及重复名称失败。使用 `target/qa/group-create-ui` 隔离数据库，在 GPUI 窗口实际点击“＋ 新建”、键入 `WorkQA`、先确认中文输入法候选、再点击“创建”；SQLite `groups` 表新增 `WorkQA`，界面自动选中新分组并显示空组提示。整个流程禁用了系统剪贴板采集。

待办：将已有条目移入分组，以及重命名、删除分组。测试机启用中文输入法时，自动化键入后的候选词需要先确认；人工使用时亦应先完成输入法组合再提交。
