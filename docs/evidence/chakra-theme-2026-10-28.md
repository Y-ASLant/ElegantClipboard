# 全应用主题与动效（2026-10-28）

将 Chakra 的视觉层级、语义颜色和时序应用到现有 Rust/GPUI 原生应用。继续使用官方 GPUI Kit 组件，没有增加 React、Node、WebView 或组件库。

## 设计来源与实现

- [Chakra 语义配色](https://github.com/chakra-ui/chakra-ui/blob/main/packages/react/src/theme/semantic-tokens/colors.ts)：灰色前景/背景/边框层级，蓝色强调、焦点和选中态。
- [颜色值](https://github.com/chakra-ui/chakra-ui/blob/main/packages/react/src/theme/tokens/colors.ts)：gray 50–950 和 blue 50–950。应用保留自己的语义错误/警告/成功状态，不靠颜色单独表达含义。
- [动效时长](https://github.com/chakra-ui/chakra-ui/blob/main/packages/react/src/theme/tokens/durations.ts)与[缓动](https://github.com/chakra-ui/chakra-ui/blob/main/packages/react/src/theme/tokens/easings.ts)：快速反馈 150ms，标准入场 200ms，移动/弹性过渡 300ms，采用 ease-in/ease-out/ease-in-out。
- `design_system.rs` 通过官方 `Theme::update` 同步颜色、tokens、基础组件和动效；明暗/系统外观切换后重新应用同一规范，不各页面维护独立色表。
- `visual.rs` 负责应用内容的入场与拖动。历史卡片悬停/选中使用官方 Base transition，目标改变从当前显示值继续；明暗模式切换使用独立过渡通道，避免新文字与旧背景短暂低对比；动画只影响表现，不改列表排序和命中算法，减少动效遵循 GPUI 状态。

## 覆盖范围

- 主窗口：搜索、分类、分组、列表卡片、选中/悬停、空状态、行内动作、批量/分组移动工具栏和底部计数。
- 设置：八个页面、侧栏、官方分组/卡片、单选分段、复选框、开关、输入/数字输入、快捷键编辑、应用筛选、数据报告与操作按钮。
- 悬停预览：独立浮窗的文本、HTML、图片与文件表面同步主题和圆角。按用户后续要求移除主窗口整页预览及“查看详情”入口；编辑与备注改为官方 Dialog，另存、路径和系统定位保留在右键菜单。
- 浮层：官方 Dialog、Select、菜单、Tooltip、Notification 与首次引导。系统 toast 的外观仍由操作系统决定；应用只设置自身身份和消息。

## 可调圆角

用户要求全局圆角默认 4px。在外观设置提供 0/4/8/12/16px，服务端允许 0–16，非法写入返回失败并保留旧值；读取损坏配置回退 4。配置键 `gpui_corner_radius` 加入备份白名单。主窗口、设置、预览和浮层均读取当前 theme.radius/radius_lg，保存确认后同步更新，主题切换继续保留圆角。

新增行为回归覆盖数值边界、非法值不覆盖、数据库重开、服务 ACK/失败与重启；既有备份恢复测试新增圆角持久化检查。没有添加绑定静态文案/颜色/控件接线的测试。

## 边距与组件细节

主窗口搜索、工具栏、卡片、底栏共用12px左右边距，分类分段与分组选择器同高32px。分类扣除分组宽度、行间距及官方分段padding后等分四项；选中块与外框四周各4px，标签在最小窗口中不截断。原生稳定帧像素测量确认选中块顶部/底部各4px、末项右侧4px，四项等分仅可能相差1px取整。设置中的宽分段使用36px规格，内边距仍上下左右一致。圆角从主题读取，编辑/菜单/对话框不使用局部固定面板圆角。
