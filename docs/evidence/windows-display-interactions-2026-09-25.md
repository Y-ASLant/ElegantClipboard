# GPUI 分类、搜索高亮与卡片密度交互验证

- 使用 `target/ui-display-qa-20260925` 隔离数据目录，通过 `--smoke-test` 初始化后直接向 SQLite 插入三条合成文本和一条合成网址记录。以 `--no-monitor` 启动调试版；没有启用剪贴板采集，也没有向用户剪贴板写入内容。
- 分类栏“其他”只显示合成网址（1 条），“文本”只显示合成文本（3 条）；收藏首条文本后，“收藏”只显示该条（1 条）。分类切换后的数量和卡片内容与插入数据一致。
- 搜索 `FINDME` 时，唯一命中的词位于正文深处、原卡片摘要之外。卡片改为显示命中附近片段，并用背景色高亮 `FINDME`；清空搜索后恢复全部四条记录。
- 在设置页将卡片密度从标准切为紧凑，主窗口首条卡片高度从约 130px 降为约 118px；关闭并重新启动隔离实例后仍为紧凑。再切为宽松，首条卡片增至约 170px，卡片操作按钮和内容未重叠。SQLite 的 `gpui_display.card_density` 在最终检查时为 `spacious`，主窗口显示“显示设置已保存”。
- 一次通过 Alt+F4 关闭设置窗口后，隔离进程随后退出；重新启动后，用设置窗口右上角关闭按钮退出设置，主窗口保持运行。前一次现象未稳定复现，不能据此判定应用缺陷。本轮未测试真实剪贴板采集、系统级快捷键或最小窗口尺寸。
