# Windows 文本编辑验收（2026-09-19）

- 从卡片“查看”进入预览后，文本、网址和 HTML/RTF 的纯文本表示可以编辑；保存前说明富文本会转为纯文本。取消或 Esc 恢复原预览内容，空内容保存报错并保留记录，删除仍使用独立按钮。
- 核心测试覆盖编辑后 ID、分组、置顶与收藏保留，搜索和重启读取更新，旧内容哈希、空内容与超过 1 MiB 的文本被拒绝。富文本内容未改变时保持原格式，实际修改后清除 HTML/RTF 字段并转为文本。Windows 后端测试验证列表刷新与过期内容错误反馈。
- 使用 `target/qa/reorder/clipboard.db` 的隔离备份，以 `--no-monitor` 打开真实 GPUI 窗口。点击首条卡片“查看”→“编辑”，输入 `EditedQA` 并保存；SQLite 中原 ID `7` 的正文更新为 `EditedQA`，`content_hash` 改变，窗口卡片立即显示新内容和“内容已保存为纯文本”。截图位于忽略目录 `target/qa/text-edit/`。
- 未修改真实用户数据目录或交互桌面剪贴板。常见应用之间的实际复制粘贴仍需单独验收。
