# GPUI 2.0 基础版规划

状态：2026-10-09 的历史规划基线，保留未完成需求与发布门槛。2026-10-16 维护说明：部分交互目标已由后续开发调整，本文不再覆盖当前行为；现状以 [Windows 功能状态](WINDOWS_MVP.md)和 [UI 规范](UI_GUIDELINES.md)为准，未完成事项需逐项核对。

分析基准：原版 `main@d6cc194`；GPUI `a5744a1`。本轮只重新规划，不修改应用行为。

## 1. 产品目标与依据

2.0 首版完成一个能长期用于 Windows 日常工作的本地剪贴板管理器：复制内容自动保存，随时唤出并检索，按原来的操作习惯粘贴回目标应用，重启不丢历史，数据可管理、备份及恢复。

- **基础能力范围**：采集、持久历史、搜索、回到原窗口粘贴、多格式与纯文本、常用内容组织、快捷键、保留策略。不承诺支持任意自定义剪贴板格式。
- **交互基准采用原 `main`**：主窗口结构、默认入口、卡片动作、分类与分组、批量操作、独立设置与编辑窗口。
- **实现延续当前 GPUI 工程**：复用已有 core/platform/gpui 分层、数据库兼容、后台 worker 和 Kit 组件，不从零重写。
- 本版优先本地功能。WebDAV、翻译、插件框架和在线更新不进入基础版发布门槛。

参考来源：

- 原版 `main:FEATURES.md`、`main:src/App.tsx`、`main:src/stores/ui-settings.ts`、`main:src/stores/clipboard.ts`、`main:src/components/ClipboardItemCard.tsx`、`main:src/pages/Settings.tsx`。
- GPUI Kit 官方组件目录：<https://gpui-kit.com/zh-CN/component>（同目录英文入口 <https://gpui-kit.com/component>）。

## 3. 原 main 的交互基准

### 主窗口布局

主窗口仍无独立应用标题栏，恢复以下顺序：

1. 顶部一行：搜索框占可用宽度，右侧依次为 **清理历史、多选、固定窗口、设置**。搜索清空按钮只清搜索文字，与清理历史严格区分。顶行非控件空白承担拖动，边缘缩放由 Windows 处理。
2. 批量栏：仅在多选模式出现，显示选择数、合并粘贴/复制、删除、取消，以及已加载范围说明。
3. 历史列表：单列虚拟卡片，置顶记录在前；支持滚动、分页和左右拖动区域。返回顶部作为列表辅助入口，不占用分类栏。
4. 底部固定栏：**全部 / 收藏 / 文本 / 其他 + 分组下拉**。状态/错误反馈就近显示，不替代分类栏。

默认四按钮先固定顺序，原版按钮显隐和排序自定义后置。原版的 WebDAV 工具栏入口不进入基础版。

### 卡片与编辑

- 普通模式：单击内容立即请求粘贴，不再等待系统双击时间。取消默认双击编辑；编辑统一从右键进入。
- 悬停右上角显示四个基础动作：记录置顶、收藏、复制、删除。阻止动作点击冒泡为卡片粘贴。
- 右键按类型提供粘贴、纯文本/路径粘贴、复制、详情、编辑、移动分组、另存为、定位、删除；不支持的动作隐藏或禁用并说明原因。
- 文本类编辑使用独立 GPUI 窗口：标题、未保存状态、编辑区、字符/字节信息、保存按钮；Ctrl+S 保存，Esc 关闭。有未保存修改时确认放弃，属于相对原版的明确改进。
- 富文本和 URL 编辑后转为纯文本，保存前提示。空文本拒绝保存，删除使用独立动作；保留当前 GPUI 的明确行为。
- 文本默认预览三行，标准密度；时间、字符数、大小与来源应用沿用原版信息层次。既有用户设置不被新默认覆盖。
- 图片/文本悬停预览沿用原版默认开启、128 ms 和自动左右定位，新目录采用该默认；现有保存值保留。原生浮窗中也可缩放/滚动，主列表上的 Ctrl+滚轮按当前预览类型路由，避免抢走普通列表滚动。

### 多选、分组与清理

- 顶部多选按钮进入批量模式；卡片点击改为选择，Shift 连选，Ctrl+A 选择已加载条目；批量模式不执行单条粘贴或拖拽排序。
- 合并按当前显示顺序执行，至少两条；任何一条无法执行时整体报错，不静默跳过。类型/格式组合不支持时明确提示。
- **分类与分组是独立可组合维度**，查询语义为 `分组 ∩ 分类 ∩ 搜索`。默认分组只表示 `group_id IS NULL`，不是跨分组汇总。选择自定义分组不取消收藏或类型过滤。
- 新采集进入当前活动分组；默认组作为无自定义组选择时的归属。事件入队时附带分组上下文，避免排队期间切组改变归属。去重与清理使用该组；组已删除时回默认组并作受控提示。
- 分组新建/重命名/删除用官方 Dialog；删除分组后记录移回默认组，保留当前 GPUI 行为，**不恢复原版级联删除**。
- 顶部清理按当前分组及类型，保留置顶/收藏；搜索文字不缩小范围，确认中明确范围。收藏视图禁止普通清理；彻底删除属于数据设置中的独立强确认。

### 焦点、目标窗口与固定

- 新目录默认唤出热键 Alt+C；可输入或录制其他受支持组合。已有明确保存的热键保持原值；支持冲突失败后恢复旧注册。
- 唤出默认不自动聚焦搜索，默认清空搜索，隐藏默认不重置分类/分组；保留用户配置。键盘导航作为原版可配置选项，默认关闭；显式搜索操作仍能获得编辑焦点。
- 鼠标使用保持目标应用上下文；键盘导航启用或搜索/编辑需要时允许 GPUI 主窗口获取焦点。不为模仿 WebView 实现而强制引入低级键盘转发：先用原生窗口焦点和明确目标句柄实现，同等操作结果为验收标准。
- 窗口显示前记录外部目标，包括热键和托盘唤出；已在应用内再次打开时不覆盖为自身。每次执行仍重新校验窗口、进程、修饰键和剪贴板序列。没有有效目标时明确复制降级，不宣称粘贴成功。
- 恢复顶部“固定窗口”：固定后外部点击不隐藏，粘贴后不隐藏，并把焦点交回目标应用；Esc/唤出热键仍可主动隐藏。固定与历史记录置顶分别显示、分别维护。是否采用 topmost 由 Windows 实现决定，以跨应用可见性、焦点和遮挡验收为准。
- 非固定时粘贴后默认隐藏、普通记录默认移顶，两项可配置；失败不按成功执行隐藏和排序。操作已完成但刷新失败单独提示。

### 设置窗口

沿用原版独立窗口、左分类导航、右设置分区；用现有 Kit Settings 组织八个基础页面。数据页按“采集与去重 → 保留策略 → 存储与迁移 → 备份恢复 → 清理”分区，复制/粘贴与提示使用统一的语言和动作名称。

## 4. 数据与兼容决策

### 默认策略

新目录采用原版基础默认：每组 10,000 条普通历史、30 天清理、文本类 1,024 KiB、图片 51,200 KiB、重复移顶、文本语义匹配。数量 0 表示不设用户数量限制，天数 0 表示关闭按天清理；解析、解码、排队及总资源边界仍有效。置顶和收藏不受普通自动淘汰影响。

现有 GPUI 数据升级时，缺少保留天数设置的实例保持“未启用按天清理”，不得因加入新默认删除已有历史；在设置中提示可启用。已有明示策略不被默认值覆盖。首次应用可能删除数据的策略前展示当前范围和受保护记录规则。

语义去重按当前分组匹配文本表示，严格模式保留精确字节差异；富文本与纯文本之间需要格式保留规则。捕获更丰富格式时不得被已有纯文本吞掉，捕获较少格式时不得降低已存保真度；置顶、收藏、分组与访问状态保持一致。此规则需在实现前用明确案例固定，不以简单 trim/lowercase 代替原版算法。

### 文件暂存与格式

普通文件暂存是可选能力，设置中说明它会复制文件内容，支持单文件与总占用上限；目录、超限文件和无法读取文件仅保留原路径并显示是否有备份。暂存失败不声称可恢复；清理在数据库提交后按引用回收。

格式支持采用明确列表：文本/Unicode、HTML、RTF、DIB/PNG、CF_HDROP 及经确认需要的文件伴生格式。不无差别保存应用内部句柄、未知进程私有格式或虚拟文件描述符。必要的格式转换在改变现有剪贴板前完成；多格式写入失败与部分写入分别报告。

### 导入、恢复与存储目录

- 设置页提供“导入旧版数据”“恢复 GPUI 备份”“导出备份”，原 CLI 保留为辅助入口。
- 导入旧版前展示记录/媒体/配置范围，列出可迁移与未迁移的设置。基础设置用显式白名单转换；同步、翻译、凭据和高级外观不导入。
- 直接旧 DB 导入不会假装包含媒体备份；优先建议旧 ZIP，原路径依赖和缺失资产写入报告。
- GUI 导入/恢复仍先用临时目录校验，不合并覆盖当前库。恢复到新目录后切换实例并重启；现有数据保持可回退。路径迁移独立于备份恢复，需关闭服务、取得目录锁、复制校验和切换失败回退。
- 普通清理、彻底删除历史、恢复默认设置、重置全部数据采用四个清楚的操作名称和范围；后两项必须保留数据/备份说明，不能用同一个“清空”按钮混合。

## 5. 实施顺序与完成标准

没有工时估算；以可验收结果而非提交数量划分阶段。每阶段保持可编译、可运行，复用已有模块并补差距。

### M1：恢复原版主窗操作（先做）

涉及：`clipboard-gpui/src/ui.rs`、`state.rs`、设置子模块、`tray.rs`、`position.rs`；必要的筛选参数沿 core/platform 调整。

- 恢复顶部四入口、底部分类分组、即时单击、右键编辑和批量栏。
- 将互斥 HistoryFilter 调整为正交 group/category/search 状态；分页、计数、选择和代次使用同一查询上下文。
- 恢复窗口固定及默认 Alt+C，主唤出热键自由配置；目标捕获与焦点规则接通。
- 活动组采集上下文在命令入队时固定；保持已有热键、显示和预览偏好。

完成标准：中文/英文、最小窗口和常规窗口中入口无重叠；单击无双击等待；分类与分组组合查到正确结果；固定窗口粘贴后保留并交回焦点；多选和右键不误触粘贴。运行记事本/浏览器的文本往返作为阶段验收，不能只看截图。

### M2：补齐基础内容与数据规则

涉及：core 捕获/去重/仓库/偏好/媒体与 platform Windows 剪贴板采集、写回及 worker。

- 去重三策略、语义/严格模式；每组数量、天数和大小限制接入设置及捕获链。
- 浏览器图片/富文本组合分类、文件可选暂存与受支持伴生格式。
- 统一执行预检、受管媒体引用清理、资源状态与格式能力反馈；补独立编辑窗口。

完成标准：不同去重策略、跨文本/富格式、跨分组、收藏/置顶保护和升级默认有隔离测试；普通文件原件删除后的暂存回退实测；超限/失效/不支持格式不导致错误成功反馈；Office/浏览器、图片编辑器与 Explorer 验证相关内容往返。

### M3：完成数据迁移与设置闭环

涉及：core 导入/备份/偏好转换、platform 服务生命周期/目录锁、GPUI 数据设置与 options。

- GUI 导入/恢复、旧基础设置转换报告、数据目录切换/迁移。
- 清理范围、普通/彻底删除、默认设置恢复与全部重置；受控错误和取消反馈。
- 八页基础设置及所有新策略持久化，备份恢复后行为一致。

完成标准：隔离副本覆盖旧 DB、旧 ZIP、GPUI ZIP；中文路径、缺媒体、已有目标、损坏归档、迁移失败/中断均可恢复；不接触用户真实旧目录，导入报告与实际内容一致。

### M4：当前版本发布验收

- 自动门禁：fmt、workspace all-targets check、Clippy -D warnings、locked tests、release build。
- 当前 HEAD 重新运行隔离 Windows clipboard smoke，不把旧结果当当前证明。

## 6. 工程边界

- 只使用 Rust、GPUI、GPUI Kit；不恢复 Tauri、React、TypeScript、Node.js 或 WebView。
- 官方目录已有的控件必须用 Kit：Input、Button、Tabs/TabBar、Select、Menu、Dialog、Tooltip、Settings、TitleBar、VirtualList、Kbd、Scrollable、Checkbox/Switch、NumberInput 等；应用卡片和窗口拖动布局用 GPUI primitives。
- core 不依赖 Windows/GPUI；Windows 剪贴板格式、目标窗口、快捷键、目录生命周期在 platform；UI 仅维护视图与提交请求，不再复制业务规则。
- 源代码仍可模块化拆分，但不把全库重构和新增通用框架当作基础功能里程碑。
- 复用第三方源码前，先核对具体文件许可及分发要求。
- 自动测试使用隔离临时目录；涉及真实系统剪贴板的测试必须明确限制在非交互窗口站。桌面跨应用验收需显式说明测试内容与对真实剪贴板的影响。
