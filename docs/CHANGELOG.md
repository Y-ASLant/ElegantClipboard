# 变更日志

本日志从 Windows 原生 GPUI 重构版 `2.0.0` 开始记录；此前版本不在此处补录。版本号来自根目录 `Cargo.toml` 的 `[workspace.package]`，发布标签须与之对应（如 `v2.0.0`）。

## 2.0.0-beta.10（预发行版）

- 恢复浅色无材质模式的纯白实色画布与白色内容表面，侧栏、控件、描边改回中性灰，移除统一token时引入的冷灰底色。毛玻璃/云母仍独立控制，深色配色及原生窗口圆角、阴影不变。
- 清理依赖声明：将GPUI包仅用于文件卡片测试的serde_json移至dev-dependencies，移除Windows测试重复启用的GDI feature及两处macOS Foundation默认已启用的feature清单；保留实际平台能力与锁定版本。核对模块树、构建资源、打包与CI入口后，未发现可安全删除的废弃源码、资源或脚本。
- 完整升级GPUI依赖链至[稳定版GPUI Kit 0.8.1](https://github.com/longbridge/gpui-kit/releases/tag/v0.8.1)：配套Base/Component/Assets/Macros为0.8.1，默认gpui-pre后端及平台包为0.3.10，锁文件同步其布局/渲染依赖。卡片与列表滚轮入口迁移到ScrollEvent/on_scroll，移除弃用API使用；静态快捷键与现有数据格式保持不变。
- 统一材质与组件表面层级：材质启用时设置分组、侧栏与普通历史卡片共享单层窗口染色，不叠加半透明背景或普通容器细描边，避免灰块与圆角边缘叠色；控件及菜单、通知、对话框保留清晰表面。材质切换同步投影GPUI Kit主题，不再只改外壳。
- 收敛共享尺寸、间距、字号、图标、描边和浮层阴影；设置选项最大640px，音效保持360px。预览内部圆角跟随主题，与图片/备注裁切保持一致；Windows原生圆角不变。
- 统一应用入场与重排动效使用主题曲线，保留190ms侧边预览展开；材质卡片表面即时切换，避免透明插值产生脏边，操作栏仍淡入淡出。Windows启动和主题/材质刷新读取系统客户区动画开关，并同步原生背板明暗，修复应用深色而系统背板仍为浅色的割裂。
- 修复背景材质切换导致Windows原生圆角、阴影消失：保留窗口样式和GPUI非客户区处理，删除材质专用去边框子类、样式缓存与人工尺寸刷新。Windows 11以DWM系统背板直接覆盖窗口，切换前清除旧WCA效果，不再改边框颜色或写只读边框厚度属性；DWM应用失败记录具体错误。组件圆角仍不影响原生窗口。
- 修复重构后的Unix复制模块导入层级，恢复Linux/macOS平台层编译。内容类型改为严格解析，未知类型不再获得文本编辑、合并、纯文本复制和悬停预览权限；历史文本展示兼容回退保留。
- 纯文本回退使用借用的`Cow<str>`，已有正文不再额外复制；HTML转换仍返回拥有的文本。缩略图使用复用容量的位置映射，保留输入顺序及去重，同时维持快速成员查询，移除可见范围同步的临时Vec。
- 修复禁用分段选项的不透明底色覆盖底槽与选中指示，保留官方GPUI Kit禁用交互和选中状态；音效播放时机控件最大宽度调整为360px，明暗主题均保持可辨识的选项层次。
- 修复侧边短文本预览末字异常换行：拟合宽度与GPUI文字布局统一向上取整，避免像素吸附压缩有效宽度；保留长文本自动换行和显式换行。
- 重构背景材质为不透明、毛玻璃、云母，移除独立云母 Alt 与原生分支；Windows 毛玻璃映射原生亚克力，macOS 映射系统模糊，Linux 未验证原生模糊时保守不透明。界面只列出受支持选项，按平台降级但不覆写不受支持的保存偏好；旧 none/acrylic/mica_alt 在存储边界迁移为 opaque/frosted/mica，保留浓度与备份恢复。
- 「背景遮罩强度」改为「背景浓度」，说明越高越不透明；默认背景材质显示为「无」，无材质或降级到不透明背景时隐藏浓度调节与说明，保留已保存浓度供重新启用材质时使用。继续仅重绘外壳染色，文字、按钮、卡片与透明预览层不受影响；中英文设置及保存反馈同步更新。
- 减轻预览连接效果：实心端点缩至 4px、光晕缩至 8px/14%，连线改为 1.5px/65%；短间距按朝向间隙收紧控制点，避免鼓包回折。内容、连接线与信息共用 190ms 淡入，缩放时不重播。
- 将预览完整切换为 QcClip 风格的工作区透明穿透层，图片、实测尺寸的文本/HTML、曲线与端点光晕、外部信息标签统一绘制；8px 圆角与轻阴影，移除旧预览标题栏、内部比例角标和单独连接窗口。信息使用真实存储元数据，不将 PNG 冒充原始 CF_DIB。
- 对齐 190ms ease-out-quint 展开与淡入，内容保持目标尺寸并随外层裁切展开；非激活预览不再限制为 30fps，减少动态效果时直接显示。来源卡片 Ctrl＋滚轮按步调整图片或滚动文本，缩放不重播入场；预览跟随来源位置，离开来源立即关闭。Windows 原生定位与样式设置仍在 GPUI 借用之外执行。
- 移除历史列表空白区域的点击隐藏行为，避免在窗口内部误触关闭；保留卡片操作和 Esc/快捷键等既有行为。
- 默认启用限量轮转的本地诊断日志与独立 panic 堆栈文件，记录显示器坐标/DPI、窗口与预览创建、缩放及关闭过程；日志独立于剪贴板数据库目录，不主动记录剪贴板正文、搜索词或图片像素。
- 修复诊断中实际捕获的 Windows 跨显示器定位重入崩溃：启动/唤回时的 `SetWindowPos` 延后到 GPUI 借用结束后执行，避免显示器变化回调触发 `RefCell already borrowed`。主屏和负坐标副屏的 Debug/Release 隔离启动均正常退出；详见[诊断与验证记录](WINDOWS_MVP.md#默认诊断日志与双屏定位重入)。
- 全应用统一 Chakra 风格的语义配色、控件层级和动效，覆盖历史列表、设置、预览、首次引导、菜单与确认弹窗；保留官方 GPUI Kit 组件和 Rust 原生运行方式。
- 外观圆角改为跟随系统、关闭、4px、16px，移除8px选项并将原「直角」改名为「关闭」。默认仍为4px；旧8px值迁移为可持久化的system，其他合法旧值保留并明确提示。圆角设置仅改变内部组件：跟随系统恢复主题默认控件圆角，关闭将控件半径设为0；移除原生窗口圆角修改，不再按设置重配主窗口或设置窗口的DWM圆角策略。重启、备份恢复及非法写入保护保留。
- 移除主窗口内整页预览及查看详情入口，保留独立悬停预览；文本编辑与备注使用对话框，另存、路径与系统文件定位保留在右键菜单。
- 剪贴板主窗口反馈改用系统原生通知：Windows WinRT Toast、macOS UNUserNotificationCenter、Linux 桌面 D-Bus；已打开的设置窗口继续使用应用内通知，主窗口与首次引导不再挂顶部 toast。
- 首次引导改为实际使用与配置流程：先介绍快捷键唤出/隐藏，再说明复制记录、选择与回贴、纯文本使用，最后直接配置主题、开机启动和搜索聚焦；移除循环小窗口演示，采用顶部步骤、操作说明卡片和固定底部导航，视觉与入场参考 Chakra。
- 新用户默认唤出快捷键改为 `Alt+C`，已保存的自定义组合、关闭状态和旧 `ctrl_shift_v` 预设保持原意。引导显示真实配置和注册状态，文案精简，快捷键卡片仅提示“可在设置中修改”。
- 重排历史卡片内部层级：紧凑/标准/宽松密度的四边内边距统一为 8/10/12 px，文本预览、媒体图标、标题和底部元信息沿同一边界排布；悬浮操作栏移至右上角，来源应用不再随悬停隐藏；图片、文件采用左侧预览或图标、右侧标题与元信息的横向布局，拖动预览保持同一结构。
- 清理卡片渲染：媒体预览仅在图片/文件分支构造，合并文本高亮、截断与图片不可用提示的重复实现；缓存命中时不再复制缩略图路径，保持卡片布局、焦点细边框及拖动行为不变。
- 修正 `just build` 和 `just run` 的 Cargo 包名为 `elegant-clipboard-gpui`。
- 卡片右上角操作栏移除复制、粘贴及路径/纯文本按钮，仅保留五项管理操作；独立主题底色、细描边与轻阴影区分操作栏和卡片背景，保留卡片点击、快捷键和右键菜单的复制粘贴入口。
- 卡片及右键菜单的删除图标改为垃圾桶；返回顶部改为 Chakra 主题蓝色的圆角方形图标按钮，以官方 `ArrowUpToLine` 替代字符箭头，保留原有回顶交互。按需打包两枚扩展图标，避免加载完整图标集。
- 修正默认选中记录的操作栏常驻：仅悬停时显示，离开或拖动时隐藏；复用官方 transition 实现 150ms 淡入淡出，不改变卡片几何，完全透明后取消命中，减少动态效果时直接切换。
- 修正搜索框自定义 Size 回退到 24 px，使用官方 Medium 与分类分段保持实际 32 px 同高。
- 返回顶部改为浅色描边按钮，仅实际向下滚动后显示，使用可由用户操作打断的 300ms 平滑回顶。
- 验证：完整检查、Release 构建与 409 项测试通过、2 项原有忽略；Windows 原生窗口实测引导与系统通知中心接收，macOS/Linux 通知模块的目标平台编译及 Clippy 通过。卡片重排另在 560×760 和 420×520 的原生 Release 窗口核对文本、图片、文件及选中操作栏，缩略图、标题和元信息保持分区且未越界。引导覆盖快捷键显隐、初始偏好、最小窗口、步骤滚动隔离及完成重启。详见[首次使用与配置验证](evidence/onboarding-setup-2026-10-28.md)和[全应用样式验证](evidence/chakra-theme-2026-10-28.md)。

## 2.0.0-beta.8（预发行版）

- 移除普通文件副本功能及设置：文件历史仅记录原始路径，原件失效时明确报错，不自动备份文件实体。启动时清理数据目录内旧 `staged` 副本并移除对应数据库引用，保留原始路径、历史元数据和截图；备份不再携带副本，旧备份恢复时跳过副本文件，避免重新占用空间。

- 验证：404 项测试通过、2 项原有忽略；完整本地检查、Release 构建和隔离剪贴板往返通过，原生隔离样本确认旧副本清理、原文件和历史保留。Linux x64、macOS ARM64 平台库交叉编译通过。详见[仅路径存储验证](evidence/file-paths-only-2026-10-27.md)与[目录迁移验证](evidence/data-directory-migration-2026-10-27.md)。

## 2.0.0-beta.6（预发行版）

新增序列粘贴（粘贴队列，决策 0004 `docs/decisions/0004-sequence-paste.md`）：

- 多选 ≥2 条记录后从批量操作栏进入序列粘贴：首条立即受控粘贴到原窗口，其后在目标应用中按全局推进键逐条送出，队列耗尽自动结束并显示总数。
- 推进键默认 `Ctrl+Shift+G`，可在设置 → 快捷键录制、修改或停用；与主唤出快捷键及快速粘贴槽位互斥校验，三平台常驻注册（未激活序列时事件忽略）。
- 离开面板（窗口失活/隐藏）、复制、合并或删除操作自动取消队列；每条粘贴送达后照常执行「粘贴后恢复原剪贴板」（决策 0003）。
- 验证：354 项测试通过（2 项忽略），隔离窗口站冒烟全链路通过；推进键的真实多选逐条回贴待实机验收。

## 2.0.0-beta.5（预发行版）

按决策 0003 补齐复制→粘贴链路的五项基础能力（`docs/decisions/0003-core-paste-parity.md`）：

- 新增粘贴后恢复原剪贴板（默认关闭）：开启后受控粘贴完成时把粘贴前的剪贴板内容写回并抑制自捕获；隐私标记内容读不到即静默放弃。数据设置页可切换。
- 新增去重策略切换（数据设置页）：相同内容再次复制时移到列表顶部（默认）或各存一条保留时间线；「各存一条」同时跳过同文格式合并。
- 新增文本转换复制/粘贴：文本条目右键菜单提供去首尾空白、去换行、转大写、转小写四种转换后的复制或粘贴到原窗口。
- 新增按格式复制/粘贴：富文本条目右键菜单可选纯文本、HTML 或 RTF 单一格式，缺少所选格式时明确报错不降级。
- 新增条目备注：完整预览页可保存备注（2000 字符上限），备注参与关键词搜索。
- 验证：354 项测试通过（2 项忽略），隔离窗口站冒烟覆盖备注搜索、转换复制、按格式复制与去重策略往返；恢复剪贴板的跨应用回贴待实机验收。三平台共用核心与界面；Unix 平台集成随代码同轮实现，交叉编译检查因本机缺少工具链未执行，由 CI 原生检查覆盖。

- 文本、网址及 HTML/RTF 卡片默认启用已有完整内容悬停预览，与图片预览一致；文件预览仍默认关闭，用户明确保存的预览开关不会被覆盖。单张受支持的图片文件（截图工具放进剪贴板的 JPG/PNG）改按「图片」开关判定，并同样支持按图片尺寸放大浮窗。
- 悬停预览浮窗：图片正文支持滚轮无极缩放（1.10 倍/档，0.5×–4×）与左键拖拽平移，缩放时保持视口中心不动；浮窗可按住标题整窗拖动，出现后固定 5 秒自动关闭；大图浮窗按图片比例收敛，最多占显示区域的 70%，不再铺满整屏。
- 主窗口、设置窗口与悬停预览浮窗支持 Windows 系统材质（关闭／亚克力／云母／云母 Alt）与 40%/55%/72%/85% 四档背景遮罩强度。材质仅作用于窗口外壳；设置标题栏和侧栏容器局部透明以露出同一层外壳，控件、卡片和浮层保留原有主题表面。设置入口位于「外观」页，已保存的材质与强度值保持有效。
- 图片解码缓存按需回收：图片离开可见与预取范围且不再被拖动或预览使用时释放，窗口隐藏 30 秒后释放全部缩略图，再次唤出会取消该任务，避免频繁显隐反复解码。
- 首次启动的四步引导改用 GPUI Kit Stepper 展示进度并支持点击切换步骤；保留下一步、跳过、Esc 与完成后持久化的行为。
- 数据设置新增 GPUI Kit 绘图柱状图，按本地日期展示最近 7 天（含今天）保留的剪贴板历史条数，空白日期显示为 0；打开设置及点击本地数据刷新按钮时重新统计，删除全部历史后同步更新。
- 数据设置的“删除全部历史”二次确认改用 GPUI Kit Dialog 自定义操作按钮，直接在设置窗口确认或取消；删除期间锁定操作，失败时在对话框内显示错误，成功后保持设置窗口打开。
- 设置窗口初始内容区由 820×500 调整为 1280×720（16:9），保持居中打开及现有最小尺寸约束。
- 设置中的唤出热键、自动粘贴按键、快速粘贴槽位、录制提示及首次引导中的按键改用 GPUI Kit `Kbd` 展示平台原生快捷键格式；按钮、录制和保存逻辑不变。
- 设置中的多选和其余布尔项使用 GPUI Kit `Checkbox`，开机自启及复制、粘贴音效启用项使用 `Switch`；窗口位置、快捷键、外观、悬停预览、列表显示、音效时机及应用过滤的互斥选项统一采用等宽填充的 `TabBar`，保留试听等执行按钮及原有异步保存、禁用和错误反馈。卡片预览行数使用 `NumberInput` 并限制在 1–10 行，主窗口仅在保存排序期间显示 `StatusBar`。
- 历史列表改用 GPUI Kit `VirtualList` 按记录高度虚拟渲染，并以 Kit 滚动条保留像素级滚动、键盘定位、拖动边缘滚动和分页；预览缩放区域使用 Kit 滚动条。分组删除、当前分组清理和批量删除改用 Kit `Dialog`，保持后台处理中禁止重复操作与取消、失败反馈和焦点恢复。
- 设置中的可展开快捷键与运行中应用区域改用 Kit `Accordion`，操作错误改用 Kit `Alert`；历史卡片的拖动握柄和图片缩放按钮使用 Kit `Icon`，保留原有异步保存和按需加载。
- 核心去除重复语义哈希、重复媒体查询和未使用的数据库路径状态，淘汰记录时只读取待删除行的受管媒体；Windows 服务复用设置保存应答与快捷键注册逻辑，避免重复的图标路径和应用名称分配。
- 历史卡片拖动时，GPUI Kit `VirtualList` 的可见行按实际文字/图片高度播放主动让位动画；落点改由未移动的虚拟槽位及滚动位置计算，避免动画改变拖放命中。排序确认后的回流动画也按真实像素距离移动；Esc、边缘自动滚动和松手后持久化规则不变。
- 移除设置中无用的“操作按钮”分组及托盘/批量选择入口的显隐和排序配置；旧配置不再生效，托盘的清理历史、置顶和设置入口始终可用。
- 设置界面内容卡片随窗口宽度伸展并统一横向、窄窗换行规则；外观页的语言和具名主题选项并排，窗口行为设置分列，快捷键槽位合并为一行；“本地数据”的占用摘要与四个操作按钮在宽窗口同排，窄窗自动换行。
- “关于”页改为按分组列出 README「当前功能」的完整中英文条目（剪贴板历史、整理与分组、采集规则、快捷键与粘贴、悬停预览、新手引导、窗口与界面、备份与数据），与应用内功能保持一致；保留版本号、作者、GitHub 和反馈入口。
- 唤出快捷键选项改用无阴影的 Kit 描边标签；标签内的 Kit `Kbd` 使用无底色文字，避免灰色小徽标与选中态重叠；复制和粘贴音效的播放时机、试听按钮及最右侧的启用开关调整到同一行。

### 修复

- 数据库的排序、字符数和收藏顺序迁移将新增字段与数据回填放在同一事务，失败后可完整回滚再重试；图片尺寸和来源应用字段逐列补齐，恢复旧版本中断留下的单列状态，同时保留已存在字段的数据和用户排序。回归与构建结果见[迁移和附件回收验证](evidence/windows-migration-cleanup-2026-10-14.md)。
- 单条删除、批量删除和历史清理区分数据库提交与附件回收结果：记录已删除但受管文件无法回收时仍刷新列表并结束操作，通过现有通知明确提示残留，不再静默吞掉回收错误或误报记录删除失败。自动淘汰及编辑后的回收失败记录警告，保留已完成操作的成功语义。

- 修复开启窗口材质后窗口右下多出一条灰色带、拖动窗口才恢复的问题。套用效果会去掉窗口边框并加上 DWM 背板与圆角，客户区随之变大，必须补发 `WM_SIZE` 让 GPUI 重新布局；而原先用 `SendMessageW` 同步派发，调用点都在「正在更新窗口」的过程中，GPUI 写回新尺寸的回调会因窗口被借用而静默失败。改为 `PostMessageW` 投递，等本次更新结束后派发即可生效；悬停预览浮窗额外在窗口创建完成后再套用一次效果。
- 修复悬停预览浮窗右/下边缘那圈 1 px 亮线与灰带：浮窗不再经 `gpui_kit::open_window` 开窗（那会用 `gpui_base::Root` 包一层，从而触发 gpui-component `WindowState` 插件给每个 Root 套上的 `window_border()`）。该组件画 1 px 边框和一个 blur 10 px、offset (0,+2px) 的 box shadow，而给它留空间的 `SHADOW_SIZE` 在 Windows 上是 0，阴影无处落脚便溢进窗口内部。
- 修复窗口材质开启后通知呈深灰块、分段选中项凹陷和多种组件底色异常：移除 `retint_theme` 对全局主题 token 的透明化，材质切换不再重载或修改主题。背景遮罩强度只控制外壳的一层染色，不分摊到组件，也不改变系统模糊半径；通知、菜单、输入框、卡片与拖动浮层使用原有主题背景和阴影。
- 窗口材质按 Windows build 筛选并降级：22621 起支持全部材质，17763–22620 使用兼容亚克力，更早或版本未知时使用不透明背景。不支持的已保存选项仍显示为选中但禁用，并通过持续 Alert 说明实际降级效果；保留数据库中的原选择。
- 遮罩强度与原生材质更新分离：仅在解析后的原生后端改变时重新应用窗口效果，主窗口不再被重复处理；强度调整及等效降级选项切换仅重绘，保留悬停预览。新增版本边界和安全降级回归覆盖。
- 外观页为四个窗口材质选项保留最小可读宽度，空间不足时将标签与选项换行；背景遮罩说明限制在内容宽度内并正常折行，避免英文“云母 Alt”选项和窄窗口说明被裁剪。
- 修复切换窗口材质后右下短暂出现灰块的问题：`set_frameless` 之前的那次非客户区刷新发生在无边框子类安装之前，客户区仍按旧尺寸计算；现在在子类就位后补一次 `refresh_frame`，再通知客户区尺寸。
- 修复悬停预览的关闭时机：切到别的应用时立即收起浮窗并丢弃待粘贴目标，判据改用「前台窗口是否属于本进程」，不再用「浮窗此刻是否激活」——失活回调触发时浮窗往往尚未被系统标记为激活，会把「点浮窗缩放按钮」误判成「切走」，预览一点就没。同时把离开来源行后的关闭宽限期由 180 ms 提到 600 ms，鼠标来得及移进浮窗。
- 修复大图悬停预览铺满整屏的问题：按图片尺寸放大浮窗时改为按比例收敛，最多占显示区域的 70%，屏幕上始终留有可点的列表区域，图片仍由 `object_fit: Contain` 缩进窗口而不会变形。
- 修复悬停预览正文右下出现两条灰边的问题：正文不再复用只读 `Textarea`（它会自带滚动条并在点击后获得焦点，看起来像变成可编辑），改为普通文本渲染；要选中或编辑请用主预览。
- 修复图片悬停预览点击缩放后浮窗被误关的问题，以及预览正文滚动条、浮窗被任务栏遮挡无法挪动等问题。

- 已完成的内容哈希索引迁移不再在每次打开数据库时重建索引；仍转换旧 UNIQUE 索引、补齐缺失索引并允许默认组和自定义组内保留重复内容。
- 旧版 ZIP 导入复用 GPUI 备份的原始 central-directory 校验，拒绝会被 ZIP 依赖合并的同名数据库和媒体条目，失败时不安装数据库或附件；正常旧版路径映射、未打包附件引用和 GPUI v1/v2 兼容保留。
- 主窗口操作反馈也改用官方 `Notification`，不再常驻底栏；由主视图统一向主窗口或设置窗口投递，避免同一结果在两处重复显示。后台统计成功保持静默，上下文错误仍留在对应对话框。

- 修复设置窗口“数据占用已更新”常驻底部的问题：移除将共享消息反复渲染为全宽 `Alert` 的底栏，改用 Kit 官方 `Notification` 显示新的操作结果，默认自动消失且不占用布局。数据占用查询成功时只更新统计，避免无操作成功提示及覆盖其他错误。
- 删除 7 项过度测试：表存在性及旧默认字面量、空库维护仅不报错、重复 RTF 分支、图标仅能加载及固定 URL 复述；保留实际持久化、迁移、回滚、并发、安全边界和交互状态覆盖。`CLAUDE.md` 新增代码质量、测试准入与清理规则，避免把文案和实现细节当作永久契约。

- 新建和重命名分组的 Kit Dialog 从默认靠上位置调整至窗口中央，保留背景遮罩、输入焦点与异步保存反馈；为输入框焦点描边预留间距，避免其底边被弹窗内容区裁剪。

- 快速粘贴全局组合键改为默认关闭，已有明确启用配置仍保持有效；注册冲突只显示失败数量和一个示例，避免启动时将大量错误铺满历史窗口。
- 修复关闭设置后从托盘再次打开设置、主窗口隐藏时后台事件不再响应的问题；后台通知固定使用历史窗口句柄并及时刷新 GPUI 状态。历史列表空白处现在可点击隐藏，卡片点击、置顶及进行中的粘贴行为保持不变。
- 修复全局唤出快捷键在主窗口忙于显示时连续按下、第二次切换事件可能被容量为一的通道静默丢弃的问题；热键按次序投递到主窗口，正在粘贴或批量操作时仍按原有保护规则暂不隐藏。
- 修复按住 Alt 连续按放 C 时唤出后不能再次隐藏：GPUI 的 Windows 激活实现会注入 Alt 按下和松开，导致真实按住的 Alt 被程序释放；检测到 Alt 已按下时直接使用系统窗口激活 API，保留修饰键状态，其余场景继续沿用 GPUI 激活。
- 移除历史列表顶部占一行的操作快捷键提示；顶部 8 px 与 Windows 缩放边缘重叠，改用记录数量行拖动仍不够直观，现提供可见的顶部握柄；卡片两侧的记录排序拖动区保持不变。
- 新剪贴板记录未命中去重时不再查询最大排序值；已有记录的置顶顺序与访问次数更新保持不变。
- 新建库和 GPUI 备份保留 URL 与语义哈希迁移完成状态，防止已编辑的链接在重启或恢复后重新归类；旧库仍执行必要的首次回填。恢复孤立迁移表时先处理旧记录，再创建新表。
- 后台任务失败和单实例唤窗请求在事件队列拥塞时等待投递，不再静默丢失；关闭时先释放阻塞的投递线程。剪贴板监听回调仍使用非阻塞队列。
- 隐藏分类栏只清除当前分类或收藏筛选；浏览自定义分组时保留分组、已加载记录和选择状态。命令行路径参数共用同一解析规则。
