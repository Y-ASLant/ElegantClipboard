# 变更日志

本日志从 Windows 原生 GPUI 重构版 `2.0.0` 开始记录；此前版本不在此处补录。版本号来自根目录 `Cargo.toml` 的 `[workspace.package]`，发布标签须与之对应（如 `v2.0.0`）。

## 2.0.0（未发布）

### 重构

- 使用 Rust、GPUI 和 gpui-kit 构建 Windows 原生应用，移除旧版前端运行时及构建链。代码划分为 `clipboard-core`（数据与业务逻辑）、`clipboard-platform`（Windows 集成）和 `clipboard-gpui`（界面）。
- 默认数据目录改为 Windows 用户 LocalAppData 下的 `ElegantClipboard-GPUI` 应用目录；不会自动读取或覆盖旧版数据库。可按 [Windows GPUI 状态](WINDOWS_MVP.md)中的说明，向空 GPUI 数据目录显式导入旧数据库或旧版 ZIP 备份。

### 当前功能

- 采集、搜索和管理文本、网址、HTML/RTF、图片及文件路径历史；支持收藏、置顶、分组、排序、预览和批量操作。
- 提供全局快捷键、系统托盘、受控粘贴、来源应用过滤、可配置的采集类型、简体中文/英文界面及明暗主题。
- 支持 GPUI ZIP 备份与恢复；提供 Windows x64 独立 ZIP 打包，当前不提供安装器或自动更新。
- 主窗口移除顶部标题栏，改用搜索框上方的可见短横握柄拖动，并保留系统边缘缩放；清理历史、置顶窗口和设置入口移至托盘菜单，批量选择图标与搜索框同行；分类标签和 GPUI Kit Select 分组下拉同行，分组新建、切换及重命名、删除、上下排序通过下拉菜单完成。
- 历史卡片改为图片和文本分别定高的可变高度虚拟列表：正文或大缩略图在上，时间、大小和来源在底部，操作和拖动提示悬停显示；默认文字预览调整为两行。分类 TabBar 和分组 Select 与搜索框统一高度。
- 文本、网址及 HTML/RTF 卡片默认启用已有完整内容悬停预览，与图片预览一致；文件预览仍默认关闭，用户明确保存的预览开关不会被覆盖。
- 首次启动的四步引导改用 GPUI Kit Stepper 展示进度并支持点击切换步骤；保留下一步、跳过、Esc 与完成后持久化的行为。
- 数据设置新增 GPUI Kit 绘图柱状图，按本地日期展示最近 7 天（含今天）保留的剪贴板历史条数，空白日期显示为 0；打开设置及点击本地数据刷新按钮时重新统计，删除全部历史后同步更新。
- 数据设置的“删除全部历史”二次确认改用 GPUI Kit Dialog 自定义操作按钮，直接在设置窗口确认或取消；删除期间锁定操作，失败时在对话框内显示错误，成功后保持设置窗口打开。
- 设置窗口初始内容区由 820×500 调整为 1280×720（16:9），保持居中打开及现有最小尺寸约束。

### 修复

- 快速粘贴全局组合键改为默认关闭，已有明确启用配置仍保持有效；注册冲突只显示失败数量和一个示例，避免启动时将大量错误铺满历史窗口。
- 移除历史列表顶部占一行的操作快捷键提示；顶部 8 px 与 Windows 缩放边缘重叠，改用记录数量行拖动仍不够直观，现提供可见的顶部握柄；卡片两侧的记录排序拖动区保持不变。

### 依赖

- GPUI Kit 升至最新稳定版 `0.6.6`（含配套 GPUI 依赖），更新 Cargo.lock 中可兼容的间接依赖；其余直接依赖经查询保持最新稳定版。上游 ropey 预发布依赖与锁定版本例外见 [依赖策略](WINDOWS_MVP.md#依赖策略)。

功能细节及限制见 [Windows GPUI 状态](WINDOWS_MVP.md)。本节为待发布版本记录，不表示已创建 `v2.0.0` 标签或正式发布。
