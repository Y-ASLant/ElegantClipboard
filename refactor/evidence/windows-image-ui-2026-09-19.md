# Windows 图片界面验证（2026-09-19）

- 列表将图片显示为“图片 · 宽 × 高”，并在与文本共用的 160 px 卡片内放入缩略图；置顶、收藏、删除、复制和拖拽仍使用同一操作区。图片预览使用同一 160 ms 淡入规则，按原比例显示，并提供“复制图片”。文件缺失时按需预览报错，图片解码失败时显示替代文案。
- 在 `target/qa/image-ui` 隔离目录中，用仓库 PNG 样本生成一条图片记录；以 `--no-monitor` 启动真实 GPUI 窗口。屏幕截图确认图片缩略图、尺寸及操作按钮均在卡片内，点击“查看”后完整图片和复制按钮正常显示。截图留在忽略目录 `target/qa/image-ui`，未纳入版本库。
- 混排拖动测试先暴露排序事务只允许文本的缺口；修正为与默认列表一致的文本、网址、图片类型和默认分组过滤后，拖动结果在重启数据库后仍保持。文本新增触发一万条上限时也会清理被淘汰图片的托管文件。`cargo test --workspace --locked --quiet` 共 110 项通过；`cargo clippy --workspace --all-targets --locked -- -D warnings`、`cargo fmt --all -- --check`、Windows debug/release 构建和 release 窗口冒烟通过。
- 截图和单元测试不证明真实系统剪贴板图片读取、写回及跨应用粘贴成功；这一步需要隔离桌面环境，避免覆盖用户当前剪贴板内容。图片拖拽沿用既有文本卡片命中逻辑，尚未对图片卡片单独进行真实鼠标拖放回归。
