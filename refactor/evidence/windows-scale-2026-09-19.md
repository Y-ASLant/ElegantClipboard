# Windows 10,000 条文本历史规模验证

- 使用 `--smoke-test --data-dir target/qa/scale-10000` 初始化隔离数据库，随后插入 10,000 条唯一合成中文文本，每条约数百字符、带独立顺序和哈希。没有读取真实历史或写入系统剪贴板。
- `--no-monitor` 启动真实 GPUI 窗口，通过 Windows UI Automation 等待搜索框和 3 条可见卡片就绪，测得从启动测试进程到该状态约 1,478 ms。此数包含进程创建与 UIA 查询，不是纯应用内部指标。
- 交替输入无结果词与最后 5 条记录的唯一编号，等待可见卡片从 0 变为 1；从设置搜索输入到结果可见分别为 231、200、235、234、232 ms。每次包含固定 150 ms 防抖及约 30 ms 一次的 UIA 轮询；因此只能粗略判断查询与渲染余量，不能作为精确 p95。测试后调试版进程工作集约 122.3 MiB。
- 该验证覆盖当前窗口可见列表与末尾搜索，不覆盖逐页加载至第 10,000 条、跨全部记录的拖拽、真实中文 IME、长时间运行或用户剪贴板读写。
