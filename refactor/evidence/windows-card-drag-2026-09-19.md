# Windows 整卡拖拽与界面验收（2026-09-19）

- 历史卡片的正文、预览和标题区域都可启动同一 `HistoryDrag`；操作按钮区拦截拖动起点，保留点击行为。既有后台校验继续约束分组、收藏视图、置顶分区和列表代次，SQLite 成功后才显示排序完成反馈。
- 使用 `target/qa/reorder/clipboard.db` 的隔离备份，以 `--no-monitor` 打开真实 GPUI 窗口；从第一张卡片正文 `(200, 395)` 拖至第二张卡片下半部 `(200, 620)`，排序 ID 由 `[7, 6, 5, …]` 变为 `[6, 7, 5, …]`，界面显示“顺序已保存”。过程截图位于忽略目录 `target/qa/card-drag/`。
- 随后点击首条卡片的“收藏”，SQLite 中该记录的 `is_favorite` 由 0 变为 1，确认整卡拖动没有吞掉按钮点击。
- 将窗口缩至 420 × 520 客户区目标附近，首条卡片的操作按钮仍可见，搜索、分组和状态栏保持布局；截图为 `target/qa/card-drag/narrow.png`。
- 拖动预览、插入线、排序完成、预览进入和分组临时栏共用 `visual::reveal` 的 160 ms ease-out 动效；系统减少动画时跳过动效。列表仍为 160 px 定高虚拟行，窄窗口操作按钮可以换行。
