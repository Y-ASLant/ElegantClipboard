# Windows 跨置顶区拖放验收（2026-09-19）

- 历史卡片可直接跨置顶区和普通区拖放：源卡片继承目标卡片的置顶状态，再按目标上/下半区插入。置顶状态切换和目标区顺序重排位于同一个 SQLite 事务中；排序更新被故障触发器拒绝时，置顶状态也会回滚。
- 搜索隐藏、尚未加载的记录及收藏独立顺序继续由稳定 ID 重排保护；收藏视图跨区拖放只改 `favorite_order`，普通视图保留自己的 `sort_order`。跨分组目标、缺失 ID、非收藏记录及过期列表仍被拒绝。
- UI 不再把跨区目标显示为红色不可放置；它沿用同区排序的主色 3 px 插入线、180 ms 换位动画、持续边缘滚动和减少动态效果设置。后台快照返回后，卡片的“置顶”标签与“取消置顶/置顶”按钮同步更新。
- 在忽略目录 `target/qa/cross-pin-drag-20260919-v1` 中使用 900×1020 真实 GPUI 窗口和四条隔离文本验收。先把 `置顶 A` 拖到 `普通 C` 后半区，数据库顺序变为 `置顶 B / 普通 C / 置顶 A / 普通 D`，A 自动取消置顶；再把 `普通 D` 拖到 `置顶 B` 前半区，顺序变为 `普通 D / 置顶 B / 普通 C / 置顶 A`，D 自动置顶。最终截图中的标签、按钮和状态栏与数据库一致。
- 验收以 `--no-monitor` 启动，没有读取或写入系统剪贴板。核心测试覆盖双向跨区、收藏顺序、重启持久化和事务回滚；Windows worker 测试覆盖快照、成功确认及过期列表拒绝。
- `cargo test --workspace --locked` 共 176 项通过（核心 136、Windows 后端 34、应用状态/参数 6）；格式检查、严格 Clippy、Windows Debug/Release 构建、真实窗口验收及包内程序隔离冒烟均通过且无编译告警。
