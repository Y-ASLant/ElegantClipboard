# Windows 导入分组浏览与组内排序验证（2026-09-19）

在已有数据库中创建五个合成自定义分组，将两条文本放入“工作”组、两条留在默认组。GPUI 启动时读出分组列表；切换组会更新查询代次，搜索、收藏筛选、数量和分页使用同一组 ID。拖拽请求携带组 ID，核心排序事务仅处理该组内受支持的记录；跨组或过期视图请求会被拒绝。

核心测试验证自定义组排序不改变默认组，跨组排序被拒绝。后台测试验证启动分组事件、切换查询和排序后再回默认组。总计 121 项 workspace 测试通过，严格 Clippy、fmt、debug/release 构建及 release 窗口冒烟通过。旧 Tauri 入口的分组仓储测试和八项数据库测试也通过。并行测试中发现旧测试以截断时间戳命名临时数据库会偶发碰撞，已改为完整纳秒时间戳加进程内计数器。

在 `target/qa/groups-ui` 隔离目录启动 Windows GPUI，实际点击“工作”分组后，屏幕上由默认组的两条记录切换为工作组的两条记录；420×520 的最小窗口下分组栏保持单行横向滚动，卡片仍在虚拟列表中显示。测试没有读取或写入交互桌面的剪贴板。

当前阶段只浏览已有分组；创建、重命名、删除分组，以及把记录移入/移出分组仍待实现。普通新复制内容继续进入默认分组。
