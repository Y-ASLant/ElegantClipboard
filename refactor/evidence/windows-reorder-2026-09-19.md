# Windows 拖拽排序验证

- 核心按稳定 ID 把条目插到目标前/后；在一次 SQLite 事务中重排当前置顶分区，搜索隐藏及尚未加载的条目保留相对次序。收藏使用独立 `favorite_order`，不改普通排序。跨置顶分区、缺失 ID 和不属于收藏视图的 ID 被拒绝。
- 新核心测试覆盖非相邻插入、重开持久化、收藏独立顺序、105 条跨默认分页重排和触发器强制写入失败后的事务回滚。Windows worker 测试覆盖成功确认与过期列表拒绝。
- `cargo test --workspace --locked`：97 项通过（86 核心、7 Windows 后端、4 应用）。`cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets --locked -- -D warnings`、Windows 构建通过。
- 隔离的 8 条合成记录下，用真实鼠标从第一条拖至第三条后半区，数据库顺序由 `[8,7,6,...]` 变为 `[7,6,8,...]`；再拖回第一条前半区，顺序恢复。关闭窗口后数据库顺序保留。普通窗口内保持拖动并在列表底缘移动约 4.5 秒，滚动后第一条可落到第 4 位；拖动浮层和插入线通过 PrintWindow 截图检查。
- 420 × 520 px 最小窗口截图确认筛选、卡片操作和状态栏无重叠；Kit 主题色在明暗模式沿用既有配置。底部状态栏由列表和预览共用。
- 未验证极端 DPI 下的鼠标命中、触摸拖拽和 Windows 辅助功能拖放；未读写真实剪贴板。
