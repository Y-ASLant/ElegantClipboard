# Windows 普通文件路径接入（2026-09-19）

- `ContentFormat::Files` 优先于图片读取，记录最多 256 条、总路径列表最多 1 MiB；核心以路径列表去重并写入现有 `files` 类型。文件和文件夹共用文本、网址、图片的列表过滤、收藏、置顶、搜索和拖拽排序。
- 预览按需显示完整路径列表；复制前确认原路径都存在，再通过 Windows 剪贴板接口写回文件列表。缺失源文件时返回错误，避免把不可用路径作为成功操作。只保存路径，不备份文件内容，也不支持旧版虚拟文件的伴生载荷。
- 核心测试覆盖路径去重、混排拖动、空列表与容量限制；Windows 工作线程测试覆盖采集、预览和源文件消失时不触碰系统剪贴板的错误路径。全工作区 113 项测试、严格 Clippy、格式检查、Windows debug/release 构建及 release 窗口冒烟通过。
- 在禁用监听的 `target/qa/image-ui` 隔离目录插入合成文件路径，用真实 GPUI 窗口截图核对“文件 · 1 项”卡片、统一操作区，以及“文件路径”只读预览和“复制文件”按钮。截图留在被忽略的 `target/qa/image-ui`，未提交。
- 未向系统剪贴板写入文件列表，跨应用粘贴、文件移动/删除后的行为，以及虚拟文件格式仍待隔离环境验证。
