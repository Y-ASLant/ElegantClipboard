# Windows 自定义分组拖拽排序验收（2026-09-19）

- 自定义分组各有 22 px 拖动把手，原有按钮仍可点击切换。默认分组固定在首位，不参与排序；分组按钮左/右半区对应目标前/后插入。拖动浮层、3 px 落点线和保存反馈沿用历史卡片的主题色、180 ms 动效及系统减少动画设置。窄窗口仍使用原有 42 px 横向滚动分组栏。
- 复用 `groups.sort_order`，无需数据库迁移。核心层在事务内写入完整自定义分组顺序；目标缺失或中途写入失败时保持旧顺序。后台成功写入并刷新分组列表后才发送确认；拖动期间分组列表变化会拒绝旧拖动。
- 使用 `target/qa/group-drag-20260919` 隔离目录，禁用系统剪贴板采集。三个合成分组初始为 `QA-A, QA-B, QA-C`；在真实 Windows 桌面从 `QA-A` 的把手拖至 `QA-B` 右半区后，SQLite 顺序为 `QA-B, QA-A, QA-C`。测试结束后重启同目录窗口冒烟退出码为 0，复查顺序未变且 `PRAGMA quick_check=ok`；拖动中截图在 Git 忽略目录 `target/qa/group-drag-during.png`。
