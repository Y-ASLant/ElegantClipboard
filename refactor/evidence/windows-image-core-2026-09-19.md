# 图片历史核心存储阶段

- Windows 图片接入前，核心新增 PNG 历史存储：限制 50 MiB、2500 万像素，按 `image:` 前缀与 PNG 字节计算 BLAKE3 哈希，使用临时文件并在写盘后无覆盖地持久化到独立 `images` 目录；数据库保存尺寸、字节数、路径和预览文案。
- 重复图片复用原记录；若数据库记录存在但图片文件丢失，再次采集同图时补齐文件和路径。删除记录或历史数量上限淘汰图片时，只清理 GPUI 图片目录内且没有其他记录引用的文件，保留旧版外部图片路径。
- 新增核心测试覆盖保存、去重、缺失文件修复、无效大小拒绝和删除边界。当前只是存储阶段；系统监听、GPUI 图片列表/预览与写回尚未接入，不能将本阶段视为图片功能完成。
