# Windows 旧版数据库显式导入验证

- `--import-db <旧版 clipboard.db>` 在 GPUI 数据目录取得与应用相同的实例锁，并拒绝已有 `clipboard.db`，避免覆盖或与运行中的 GPUI 实例并行写入。
- 源库只读打开，SQLite 在线备份将含 WAL 的一致快照写入同目录暂存文件；只对副本运行现有 schema 迁移和 `quick_check`。验证后移动到 GPUI 数据目录。持续忙碌超过 10 秒时终止导入；失败时暂存目录清理，旧库不改动。
- 单测保持源数据库连接打开且有 WAL 记录，导入后验证文本内容、置顶和收藏元数据、其他格式记录计数，以及重复导入拒绝覆盖；无效来源不创建目标数据库。
- 原生命令行验收使用 `target/qa/gpui-smoke/clipboard.db` 合成库导入到全新隔离目录：导入 116 条、可见默认分组文本 116 条、退出码 0；源文件 SHA-256 未变化。再次导入返回错误并退出码 1，原目标仍存在。
- 当前 UI 展示默认分组文本和网址。导入副本保留其他格式、自定义分组和设置；外部图片文件没有复制。真实用户旧库未参与验收。
