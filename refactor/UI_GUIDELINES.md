# GPUI 基础界面规则

当前规则对应 Windows 文本、HTML/RTF、图片和文件路径基础版，定义在 `crates/clipboard-gpui/src/visual.rs`，使用 GPUI Kit 主题色，不单独维护固定明暗色表。

| 部位 | 规则 |
|---|---|
| 内容左右边距 | 20 px；标题、搜索、筛选、列表和状态栏对齐 |
| 历史行高度 | 184 px，供虚拟列表计算；文本、HTML/RTF、图片与文件共用卡片边框、预览底板、正文拖拽区和操作区 |
| 行内按钮高度 | 28 px；窄窗口允许操作区换行；辅助操作统一 ghost，复制与受控粘贴统一 outline；粘贴仅在快捷键唤出并保存有效原窗口后启用 |
| 标题栏 | GPUI Kit TitleBar，沿用系统窗口控制 |
| 窗口设置 | 默认收起外观、唤出、开机启动与数据维护选项，最小窗口可完整显示首张卡片；数据占用的刷新、整理数据库和打开目录共用小号 ghost 按钮并允许换行 |
| 状态反馈 | 列表与全文预览共用一个底部状态栏；错误使用主题 danger 色 |
| 文本编辑 | 从全文预览进入，保持原卡片 ID 与分组；保存前提示富文本会转为纯文本，空内容需使用独立删除操作；Esc 取消编辑并恢复原内容 |
| 文件详情 | 使用可滚动的统一卡片列表；标题显示文件名，状态标签显示大小、文件夹或失效，正文显示原始路径；受管备份副本另列实际路径，失效项使用主题 danger 边框和文字 |
| 动效 | 预览、分组编辑与移动栏、拖动浮层、插入线和排序完成共用 180 ms ease-out 动效；保存排序后，所有换位的可见卡片从原位置滑入新位置；尊重 GPUI `reduce_motion` |
| 拖放 | 每张卡片正文均可拖动；按钮区只响应操作。浮层使用 Kit 主题，3 px 插入线提示落点；只在有效落点提交，置顶与普通条目分别排序 |
| 富文本复制 | 默认“复制”保留可用富格式；卡片“纯文本”和预览“复制纯文本”仅复制已保存的文本表示，缺失时提示错误 |
| 批量选择 | 卡片标题区“选择/已选”与普通操作分离；勾选后显示“全选已加载 / 取消选择 / 删除选中”，删除另有确认。搜索、分组及收藏视图切换会清空选择；受管媒体在事务提交后按引用清理 |
| 隐私清理 | 当前分组“清理历史”保留置顶和收藏；窗口设置中的“删除全部历史”使用 danger 按钮和独立强确认，明确覆盖所有分组、置顶与收藏，并说明设置和自定义分组保留 |
| 分组栏 | 始终显示新建入口与固定在首位的默认分组；自定义分组可拖动排序，左右半区决定插入位置，拖至栏边缘时横向滚动。默认分组按钮、自定义分组按钮和拖拽柄共用 28 px 控件高度；保存后被拖动及被挤开的分组共用排序反馈动画。选中自定义分组可重命名或删除。删除前显示名称和记录数，确认后将记录移到默认分组；固定 42 px 行高，避免压缩虚拟历史列表 |
| 移动记录 | 每张卡片共用“分组”入口；目标选择栏同样固定 42 px 并横向滚动，后台确认后才从当前列表移除记录 |

动效只传达操作状态，不改变列表的最终顺序；数据库确认后才播放排序完成反馈。若期间列表成员变化，则直接显示新顺序，不播放错误的位移动画。自定义分组拖放沿用卡片的主题色浮层、插入线、保存反馈和减少动画设置。滚动列表保留虚拟渲染，正文仅在预览时读取。

最小窗口客户区目标为 420 × 520 px，保持搜索、首条记录和状态栏可见；较长列表使用滚动。
