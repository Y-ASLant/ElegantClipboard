# GPUI 基础界面规则

当前规则对应 Windows 文本、图片和文件路径基础版，定义在 `crates/clipboard-gpui/src/visual.rs`，使用 GPUI Kit 主题色，不单独维护固定明暗色表。

| 部位 | 规则 |
|---|---|
| 内容左右边距 | 20 px；标题、搜索、筛选、列表和状态栏对齐 |
| 历史行高度 | 160 px，供虚拟列表计算；文本、图片与文件共用卡片边框、拖拽手柄和操作区 |
| 行内按钮高度 | 28 px；统一 small/ghost 行为，复制为 outline 主操作 |
| 标题栏 | GPUI Kit TitleBar，沿用系统窗口控制 |
| 状态反馈 | 列表与全文预览共用一个底部状态栏；错误使用主题 danger 色 |
| 动效 | 文本/图片/文件路径预览进入与排序完成使用同一 160 ms ease-out 淡入；尊重 GPUI `reduce_motion` |
| 拖放 | 手柄启动；拖动浮层使用 Kit 主题，3 px 插入线提示落点；置顶与普通条目分别排序 |

动效只传达操作状态，不改变列表的最终顺序；数据库确认后才播放排序完成反馈。滚动列表保留虚拟渲染，正文仅在预览时读取。

最小窗口客户区目标为 420 × 520 px，保持搜索、首条记录和状态栏可见；较长列表使用滚动。
